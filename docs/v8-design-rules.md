# V8 の見た目の決まり（管理画面）

- 作成: 2026-10-05（オーナー「V8 が入ったとき V6・V7 が邪魔にならないように」）
- 管理画面の見た目は **V8 だけ**。v7 の見た目・「前の見た目に戻す」は無くす。V6・V7 の見た目の文書・契約は使わない。

## 1. 正本の順位（上が勝つ）

1. **使いやすさ** — 使う人にとって分かりやすく使いやすいか
2. **Pencil の ★V8** — `~/Downloads/LINE-Harness-V8.pen`（部品の正本・主な画面）と `~/Downloads/LINE-Harness-V8-B.pen`（残りの画面）。**画面ごとに、その板の絵のとおり**。1枚の絵を全部の画面の決まりにしない。
3. **この文書**
4. **共通部品 `apps/web/src/components/shared/`・`layout/` と画面の型 `apps/web/src/components/templates/`**（どちらも絵と照合済み）
5. **動きの試験**（保存・送信・権限・失敗時・読み直しを守るもの）

- 見た目を変えるときは Pencil を先に直す。コードだけ直すと、次に絵を見た人が元に戻す。
- 絵と古い案・今の作りが食い違ったら、絵どおり。ただし LINE の決まり・安全・見張りに反する絵は、今の作りに合わせて絵を直す（例：LINE アカウントの乗り換え・運営ログインの2段階・運用状態の項目・プールのランダム振り分け）。
- 受け口（API）が無い欄は、見た目だけ置かない。足りない受け口は作ってから出す。

## 2. 作り方

- 画面は **型** に中身を入れて作る（ダッシュボード・一覧（フォルダの列あり／なし）・作る・詳細・受信箱・設定・分析）。型の外で、箱・余白・段を手で書かない。
- 部品は共通部品を使う。画面の中で同じものを手で書かない。部品の見た目を画面側で上書きしない（直すときは部品を直す）。
- 作る・編集の画面の保存の帯は、画面の下に追従。キャンセル・保存は中央、削除は左端。
- 一覧のフォルダは左の列、作るボタンはその列の上。行の右端は「…」、ページ送りのある一覧は 10・20・50 件の切り替え。
- 見出しの下の説明は「？」に入れる。
- 確かめる幅は 1152・1280・1366・1425・1440・1920。どの幅でもはみ出し・右端越えは 0。表だけの横送りも原則なし。

## 3. 合格の決まり（絵と照合したものだけを入れる）

- 絵の HTML（Pencil の書き出し。枠の幅に余白と枠を含む border-box で描く）と実装を、**同じ 1440 幅で撮って重ねる**。重ねた画像・差の画像（文字は同じ大きさの塗りに置き換える）で同じであること。
- **合格にしてよい違い**：文字の中身（名前・件数・日時・本文）、文字の長さによる行数、表やカードの行の数、データの有無で出る／出ない札・欄、権限による出し入れ。繰り返しは最初の 1〜3 行で比べる。
- **合わせなければいけないもの**：並べ方と段の順、繰り返す1行の形（高さ・余白・列幅・枠・線・角丸・色・部品）、板の内側の余白と段と段の間（±4px 以内）、はみ出し 0。部品は計算値で 1px 以内・色一致。
- 合格は司令塔が画像を見て決め、`~/lh-work/design/v8/PASSED.tsv` に記録する。入れるのは合格したものだけ。小分けに入れる。
- 文字列の試験・ビルド成功・印（`data-design-node`）は見た目の証拠ではない。
