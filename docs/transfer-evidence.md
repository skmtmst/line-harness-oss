# 配布・設計資産の受け渡し

この文書はコードから生成できる証拠と、所有者から受け取る資料を分ける。資料の存在だけで権利移転・復元・設計照合を完了とはしない。

## ソースと依存ライブラリ

ルートの [LICENSE](../LICENSE) は、このリポジトリの履歴 `1efa40dd4c` にある許諾本文を同一内容で復元したもの。著作権表記も原文を維持する。独自の追加成果物・委託成果物・画像・設計データの権利帰属を、この復元だけで証明するものではない。

修正版 Node と固定 lockfile を使用し、ルートから次を実行する。

```sh
pnpm install --frozen-lockfile
pnpm exec tsx scripts/release/third-party-notices.ts dist/notices
```

出力は `LICENSE`、`THIRD-PARTY-NOTICES.txt`、`sbom.cdx.json`。SBOM は CycloneDX 1.6 の構成要素一覧で、lockfile の SHA-256 を記録する。実際にインストールされた依存を版別に取り出す。生成物に埋め込まれる可能性のある開発・ビルド依存も含めた上限側の一覧であり、配信ファイルにすべて含まれるという意味ではない。許諾本文・NOTICE は配布パッケージから複写し、見つからないものは `review-required` とする。利用者のローカルパスは出力しない。

リリース workflow はこの生成を行い、bundle の `notices/` へ同梱する。3資料が欠けた bundle は生成しない。全プラットフォームの未インストール optional 依存、外部取得画像、手動で同梱した生成済みコードまでは、このインストール一覧では証明できない。とくに `packages/plugin-template/dist-mcp/index.js` は再生成元・生成時の lockfile と第三者帰属の別照合が必要。依存ごとの許諾条件の確認、独自部分の権利資料は受け渡し担当者が揃える。

## 設計の正本

比較用スクリプトは個人名を含むパスを既定にしない。取得した設計アーカイブを任意の場所へ展開し、`V8_DESIGN_DIR` を指定する。未指定時は `scripts/visual-qa/design-archive/` を探すが、そのフォルダが存在することを前提にしない。

受け渡し側は次を一組にする。

| 項目 | 必須の記録 |
| --- | --- |
| 正本 | V8 / V8-B の Pencil ファイルと版、書き出しHTML・PNG |
| 対応 | コードの完全SHA、対応表のSHA-256、対象の板ID |
| 完全性 | アーカイブおよび各ファイルのSHA-256、作成日時 |
| 取得 | 組織が管理する保管先、取得手順、権限を引き継ぐ担当者 |
| 権利 | 作成者・委託契約・フォント/画像の利用権と移管可能性 |
| 合格記録 | 実画面と正本の照合日時、対象SHA、差異、承認者 |

```sh
V8_DESIGN_DIR=/path/to/versioned-design node scripts/visual-qa/sync-v8-design-refs.mjs --include-html
V8_DESIGN_DIR=/path/to/versioned-design node scripts/visual-qa/v8-parity.mjs --board BOARD_ID
```

既定の `design-archive/` はローカル展開物としてGitから除外する。秘密値・顧客情報は設計アーカイブへ含めない。2026-10-21の独立点検ではこの正本一式を取得できておらず、手順の整備と実物の受領・照合は別の完了条件として残す。

## 基盤と復旧の受け渡し

ドメイン、Cloudflare、LINE、メール中継、決済などについて、契約主体・所有者・再発行手順を秘密値抜きで記録する。PHPが動くメール中継と連携EC、Nodeが動くCLI/MCPの実稼働版はコードの版指定だけで確定しない。サーバー上の実測版と更新記録を受領する。

復元はバックアップの存在確認に加え、隔離環境での復元結果・所要時間・データ整合性・RPO/RTOを記録する。実DB更新・実復元・外部通知の有効化は個別の運用承認を経て実施する。
