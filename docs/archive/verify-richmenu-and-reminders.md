# 検証環境で確かめること（リッチメニュー・自動応答・リマインダ）

このファイルは、**人が実際に触らないと確かめられないもの**を並べたものです。
コードの試験では通っていますが、LINE アプリでの操作や、時間の経過が要ります。

作った本人（Claude セッション）には確かめられなかったので、手順として残します。

---

## 1. リッチメニューの押された回数

**確かめたいこと**: ボタンを押すと、一覧の「今月のタップ」と編集画面の数が増えるか。

1. 管理画面 → リッチメニュー → 「メニューを作成」
2. レイアウトを選ぶ（図が出るので、6分割あたりで）
3. 画像を上げる（2500×1686 の PNG / JPEG、1MB 以下）
4. ボタンを1つ選び、動きを「メッセージを送る」にして、送るテキストを入れる
5. **同じボタンに「押されたときタグを付ける」でタグを1つ選ぶ**
6. 「LINE に登録」→ 一覧の「友だちに表示」で自分に出す
7. **スマホの LINE でメニューを開き、そのボタンを押す**
8. 管理画面に戻って確かめる
   - 一覧の「今月のタップ」が 1 増えているか
   - 一覧のカードに「今月 1 回」と出ているか
   - 編集画面でそのボタンを選ぶと「今月押された回数 1回」と出ているか
   - 友だち詳細で、そのタグが付いているか

**数えられないボタンもあります。** 「URLを開く（計測リンクなし）」「電話をかける」
「回答フォームを開く」は、LINE の中や外で完結するので押されたことが届きません。
画面には「この動きは数えられません」と出ます。0 と出ないことを確かめてください。

---

## 2. リッチメニューの出し分け（いちばん確かめたいもの）

**確かめたいこと**: タグが付いた瞬間にメニューが切り替わるか。

**とくに、オートメーションでタグを付ける構成で確かめてください。**

1. メニューを2つ作って、両方 LINE に登録する（A と B）
2. B の編集画面 →「誰に出すか」→「条件で出し分ける」を入れる
3. 条件に「タグ X を持っている」を入れて保存
4. **オートメーションで「何かのきっかけでタグ X を付ける」ルールを作る**
   （自動応答で「タグを付ける」でも構いません）
5. そのきっかけを起こす（キーワードを送る、など）
6. **スマホでメニューを開き直す**

### 期待する結果

**タグが付いた直後に、メニューが B に変わっている。**

### もし外れていたら

「タグを付けたのにメニューが変わらない。次に何かした（別のメッセージを送った）ときに
やっと変わる」という出方をするはずです。

**そうなったら教えてください。** `event-bus.ts` の Phase 3 を、オートメーションの
**後ろ**に置いた判断が間違っていたことになります。先に見直すと、いま付いたばかりの
タグが条件に反映されません。予測が外れた場合、別の理由で動いている（あるいは
動いていない）ことになるので、置き場所から見直します。

---

## 3. リマインダの配信

**確かめたいこと**: 本文の `{{name}}` が名前に置き換わって届くか。

1. リマインダを作る（「送るタイミングの決め方」は「○日前の●時」）
2. 通の本文に `{{name}}さん、こんにちは。` と入れる
3. 友だち詳細 → リマインダ →「ゴール日時」を**数分後**にして「開始する」
4. cron は毎分動くので、数分待つ
5. **届いた文で `{{name}}` が名前になっているか**

これまでは `{{name}}` が文字のまま届いていました（#195 で直しました）。

### 誕生日リマインダ

**その日のうちには確かめられません。**

友だち情報欄の日付を見るのは、**日本時間の 0:05 に1日1回**だけです。翌日以降に
効きます。確かめるなら、

1. 友だち情報に「日付」の欄を作る（例: 誕生日）
2. 誰かの誕生日を明日の日付で入れる
3. リマインダを作る（起点「友だち情報欄の日付」、その欄を選ぶ、「毎年くり返す」）
4. **翌日の 0:05 を過ぎてから**、友だち詳細でリマインダが登録されているか見る

**手で動かす口はわざと作っていません。** 確かめるためだけに本番の経路を増やすと、
それ自体が新しい穴になります。

---

## 4. 自動応答の一律応答

**確かめたいこと**: キーワードに当たらないメッセージにも返るか。

1. 自動応答を作る →「一律で応答」を選ぶ
2. 名前を付ける（例: 営業時間外の案内）
3. 「応答する曜日」と「時間帯」を、**いまの時刻が入る範囲**にする
4. 返す内容を入れて保存
5. **スマホから、何でもいいのでメッセージを送る**

### あわせて確かめたいこと

**キーワードのルールが止まっていないか。**

一律のルールと、キーワードのルール（例: 「予約」に反応）を両方作って、
「予約」と送ってください。**キーワードのほうが返るはずです。**

評価順が同じときは、キーワードのあるルールを先に見るようにしてあります。
もし一律のほうが返ったら、その仕組みが効いていません。
