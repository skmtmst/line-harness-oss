# V6 25 オートメーション・既存処理の接続契約

## 対象

V6の実行エンジンから既存のタグ、友だち情報、シナリオ、LINE送信、
送信Webhook、リッチメニューを呼び出すときの境界を定める。

## 共通ルール

- 友だちと参照先は、実行時のLINE公式アカウントと一致するものだけを使う。
- タグ、テンプレート、送信Webhookは、`line_account_id` が明示された行だけを使う。
- 既存行の所属は名前などから推測して移さない。所属が `NULL` の行はV6から使わない。
- 外部処理には処理実行IDを冪等キーとして渡し、再実行で同じ結果を増やさない。
- 一時的な失敗だけを1分、5分、30分後に再実行する。入力不備や権限不一致は再実行しない。

## 処理ごとの入力

| 処理 | 必須項目 | 安全条件 |
| --- | --- | --- |
| タグを付ける・外す | `tagId` | 同じLINE公式アカウントのタグ |
| 友だち情報を更新 | `values` または `data` | 対象友だちだけを更新。`{{message}}` を受信本文へ置換 |
| シナリオを開始・停止・再開 | `scenarioId` | 同じアカウント。開始は動作中かつ公開ステップあり |
| LINEを送る | `content`、または `templateId` | テンプレートは同じアカウント。LINE retry keyと送信記録を残す |
| Webhookを送る | `webhookId` | 登録済み・動作中・同じアカウント。HTTPSを必須にし、秘密値の設定時はHMAC署名を使用 |
| リッチメニューを切り替える | `richMenuPageId` または既知の `richMenuId` | 同じアカウントで公開済みのページだけ |
| リッチメニューを外す | なし | 対象友だちが同じアカウントにいること |

## Webhookの扱い

- 任意URLは処理定義へ保存せず、登録済みWebhookのIDだけを参照する。
- URL内の認証情報、localhost、内部向けホスト名、プライベート・リンクローカルIPは拒否する。
- 10秒で打ち切り、`429` と `5xx` と接続失敗だけを実行エンジンへ再試行可能として返す。
- `Idempotency-Key` を送る。ただし相手側がこのキーを処理しない場合の完全な一度だけ配送は保証しない。

## 今回の除外

- 所属が不明な既存タグ、テンプレート、Webhookの自動振り分け
- V6の作成・編集APIと画面
- 受信イベントからV6実行を開始するトリガーと定期ジョブ
- Webhook配送1件ごとの独立台帳（V6 26 外部連携で実装）
