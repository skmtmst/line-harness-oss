## 0. 結論

統括（本部）が、配信・リッチメニュー・回答フォームで使う画像を AI で作り、店舗（LINE公式アカウント）へ渡せるようにする。
参考にした Banas™（banas.design）の本質は「生成フォーム＋プロジェクト＋画像ライブラリ＋利用量」の4点で、musubo にはそこへ **「店舗へ渡す」** を足す。スライド生成・コンテスト・無限キャンバス・動画生成は作らない。

**Banas のクレジットと品質の選択は採用しない（2026-09-12 Masato 決定）。** 素人には判断できないので、運用者に見せるのは「用途・テキスト・色・人物・枚数」だけ。上限は **月の枚数**（プランごと）と 1日の枚数で管理し、品質はスタンダード固定。用途は LINE の画像規格すべてと主な SNS を網羅する。

| 評価軸 | 現在 | 要件どおり実装後 |
|---|---:|---:|
| V6 UI・UX | — | 設計済み（6画面） |
| Lステップ・Liny競争力 | 0（機能なし） | 高い（両者に無い機能） |
| 現行実装 | API・DB は PR #19、画面は PR「codex/masato-banner-generation-ui」で実装 | 規格サイズへの整形・課金連動が残る |
| データ安全性 | — | 統括単位で分離、店舗へは複製して渡す |

## 2. 達成すること

> 統括の運用者が、案件ごとにプロジェクトを作り、テキストと色を指定して画像を作り、店舗へ渡して配信に使える。

- プロジェクトを作る・名前と説明を変える・お気に入り・複製・アーカイブ・復元する
- 用途（LINE 7種・SNS 6種）・テキスト（1行1要素）・メイン色・サブ色・人物の有無・追加の指示・枚数（1〜4）を指定して生成する。品質は選ばせない
- 生成は 1 枚ずつ進み、途中で失敗しても成功分は残る。残りをやめられる
- 生成した画像と手持ちの画像を、統括の登録メディアとして一覧・検索・絞り込み・お気に入りできる
- 画像の「生成時の条件」を見て、同じ条件でもう一度作れる
- 画像を選んだ店舗へ渡す。渡した先の店舗では登録メディアから使える。同じ店舗へ二度渡しても増えない
- 今月・今日の生成枚数と残りが常に見える。上限に達したら理由と次の一手が出る。失敗が続いたら自動で一時停止し、理由が出る

## 3. 用語

| 用語 | 意味 |
|---|---|
| プロジェクト | 案件・キャンペーンごとの画像のまとまり。統括ごとに持つ |
| 用途 | 画像の使い道（LINE 7種・SNS 6種）。それぞれ規格サイズを持ち、画像生成APIの大きさ（1024×1024／1536×1024／1024×1536）のいちばん近いものへ対応する |
| 枚数上限 | 生成量の数え方。月（プランごと）と日（月の1/5）で数える。1回は4枚まで |
| 統括の登録メディア | 店舗に属さない登録メディア（`line_account_id` が NULL） |
| 店舗へ渡す | 画像の実体を複製して店舗の登録メディアを 1 行作ること |
| 一覧から外す | 統括の一覧に出さなくする。実体と渡した先は残る |

## 4. 画面ごとの動き

### 35-1 プロジェクト一覧（`aH6NX`）

- 1行目: タブ（プロジェクト一覧／画像ライブラリ）、右に「＋ プロジェクトを作る」「アーカイブを見る」
- 数値カード帯: プロジェクト数／今月の生成枚数／今月の残り枚数（％の札）／店舗へ渡した画像数
- 案内帯: 保存先と渡した後の使い方
- 一覧: 検索（名前・説明）、並び順、絞り込み（すべて／お気に入り／生成中）、3列のカード
- カード: 最新4枚のモザイク、名前、説明、枚数、更新、お気に入りの星、生成中の札「2/4枚 生成中」
- カードの押下でプロジェクト詳細へ。星の押下でお気に入り切替（画面遷移しない）

### 35-2 プロジェクト詳細と生成（`g1WVyR`）

- パンくず「プロジェクト一覧 › （名前）」。右に 画像を取り込む／お気に入り／複製／名前と説明を変える／アーカイブ
- 左: このプロジェクトの画像（4列）。絞り込み（すべて／お気に入り／店舗へ渡し済み）。タイルに比率札・星・渡し済み札・日時と品質
- 右 390px 生成パネル: モード（バナー／自由入力）、用途（LINE／SNS をまとめた選択）、テキスト（1行1要素・最大6行・40文字）、メイン色・サブ色（見本＋HEX）、人物、追加の指示、枚数（1〜4）。品質の選択肢は置かない
- 下部追従バー: 左に「今月の残り n枚・今日の残り m枚」、中央に「条件をクリア」「生成する（n枚）」
- 生成するを押すと 35-2-A へ。条件が足りない・上限を超える場合は押せず、理由をバー左に出す

### 35-2-A 生成中（`QGiQI`）

- グリッド先頭に生成中の枠（1枚目を生成中…／2枚目 待機中）。できた枚数から順に本物の画像へ置き換わる
- 見出し行に「0/2枚 生成中」の札。下部追従バーは「残りをやめる」「生成中… 画面を離れても続きます」
- 画面を離れても続く（1枚ごとにサーバーで保存されるため）。戻ると進み具合が反映される
- 失敗したら、その枚で止めて理由を札で出す。成功分は残す

### 35-3 画像ライブラリ（`w3ZDsD`）

- 統括の全画像。5列。検索（テキスト・指示・プロジェクト名）、並び順、絞り込み（すべて／お気に入り／店舗へ渡し済み／未使用）、用途（LINE／SNS の各規格）
- 30枚ずつ。「さらに30枚を表示」で続きを読む
- タイル押下で 35-3-A

### 35-3-A 画像の詳細と店舗へ渡す（`g4MyEA`）

- 左: プレビュー、大きさ・形式・容量、ダウンロード、お気に入り
- 右: 生成時の条件（用途／テキスト／色／人物／追加の指示／作成）、店舗へ渡す（店舗ごとのチェック。渡し済みは灰色で日付、二度渡さない）
- 下: 左に「一覧から外す」（赤）、右に「同じ設定でもう一度生成」「閉じる」「n店舗へ渡す」（主）
- 「同じ設定でもう一度生成」は 35-2 の生成パネルへ条件を戻す

### 35-4 一覧の状態（`xY2wj`）

- 空: 「まだプロジェクトがありません」＋最初のプロジェクトを作る
- 読込中: 骨組み
- エラー: 「一覧を読み込めませんでした」＋もう一度読み込む
- 上限: 「今月の生成上限に達しました」（または「今日の上限」「失敗が続いたため一時停止」）＋課金プランを見る。数字は実際の値を出し、取れないときは「—」

## 5. データと API

`docs/hq-banner-generation.md` を正本とする。要点:

- 表: `banner_projects` / `banner_generations` / `banner_images` / `banner_image_deliveries` / `banner_usage_ledger`。画像の実体は `media`
- API: `/api/hq/banners/...`（統括の管理者・オーナーのみ）。生成は「条件を登録」→「1枚ずつ run」の 2 段
- 設定: `OPENAI_API_KEY`（secret）、`OPENAI_IMAGE_MODEL`（既定 gpt-image-2）、`BANNER_MONTHLY_IMAGES`、`BANNER_IMAGE_QUALITY`

## 6. 権限

| 役割 | できること |
|---|---|
| オーナー・管理者（統括） | すべて |
| 担当者（staff） | 統括のバナー生成に入れない（403） |
| 閲覧のみ | 一覧・詳細の閲覧とダウンロードのみ。生成・渡す・外すはできない |
| 別の統括 | 何も見えない（404） |

## 7. 合格条件

1. 35-1 で作ったプロジェクトが一覧に出て、名前変更・お気に入り・アーカイブ・復元が反映される
2. 35-2 でテキスト3行・色・用途を指定して生成すると、35-2-A を経て指定枚数の画像がグリッドに並ぶ。途中で「残りをやめる」を押すと、それ以降は増えない
3. 生成した画像が統括の登録メディア（店舗に属さない）として保存され、店舗の登録メディア一覧には出ない
4. 35-3-A で店舗を選んで渡すと、その店舗の登録メディア一覧に同じ画像が出て、配信の画像メッセージで選べる。同じ店舗へ二度渡しても 1 件のまま
5. 一覧から外した画像は 35-3 に出ないが、渡した先の店舗では残る
6. 今月・今日の残り枚数が生成のたびに減り、上限を超える生成は事前に断られる（35-4 上限の状態）。15分以内に3回失敗が続くと自動で止まり、理由が出る
7. 担当者・別の統括の権限で API と画面の両方が拒否される
8. 1440px・1920px で横スクロールが出ない。設計画像と実装画像の目視比較で位置・寸法・文字・色が一致

## 8. 未決・要確認

- LINE 規格サイズ（1040×1040、2500×1686 など）への正確なリサイズ。P1 は API の大きさのまま保存し、リッチメニューは 1536×1024（比率 1.5）で LINE の下限 1.45 を満たす
- 参照画像つき生成・指示文による編集・背景除去・高画質化（P2）
- 月間上限を料金プランの値に置き換える時期（36 課金プランに依存）。仮の値: ライト 50／スタンダード 150／プロ 500、トライアル 20
- 縦横比が違う用途（3:1、9:16、4:5、16:9 など）の切り抜き処理。Cloudflare Images か WASM での整形を P2 で決める
