# V6 要件定義

Pencilの正本 **★V6 260画面**を、32機能の要件へ落とした文書群です。

- 機能別要件: 32本
- 次工程の横断文書: 5本
- 正本化の決定・進捗台帳: 2本

最初に [`v6-requirements-master-index.md`](./v6-requirements-master-index.md) を読み、共通基盤を確定してから、実装ロードマップの順に機能別Issueへ分けます。

PencilのNode IDは見た目の正本を指します。実装時は同じNode IDの1920px画像と、1440px・1920pxの実装画像をPRへ添付します。
