# V6 正本化の決定

更新日: 2026-08-26

## 決定

**V6をデザインと要件定義の正本にする。V5画面は廃止対象とする。**

理由:

- 32本の要件定義がV6実Node IDを参照している
- V6は当日のV5修正を含む複製で、260画面すべてが要件と対応している
- V5を残すと、実装者が旧版を参照する危険がある
- V5を正本へ戻すと、要件定義260件のNode ID差替えと再検証が必要になる

1. Pencil文書をアプリ側で複製し、削除前backupを作る
2. V6 260画面と要件Node ID 260件の対応を再確認
3. `★ V5 `で始まるtop-level 260画面を削除
4. `S6umap`を`V6 デザイン基盤｜トークン正本`へ改名し、画面数の集計対象外にする
5. 残存数を確認: V6画面260＋デザイン基盤1＋資料1
6. `docs/v5-common-rules.md`をV6表記へ更新し、Node ID参照を検査
