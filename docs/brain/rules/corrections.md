# corrections.md — 修正指示の蓄積(恒久ルール)

> オーナーから受けた「こう直して」「こうして」を **1 件 3 行**で蓄積する。全エージェントは起動時にこれを読み、ここに書かれた指示を恒久的に守る。同じことを二度言わせない。

## 書き方

```
## YYYY-MM-DD
- 指摘: (オーナーが何を直してほしいと言ったか。具体的に)
- 今後: (次から自分がどう動くか。「する / しない」で)
```

## 運用ルール(AI 向け)

- 訂正・要望を言われたら、**その場で**ここに追記する(司令塔がまとめてもよいが、後回しにしない)。
- 抽象的に書かない。「丁寧に」ではなく「見出しは体言止めにする」のように行動で書く。
- 既存と矛盾する新しい指示が来たら、古い行に `(YYYY-MM-DD 更新)` を付けて最新を優先する。
- 月に一度、重複・解決済みを整理する。
