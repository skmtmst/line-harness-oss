# mistakes.md — やらかしと再発防止

> 実際に起きた失敗を記録し、二度と繰り返さないルールに変える。`corrections.md` が「先回りの指示」なら、こちらは「起きた失敗の振り返り」。

## 書き方

```
## YYYY-MM-DD
- やらかし: (何をして、何が問題だったか)
- 原因: (一言で)
- 再発防止: (いつ・何を確認するか。トリガー付きで)
```

## 運用ルール(AI 向け)

- 同じミスを 2 回指摘されたら必ず記録する(1 回でも重大なら記録)。
- 「気をつける」で終わらせない。**いつ・何を確認するか**まで書く。
- 定着したルールは `corrections.md` か `AGENTS.md` に昇格させ、ここからは整理してよい。
