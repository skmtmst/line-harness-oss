# Pencil の AI へ渡す修正指示(★V6・2026-09-03)

使い方: Pencil を開き、AI に「共通の前提」を最初に貼ってから、下の項目を **1 件ずつ**貼る。1 件ごとに絵を見て確認し、よければ次へ。直した項目は `docs/v6-requirements/v6-32-feature-cross-review.md` §7 の該当行に反映日を書く。反映した画面は html-css で書き出し直し、`docs/design-reference/<機能>-v6/` を更新する。

## 共通の前提(最初に 1 回貼る)

```
あなたは LINE 公式アカウント CRM「LINE Harness」の管理画面デザイン ★V6(260 画面、1920×1080)を直す。守ること:
- 画面の骨組みは変えない: 共通メニュー J33xq(幅 256)、共通トップバー cBSCb(高さ 56)、メイン(padding 14/40/32/40)、オーバーレイは absolute。
- 共通部品は参照(ref)で置く。複製して描き直さない。追従バーは削除を左・他は中央。
- 色は S6umap のトークンだけを使う。主ボタンは背景 #068a3c + 白文字(決定済み)。LINE の緑 #06c755 は選択状態・チップ・有効表示にだけ使う。
- 文言はひらがな優先、内部語(dry-run、AND/OR、Flex、Webhook 同一 ID、{{name}})を出さない。表記は「すべて」「対応済み」「未割り当て」。
- 見本データは 1 セット(友だち 231 人、配信 24 件、シナリオ 5 本)で全画面をそろえる。
- 1 件直したら止まって報告する。指示に無い場所を直さない。
```
