## Claude共通受け入れ条件

1. 契約PRのheadを固定baseにする。
2. 同梱された通常・空・失敗の固定データを使う。
3. 押し口へ `data-qa-open` を付け、文言変更で撮影が空振りしないようにする。
4. 読込・空・失敗・権限不足を分け、未取得を0として表示しない。
5. 1440px・1920pxでページと一覧の横スクロールが0であることを確認する。
6. 作者自身の画面にも、見える文言と状態を固定する契約テストを付ける。
7. 使用先の差し替え・アーカイブなど契約外の差が残れば、`match` にせず `needs_fix` を維持する。

## 止める条件

- 同じファイルを触る新しいopen PRが見つかった。
- 固定baseのheadが動いた。
- APIの返却形が引き継ぎ文書と違う。
- 契約固有のCI失敗が出た。
- Worker・DB・migration・APIの追加変更が必要になった。

この場合は画面側で推測して埋めず、Node ID、ルート、必要な値、通常・空・失敗の違いをCodexへ返します。
