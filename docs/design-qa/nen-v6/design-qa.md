# P0 4件、すべて直りました

## P0-1 「失敗 —／失敗の記録がありません」の隣に失敗が1件 → 直った

いまは **`失敗 6件／失敗した配信を確認してください`** です。

```tsx
{overview?.jobs.failed ?? '—'}
…
{overview ? (overview.jobs.failed === 0 ? '失敗の記録はありません' : '失敗した配信を確認してください') : '確認できません'}
```

**3つに分かれています。** 取れて0なら「記録はありません」、取れて1以上なら
「確認してください」、取れていなければ `—` と「確認できません」。
**未取得と実値0が、数字でも文でも分かれました。**

「待機中」も `jobs.length`（読み込めた分の数）から
`overview?.jobs.pending ?? '—'` に変わり、**148件**と出ます。

## P0-2 「発送完了から-3日後」 → 直った

**`お誕生日クーポン／誕生日の3日前 10:00`** と出ます。

`formatCampaignTiming`（`campaign-display.ts`）が `campaignKey` で
言い分けています。**文言だけの話ではありません。**
`birthdayDeliveryTarget`（`nen-engagement.ts:414-429`）が3日先の誕生日を
探し、当日の 01:00 UTC（＝10:00 JST）に予約します。**画面の言葉と、
実際に送る日が合っています。**

## P0-3 配信履歴の日時が生のUTC → 直った

**`予定：2026/08/25 20:00`** です。もとの値は `2026-08-25T11:00:00.000Z`。
`formatNenJobDateTime` が `timeZone: 'Asia/Tokyo'` で整えます。
読めない値には「日時を確認できません」が出ます。

## P0-4 読み込みに失敗した一覧が「0件」と言う → 直った

失敗のとき、**画面ごと**「表示できませんでした／フォロー配信の情報を
読み込めませんでした。／［フォロー配信を再読み込み］」に置き換わります。
**0件の札はどこにも出ません。**

`data-list-state` も `loading` / `error` に分かれました（前回は3つとも
印が無く、機械では見分けられませんでした）。

## P1-3 編集画面には、誕生日の3日前が出ない

**前回ここに「編集画面が -3 を表せない」と書きましたが、取り下げます。**
誕生日の3日前は `delay_days` ではなく `birthdayDeliveryTarget`
（`nen-engagement.ts:414-429`）が決めていました。種データの
`birthday_coupon` は `delay_days = 0` で、**負の数はどこにも入りません。**
こちらの固定データが `pet_birthday` / `-3` という**実在しない形**で
書かれていたための誤りです。

そのうえで残る差はこれです。編集画面（`/nen-campaigns/edit?key=birthday_coupon`）は
「何日後に送るか」と「0 なら当日です。」を出しますが、
**誕生日配信ではその欄が効きません。** 一覧は「誕生日の3日前 10:00」と
出るのに、編集画面は「0日後」に見えます。

**直し方：** `campaignKey === 'birthday_coupon'` のときは日数の欄を隠し、
「誕生日の3日前に送ります（時刻だけ変えられます）」と出す。
一覧が使っている `formatCampaignTiming` をそのまま置ける。

## P1-4 画面の名前が、メニューの名前と違う

メニューと上の帯は「NEN配信」、見出しは「フォロー配信」です
（`VLMGH-1440.png`）。設計はどちらも「NEN配信」です。

押した名前と着いた先の名前が違うと、**着いた場所が合っているかを
確かめられません。**

## P1-5 押せない操作が、理由なしに3つ置いてある

見出しの右に「マニュアル」「並び替え」「フォルダを追加」があり、
**3つとも `disabled`** です。Playwright で確かめました。

さらに上の帯には**押せる「マニュアル」**があります。同じ名前が2つあって、
片方だけ押せます。

**直し方：** 使えないなら出さない。出すなら「まだ用意していません」と
理由を添える。

## P1-6 ペット・記念日に、設計の帯と表が無い
