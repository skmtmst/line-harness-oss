## 未取得と実値0が、型で分かれています

数はすべて `AnalyticsMetric<T>`（`{value, state, reason}`）で返ります。

| 出方 | 意味 |
|---|---|
| **0円** | 広告費が本当に0（店頭QRは広告を出していない） |
| **—** | 広告側の費用を取り込んでいない（値が無い） |

**判定ルールの「未取得は `—`、実値0は `0件`」を、実装が型のレベルで守っています。**
これは設計より進んだ形です。設計はどちらも数字で描いています。

## 固定データ

`AnalyticsMetric` の3つ組で書いています。**未取得を 0 と書かないこと**を、
固定データの側でも守っています。

| 混ぜたもの | なぜ |
|---|---|
| 広告費が取り込めていない経路 | `—` と `0円` の描き分けを確かめるため |
| 20人未満で開封が取れない配信 | LINEの制約。`null` ＋ 理由で崩れないか |
| 配った人数が取れないリンク | 押された数は分かるが割合は出せない、が出るか |
| 一度も押されていないリンク | **0件**（未取得ではない）と描けるか |
| 一度も使われていない種類 | 最後に使った日が未取得（0ではない） |
