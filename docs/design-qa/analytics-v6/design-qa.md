### 当時の記録（`724f9324`）

一覧の列は 分析名／種類／作成者／定義版／最新の期間／結果 です。
**`latestSnapshot.state` の列がありません。**

型は4つに分かれています（`SavedAnalyticsSummary`）。

| `state` | 意味 |
|---|---|
| `available` | 取れた |
| `partial` | **一部だけ取れた** |
| `unavailable` | 取れなかった |
| `failed` | 失敗した |

固定データに `available` / `partial` / `unavailable` を混ぜて撮りましたが、
**一覧では3つとも同じ見た目**です。

```
体験申込までの流れ（8月）  ファネル  川野 健太  第3版  2026-07-27〜2026-08-25  4件   ← available
タグ×流入経路のクロス      クロス分析 菅野 亮    第1版  2026-07-26〜2026-08-24  2件   ← partial
資料からの申込            ファネル  川野 健太  第2版  2026-07-22〜2026-08-20  1件   ← unavailable
```

**一部しか取れていない分析を、取れたものとして読むことになります。**
下の「結果の履歴」を開くと「利用可能」と出ますが、**1件ずつ開かないと
分かりません。**

なお、まだ一度も取っていないもの（`latestSnapshot: null`）は
**期間が `—`、結果が `0件`** で、ここは正しく分かれています。

**推奨：** 一覧に状態の列（または名前の横の札）を足す。
`partial` と `unavailable` は色を分ける。

| 書いていた値 | 出ていた表示 | 直した値 |
|---|---|---|
| `conversionFromPrevious: 68.7` | **6870%** | `0.687` |
| `clickRate: M(16.9)` | **1690%** | `M(0.169)` |

**割合であることは型ではなく値の慣習で決まっています。**

画面が自分で計算した数と食い違って見えます。
