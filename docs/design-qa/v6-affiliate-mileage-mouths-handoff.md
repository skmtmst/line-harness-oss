# V6 案件一覧・アフィリエイター追加・たまる決めごとの引き継ぎ

対象は `GH8VL`（V6 16 案件タブ）、`xqT1Z`（アフィリエイターを追加する）、
`N46cQ`（V6 17 たまる決めごと）です。設計にあるが**口が無いため作らなかった**
ものを、Codex 側へ渡すために残します。

画面側は「読み込んだ行から数えられるものだけ動かす」方針で組みました。
検索・絞り込み・並び順・表示件数・ページ送り・CSV書き出しは、一覧が全件を
読んでいるので画面の中で組み立てています（`app/affiliates/offer-list-view.ts`、
`app/mileage/earning-rule-view.ts`）。

## 足りない口（API側の実装が要るもの）

### 1. 並び順を覚える（`GH8VL` / `N46cQ`）

設計はどちらの一覧にも「並び順を保存」がありますが、並び順を覚える口が
ありません。**押しても何も起きないボタンになるので置いていません。**

要るもの（案）:

- `GET /api/list-preferences?screen=affiliate-offers`
- `PUT /api/list-preferences?screen=affiliate-offers` — `{ sort, pageSize, filters }`

画面ごとに1行あればよく、テナント単位ではなく操作する人ごとに持ちたい。

### 2. 案件の並び替え（`GH8VL`）

`affiliate_offers` に並び順の列がありません。いまは作成日・名前・報酬額から
その場で並べています。運用者が手で並べ替えるなら、行に `sortOrder` が要ります。

- `PUT /api/affiliate-offers/reorder` — `{ ids: string[] }`

### 3. アフィリエイターの追加で決められない4つ（`xqT1Z`）

設計にありますが、`POST /api/affiliates` も `PUT /api/affiliates/:id` も受けません。
画面では `—` と「まだ繋がっていません。○○が接続されると表示されます。」を
出しています。

| 設計の項目 | 要る列・口 |
| --- | --- |
| 友だち検索（友だちから選ぶ） | `affiliates.friend_id` を作成・更新で受ける。友だち検索は既存の `GET /api/friends?search=` を使える |
| 1件あたりの上限 | `affiliates` に上限回数の列。いまは案件側にも無い |
| 振込先の登録 | 口座情報の置き場。個人情報なので、置き場と権限を先に決める必要がある |
| 成果時の動き | 紹介者ごとのタグ付け・シナリオ開始。いまは案件（`affiliate_offers`）側にしかない |

**「1件あたりの報酬」「成果として数えるもの」「対象アカウント」は口が無いのでは
なく、案件側で決まるもの**です。こちらは「案件ごとに決めます」と理由を出して
います。混ぜないでください。

### 4. 紹介URLのコピー（`xqT1Z`）

紹介コードを空欄にすると worker が自動で作るため、保存前はURLが決まりません。
入力したコードがあるときだけコピーできる形にしています。自動採番のコードを
保存前に見せるなら、`POST /api/affiliates/preview-code` のような口が要ります。

### 5. たまる決めごとの一覧（`N46cQ`）

`GET /api/mileage/rules` はページングを持たず全件返します。件数が増えたら
`limit` / `offset` が要ります。いまは全件を読んでから画面で絞り込んでいます。

## 設計と実装で寸法が合わないところ（部品側の話）

いずれも共通部品が持つ寸法で、1画面のために動かすと他の画面が一緒に動きます。
部品を直すときにまとめて見てください。

| 設計 | 部品 | いまの値 |
| --- | --- | --- |
| 検索欄 h40 | `components/shared/search-field` | 42px |
| 表示件数・並び順 h40 | `components/shared/select` | 42px |
| 絞り込み札 h36 | `components/shared/filter-chip` | 32px |
| 追従バーのボタン h40 / 13px | `components/shared/button` | 36px / 13px |

幅は設計どおりです（検索460px、表示件数128px、右カラム390px、作成画面の
入力欄360/340/320/220/200px）。

## この変更で入れた版

`components/shared/create-page.tsx` に `variant="v6"` を足しました。渡した画面
だけ、カードの角丸10px・余白18px・行間12px、節の見出し16/700・補足11/500、
右カラム390px、保存を下部追従バーへ、という設計 `xqT1Z` の寸法になります。
既定は従来のままなので、ほかの作成画面は動きません。1画面ずつ設計と
突き合わせて `variant="v6"` を足していってください。
