## P2 409のとき、案内が的外れ

`POST /api/broadcasts/:id/cancel` を 409 にして押すと、窓の中に

> 予約を取り消せませんでした。**通信を確認して**、もう一度お試しください。

と出ます。日本語で、内部の言葉（`API error` `409` `Only scheduled` など）は
**ひとつも出ていません**。そこは満たしています。

**ただし、通信は切れていません。** ほかの誰かが先に取り消したか、送信が
始まったかで、**状態が変わった**のです。「通信を確認して」は直しようのない
案内になります。

**正しい文はもう書いてあるのに、届いていません。**

```ts
// broadcasts/reserved/page.tsx:112
const result = await api.broadcasts.cancelReservation(broadcast.id)
if (!result.success) {                       // ← ここへ来ない
  setCancelError(
    result.error?.includes('no longer scheduled') || result.error?.includes('Only scheduled')
      ? '予約の状態が変わっています。画面を読み直して確認してください。'
      : '予約を取り消せませんでした。状態を読み直して、もう一度お試しください。',
  )
```

`fetchApi` は 2xx でなければ**投げます**（`lib/api.ts:384`）。409 は投げられて
`catch` に落ちるので、`if (!result.success)` の枝は通りません。さらに
`BODY_MESSAGE_STATUSES` は **400 だけ**なので、`{error:'Only scheduled…'}` の
本文も捨てられます。

**推奨修正**（`Lg8ff` と同じ形）

```ts
} catch (cause) {
  if (cause instanceof ApiError && cause.status === 409) {
    setCancelError('予約の状態が変わっています。画面を読み直して確認してください。')
    return
  }
  setCancelError('予約を取り消せませんでした。通信を確認して、もう一度お試しください。')
}
```

## P2 人数が読めないときの見出しが日本語として切れる

> 2026/08/24 10:00に、**人数を送信前に再集計して**へ配信します。

「〜してへ配信します」になります。`{estimate ? \`${n}人\` : '人数を送信前に再集計して'}へ配信します`
と、助詞まで含めて差し込んでいるためです。人数が読めないときは
**文ごと**替えるほうが読めます（例「2026/08/24 10:00に配信します。人数は送信前に数え直します。」）。
