（`Dialog` の作り）。押せそうに見えるボタンが残りません。

除外の人数は**数としての口がまだ無い**ので、`preflight.warnings` に文が
来ないときは `—`＋「除外した人数はまだ取れません」。**0人と書きません。**

# 送信対象数を固定値で作っていません

```tsx
const audienceCount = preflight?.audienceCount ?? null
```

`runPreflight()` が数えたぶんだけを使います。数えられていないときは
`null` のままにして送らせません。**「たぶんこのくらい」を書くと、
その数を根拠に押されます。**
