# #447 で入ったもの：戻す理由をえらぶ窓（`N2J629`）

前は「見送る」を押した**その瞬間に確定**し、理由は残りませんでした。
いまは窓が開き、理由を5つから選んで補足を書けます。
投稿者へLINEで届いたかどうかも、あとの知らせに出ます
（`notificationStatus === 'sent'` で文言を分けています）。

**設計と同じ形（窓）で、同じ狙い（理由をえらぶ→文が自動で作られる）です。**

## それでも違うところ

| | 設計 | 実装 |
|---|---|---|
| 誰の写真か | レオくん／大西 健一さん **8/24 18:22 に届きました ／ この方を戻すのははじめてです** | 写真だけ。名前も日時も、前に戻したことがあるかも出ない |
| 理由 | 4つ。**それぞれに届く文が添えてある**（「うしろに他のお客様が写っているようです。もう一度お願いできますか」） | 5つ。**文は添えていない**。選ぶまで何が届くか分からない |
| 届く文 | 「お客様にはこう届きます（**直せます**）」＝書き直せる欄 | 「投稿者に届く内容」＝**読むだけ。直せない** |
| もう一度お願いする | 「文章のあとに『写真を送る』ボタンを付けます。」を選べる | 無い |
| 次から必ず人が見る | 「この人の次の投稿は、必ず人が見る／自動で通す対象から外します。」 | 無い |

## P1-1：届く文を直せない

設計はわざわざ「（**直せます**）」と書いています。写真は1枚ずつ事情が違い、
決まり文句だけでは足りないことがあります。

**この文はお客様に届きます。** 直せないと、当てはまらない文をそのまま
送るか、送るのをやめるかの二択になります。

## P1-2：選ぶ前に、何が届くか分からない

設計は理由の札そのものに文を添えています。実装は選んでから下の枠に出ます。
**5つを順に押して読み比べないと選べません。**

## P1-3：誰の・いつの写真かが窓に出ない

設計は「8/24 18:22 に届きました ／ **この方を戻すのははじめてです**」まで
出します。**同じ人を何度も戻していないかは、送る前に知りたいこと**です。

# `Qu6Vk` 写真審査

## P0：届いた日時が、生のUTCで出る

札に `2026-08-22 09:22` と出ています。もとの値は
`2026-08-22T09:22:00.000Z` で、**日本時間では 18:22** です。

```tsx
{text(photo.created_at).replace('T', ' ').slice(0, 16)}
```
（`nen-members/page.tsx:166`）

`T` を空白にして16文字で切っているだけで、**`Z` を捨てています。**
9時間ずれます。設計の窓が「8/24 **18:22** に届きました」と書いているのは、
同じ `09:22Z` を日本時間で出したものです。

審査は古いものから順に見ます。**日時がずれると、その順番がずれます。**
