LINEアカウントを登録

送受信に使うLINE公式アカウントを登録します。保存する前に接続を確かめます。

基本情報

管理画面で見分ける名前を付けます。登録後も変更できます。

表示名必須

タイムゾーン

Asia/Tokyo

国・地域

登録後に設定できます

役割メモ（任意）
親アカウント（任意）

Messaging API

LINE公式アカウントからメッセージを送受信するための必須情報です。

チャネルID必須
チャネルシークレット必須
チャネルアクセストークン必須

資格情報は暗号化して保存し、保存後は画面に再表示しません。

友だち追加・LIFF

LINE Login や LIFF を使う場合だけ入力します。あとから追加できます。

LoginチャネルID
Loginチャネルシークレット
LIFF ID

保存する前の接続確認

「接続を確かめて保存」を押すと、次の順で確かめます。どこかで止まったら保存しません。 確かめるだけで、記録は残りません。

1
LoginチャネルID・シークレット・LIFF IDの形
確かめていません
2
アクセストークンが使えるか
確かめていません
3
LINE側に登録したWebhookのURLと、利用する設定
確かめていません
4
Webhookに実際に届くかのテスト
確かめていません
