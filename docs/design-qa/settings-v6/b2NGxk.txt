LINEアカウントを登録

送受信に使うLINE公式アカウントを登録します。保存する前に接続を確かめます。

基本情報

管理画面で見分ける名前を付けます。登録後も変更できます。

表示名必須
タイムゾーン必須
Asia/Tokyo
国・地域（任意）
役割メモ（任意）
親アカウント（任意）
選んでください

Messaging API

LINE公式アカウントからメッセージを送受信するための必須情報です。

チャネルID必須
チャネルシークレット必須
チャネルアクセストークン必須

資格情報は暗号化して保存し、保存後は画面に再表示しません。

友だち追加・LIFF

LINE Login や LIFF を使う場合だけ入力します。あとから追加できます。

LoginチャネルID
Loginチャネルシークレット
LIFF ID

保存する前の接続確認

「接続を確かめて保存」を押すと、次の順で確かめます。どこかで止まったら保存しません。 確かめるだけで、記録は残りません。

3 で止まりました。右の「Webhookのつなぎ先」にあるURLを LINE Developers のチャネル設定に貼り、「Webhookの利用」をオンにしてください。 4 は 3 が通るまで確かめられません。
