## 状態の言葉

**8つの状態がすべて日本語で、英語の内部語は1つも出ません。**

| 台帳の状態 | 画面の言葉 |
|---|---|
| `success` | 動きました |
| `partial` | **一部だけ動きました** |
| `skipped_condition` | **動きませんでした**（したこと：条件に合わなかったため、何もしていません） |
| `failed` | 失敗しました |
| `running` / `waiting` / `queued` | 処理中です |
| `cancelled` | 取り消しました |

**「一部だけ」と「動きませんでした」と「失敗しました」が別の言葉と色です。**
`skipped_condition` を「成功」にも「失敗」にも寄せていません。

失敗の理由も日本語に置き換わります
（`safeFailureReason`：`line_api_error` → 「LINEへの送信を完了できませんでした」、
`webhook_*` → 「外部連携先が応答しませんでした」）。
**`failure_code` はそのままでは出ません。**

## 未取得「—」と実値0

**空と失敗で、同じ画面が違う数を出します。**

| | 空（取れて0件） | 失敗（取れていない） |
|---|---|---|
| この30日に動いた | `0回`（1日あたり 0回） | **`—回`** |
| いちばん動いた | **`—回`**（並べる元が無い） | **`—回`** |
| 失敗した | `0回` | **`—回`** |
| 条件に外れて動かなかった | `0回` | **`—回`** |
| `data-list-state` | `empty` | `error` |
| 「ありません」「0件」 | 一覧だけ | **出ない** |

**空のときも「いちばん動いた」は `—`。** 実値0と未取得が
**同じ画面の中で**分かれています。ここがいちばん見たかったところです。

行の中でも、処理中と取り消しの「したこと」「かかった時間」は `—` です。
友だちが取れない行は **「対象は未取得」** と出ます（空欄にしていません）。
