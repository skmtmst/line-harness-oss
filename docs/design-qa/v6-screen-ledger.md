# V6 全画面 台帳

Pencil の V6 設計ノード **262枚**を、機能ごとに並べたものです。
実装画像と比べた結果はこの表で管理します。

Node ID は Pencil の実ノードから機械で引いて突き合わせてあります
（262件、取り違えなし）。実装ルートは `apps/web/src/lib/menu.ts` の
`href` が正です。

## 判定は4つ

| 判定 | 意味 |
|---|---|
| **一致** | 設計と実装を並べて確かめ、差が無い |
| **未一致** | 差がある。**基準画像を合格として扱わない** |
| **未実装** | 実装が無い。**合格画像にしない。比較待ちとして残す** |
| **取得不能** | 実装は在るはずだが描けない・辿り着けない。理由を書く |
| 比較待ち | まだ撮っていない |

**差がある画像を基準画像として合格扱いしません。** 基準画像
（`scripts/visual-qa/capture.spec.mjs-snapshots/`）が見張るのは
「前回から変わっていないか」だけで、設計に合っているかはこの台帳だけが言えます。

## 設計画像の出し方

Pencil の `png` 書き出しは砂嵐になるので使えません。`html-css` で書き出して
Chromium で実寸描画し、幅1920・ノードの高さで撮ります。

`fullPage` は `position: fixed` を最初のビューポート位置に焼き込むので、
ドロワー・ダイアログは**設計の高さでビューポートを開いて**撮ります。
