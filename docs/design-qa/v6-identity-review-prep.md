# 「候補を1件ずつ判定する」画面：先回りの準備

**日付**：2026-08-30 ／ 対象：`InCDe`（3-2-A 重複候補詳細）・`ELayY`（23-1-A 会員のつき合わせ）
**この文書はアプリを変更しない。** APIのheadが届く前に、撮る道具だけ用意する。

> **`screens.mjs` の2行は `unimplemented` のままにしてある。**
> API head が届くまで、実装済み扱いにも画像合格にもしない。

## いちばん大事なこと：この2枚は同じ形で作れる

| | `InCDe` | `ELayY` |
|---|---|---|
| 何と何を突き合わせるか | 友だち ↔ 友だち | ECの注文 ↔ LINEの友だち |
| やること | **2件が同じ人かを、根拠を見て決める** | **同じ** |
| 判定 | pending / linked / different / deferred / invalidated | **同じ** |

**違うのは中身だけで、画面の作りは同じ。** 別々に作ると、**画面も試験も二重に持つ**ことになる。
固定データも1つの器（`IDENTITY_CANDIDATE`）にして、`left` の `kind` だけ変えている。

## いま止まっている理由

- `InCDe`：`/api/duplicates/stats` は**件数と重複マトリックスだけ**を返す。候補行・根拠・判定状態が無い
- `ELayY`：`ec_events` は未照合のeventを持てるが、**候補の根拠・判定・再提示抑止・影響確認を保存する口が無い**

## 想定ルートと操作手順

**どちらも「想定」で正本ではない。**

- `InCDe`：`/friends/duplicates/review?id=dup-1`
- `ELayY`：`/ec-commerce/identity/review?id=idc-1`
- 想定の口：`GET /api/identity-candidates/:id`、`POST /api/identity-candidates/:id/decide`

**押し口**：`data-qa-open="InCDe"` / `data-qa-open="ELayY"`。

## 固定データ案（`fixtures.mjs` に入れてある）

`IDENTITY_CANDIDATE` / `_DIFFERENT` / `_EC` / `IDENTITY_CANDIDATES_EMPTY`。

**入れてある要点**

1. **根拠を重みつきで持つ**（`確認済みのメールアドレスが同じ` = strong、`表示名が似ている` = weak）。
   **根拠を出さないと判定できない。**
2. **突き合わせる2件をどちらも残す**（非破壊）。片方を消す形にしない。
3. **結びつけると何が変わるかを、押す前に見せる**（`impact`）。
   **取得元が無いものは `null`** にしてあるので、**画面が `—（未取得）` と書くか、
   0と混ぜないか**をこの1枚で確かめられる。
4. **一度「別人」と決めたものを残す**（`_DIFFERENT`）。
   **消すと、また候補に出てくる。** 再提示の抑止は要件 §9。
5. **判定の履歴を持つ**（だれが・いつ・なぜ）。「本人に確認中」で保留した記録も入れてある。

## 5状態の出し分け

| 状態 | 見どころ |
|---|---|
| 通常 | 根拠2件・影響3項目（うち1つは `—（未取得）`） |
| 読込 | 「読み込んでいます」 |
| 空 | **「もう見るものがありません」と「読めなかった」を分ける** |
| 失敗 | 「**判定した記録は消えていません。**」 |
| 権限不足 | **「読めなかった」と混ぜない。** 候補の中身（個人情報）も出さない |

**権限不足のとき中身を出さないのは、この画面では特に重い。**
メールアドレスと電話番号が並ぶので、**権限の無い人に見せてはいけない。**

## 必ず見ること

- **根拠を出してから判定させる**（根拠なしで押させない）
- **結びつける前に、何が変わるかを数で見せる**
- **「別人」と決めたものが再び候補に出ない**
- 取得元が無い影響は **`—（未取得）`。0と混ぜない**
- 権限不足のとき**個人情報を出さない**
- 判定は**取り消せるか**を書く（要件 §11 は非破壊を求める）
- 1440px・1920pxで横スクロール0
- `undefined` / `NaN` / `Invalid Date` / 内部ID を出さない
