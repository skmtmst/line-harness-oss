## いちばん先に片づくのは「既存部品で作れる」19枚

- 削除がブラウザの `confirm()` のまま、または導線ごと無い … 9枚

「配信を予約する」が `save()` を直に呼び、**1,284人へ送る操作に
確認の段がありません。**

### `s6MBc` について（2026-08-28 分類を直しました）

前は「既存APIで作れる」に置いていましたが、**取り下げます。**
`scoring_rules` と `/api/scoring-rules` は在りますが、V6が要るものに
届きません。

| V6が要るもの | いまの `scoring_rules` |
|---|---|
| LINEアカウント単位 | **アカウント単位でない** |
| 下書き・テスト・公開 | **無い** |
| 公開版の固定と版履歴 | **無い** |
| 冪等性 | **無い** |
| 頻度上限 | **無い** |
| スコア帯（高い・ふつう・低い） | **無い**（`z3PB2` の画面側だけが持っている） |

**CodexがDB・API基盤を実装中です。** こちら（Claude側）は実装せず、
**V6設計との差分整理だけ**続けます。
