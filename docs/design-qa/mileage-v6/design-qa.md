# ~~P1-1 `k8VCU`：読込・空・失敗が同じ絵になる~~ → **直りました（`e953109c`）**

3つとも別の文言になり、`data-list-state` も `loading` / `empty` / `error` に
分かれました（前回は3つとも印が無く、機械では見分けられませんでした）。

| 状態 | 設計 | 実装 |
|---|---|---|
| 読込 | 読み込んでいます／このまま少しお待ちください。 | **たまる決めごとを**読み込んでいます／このまま少しお待ちください。 |
| 空 | まだ決めごとがありません／どんなことをしたら何マイル付けるかを決めます。／決めごとを作る | **文言まで同じ** |
| 失敗 | 表示できませんでした／再読み込みしても直らない場合はエラー報告へ。 | **たまる決めごとを**表示できませんでした／同じ／**＋［決めごとを再読み込み］** |

**実装が足しているのは2点だけ**です。見出しに主語を付けたことと、
失敗に再読み込みのボタンを増やしたこと。**どちらも設計に反しません。**

`loadError` と `actionError` が分かれたので、**読み込みの失敗と
操作の失敗が混ざりません。**
