## 直したいこと

### P1-1 失敗すると「API error: 405」が画面に出る

`/mileage/score-rules` の `fieldError` が、`ApiError` の `message` を
そのまま返しています。`ApiError` は 400 以外では
`API error: <番号>` に落ちる作りなので、**403・405・500・502 が
そのまま利用者に見えます。**

証拠：`s6MBc-evidence-stop-failed-1440.png`。窓の中とページ下の2か所に出ます。

**同じ機能の隣の画面はできています。**
`apps/web/src/app/mileage/friends/detail/mileage-adjustment-dialog.tsx` は
400 だけ本文を通し、403・404・405・409 を日本語に置き換え、
最後は「時間をおいてもう一度お試しください」に落としています。
**そこへ寄せてください。**

- 直す場所：`apps/web/src/app/mileage/score-rules/page.tsx` の `fieldError`

### P1-2 一覧の文字が切れて読めない

行がそのまま編集フォームで、欄が狭い。1440px で
「こちらに返信し**た**」「メッセ…」「同じ対…」「行動す…」が切れ、
「同じ記録は1回だけ」も途中で折り返します。1920px でも同じです。

**設計は一行1件の読める一覧です。** 名前・きっかけ・点数・回数を
文で見せ、編集は行を開いてから。読む場面と直す場面を分けてください。

証拠：`s6MBc-normal-1440.png` / `s6MBc-normal-1920.png`

## 版履歴について

**設計にも実装にも面がありません。** `ActionScoreRuleConfiguration` は
`editableVersion` と `publishedVersion` の2つしか持たず、過去の版を
並べる口もありません（`apps/web/src/lib/api.ts`）。

V6設計に版履歴の画面が無いので、**いまは差ではありません。**
運用で「いつ誰が何版を出したか」を追う必要が出たら、
そこで初めて口が要ります。
