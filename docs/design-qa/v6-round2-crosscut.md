# 第2ラウンド：機能をまたぐ差（文字の突き合わせで出たもの）

`node scripts/visual-qa/compare-text.mjs --rollup` の結果を、**1件ずつ実物で
確かめてから**書いている。道具の出力をそのまま貼らない。

道具は「設計にあって実装に無い語」を数えるだけなので、**札の言い方が違う**のか
**機能ごと無い**のかを区別しない。そこは人が分ける。

## 1. LINEプレビュー（設計30枚）

**札の違いと機能の欠落が混ざっていた。**

| 内訳 | 枚数 |
|---|---|

| プレビューが1つも無い | 18 |

```

配信プレビュー ／ 〜のプレビュー
```

設計は「LINEプレビュー」。用語表に載せてそろえる。

### 1-2. 共通部品が無い

**段の進み表示（3番）と違って、ここは共通部品がそもそも無い。**
`components/scenarios/step-preview.tsx` と `components/forms/form-preview.tsx`
が別々に在るだけで、LINEの見た目を描く共通のものは無い。
「配る先を増やす」ではなく「作ってから配る」になる。

## 2. CSVで書き出す（設計23枚）

実装で「CSVで書き出す」を持つのは8か所だけ。
`/friends` `/affiliates` `/mileage`（行動スコア）などに在り、
重複検出・統合ユーザー・共通情報・分析・流入と計測・コンバージョンなどに無い。

**画面だけでは作れない。** 書き出しの口が要る（Codex側）。
ただし置き場と札は先に決められる（副次ボタン・右上）。

### 2-1. 置き場は直した（§7 #44）

CSV書き出しを持つ8画面のうち、**`/scenarios/results` だけが主要ボタン（緑）**
だった。この画面でいちばんしたいことは結果を見ることで、CSVに落とすことでは
ないので、ほかの7画面と同じ副次にそろえた。契約試験で見張っている。

## 4. 期間の言い方がそろっていない（設計14枚で「この30日」）

**「言い方だけ」と「数える日数が違う」が混ざっている。分けて扱う。**

### 4-1. 数える日数が本当に違うもの（言い方の前に、どれが正しいかを決める）

| 画面 | 窓 | 根拠 |
|---|---|---|
| `/conversions` | **28日** | `page.tsx:44`「設計のKPIはどれも『過去28日』で数えている」 |
| ダッシュボード | **28日** | `page.tsx:59` 期間の選択肢に `last28` |
| `/analytics` | **30日** | `page.tsx:1332` `rangeFor(29)`（両端を含めて30日） |

設計は 60回が「この30日」、10回が「過去28日」。
**28日を使う画面が本当に28日でよいのかは、設計を見ただけでは決まらない。**
先に窓を決め、そのあとで語をそろえる。

### 4-2. 語だけの違い（窓は同じ30日）

| いまの言い方 | 場所 |
|---|---|
| 過去30日 | `/staff`（3か所） |
| 直近30日 | `/analytics`（3か所）、配信の絞り込みの例文 |
| この30日 | `/webhooks`、`/analytics`（1か所） |

設計にそろえて **「この30日」** にする。同じ画面（`/analytics`）の中で
「直近30日」と「この30日」が混ざっているので、まずそこから。

## 5. 受信箱の右パネルに「予約・EC」が無い（設計16枚）

要件書 `v6-02-inbox-requirements-draft.md` §5-5 は右パネルに
「予約、回答、購入、成果、マイル」を求めている。

実装の右パネルが持つ節は9つ。

```
profile  names  tags  support  starred  richMenu  metadata  forms  mileage
```

**予約・購入・成果が無い。** 設計 `xGLVe` は「次回予約 8/24 14:00」
「注文 出荷準備中」を出している。

### 画面だけでは作れない

`api.ts` を見ると、**友だち1人ぶんの予約・注文を引く口が無い**。

| 口 | 引き方 |
|---|---|
| `/api/booking/admin/bookings` | アカウント単位。友だちで絞れない |
| `/api/ec-commerce/overview` | アカウント単位の集計だけ |
| 成果 | `conversions.track`（書き込み）はあるが、友だちで読む口が無い |

節だけ作ると「まだ繋がっていません」が3つ並ぶことになる。**口が先。Codex側。**

## 6. 固定データの差（直す対象ではない）

「本日8月19日のお知らせです。」「Kyohei Yamamoto」などは、設計とモックで
中身が違うだけ。道具は数値・日付・ファイル名を落としているが、
**文そのものは落としていない**ので出てくる。読み飛ばす。
