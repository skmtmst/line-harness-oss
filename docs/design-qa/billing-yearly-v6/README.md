# 課金プランの年払い：表示確認

監査基準: `b9bb842f24f0c1b546a9a442c88f1951a184aae3`（PR #34取り込み後）。
対象: `/hq/billing` の月払い・年払い。画面数は増やしていない。

Pencil `V6正本.pen` の実ノードを取得し、1920pxの設計画像と実装を比較した。
プロのボタンはMasatoの追加指示に合わせ、正本の月・年とも「このプランにする」に更新済み。
コードの旧ノードIDは新IDへ更新し、これまで未登録だった課金画面を `design-structure.json` に登録した。

実装画像はローカル専用の表示用データ。実際のStripe契約や顧客情報ではない。

確認したもの:

- 既定は月払い。年払いに切り替えると3カードに固定の「約15% OFF」が出る。
- 月あたり8,250円 / 25,250円 / 50,750円、年額99,000円 / 303,000円 / 609,000円。
- プロも他2プランと同じ申込みボタン。月払いへ戻すと従来の月額表示。
- 1440px・1920pxで3カードと切り替えが収まり、料金やボタンの欠けがない。
- 実コンポーネントのテストで未設定プランの無効化、再訪時の月払いへの復帰、送信周期、Stripe価格の優先・切り捨てを確認。

## 残っている視覚差分

**画面全体のV6完全一致とはしない。** 今回は現行の見た目を保つ依頼のため、
既存の共通シェル、更新通知、サイドバー表記、共通部品の配色・角丸・影、
カードの等高レイアウト、契約案内文、履歴の空表示の位置は変更していない。
これらは変更前から正本と異なる。`visualVerification` は `unverified` を維持する。
今回の切り替えは既存Toggleにページ固有の40×22pxを適用し、色は既存トークンを使う。
本物のStripeテストCheckoutと配備後の契約反映は、ローカル画像・機能テストとは別に確認する。
