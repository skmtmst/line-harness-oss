## 取れない数は、画面もCSVも「—」

`ScenarioStats` は `enrolledTotal` `activeNow` `completed` `paused` と
段ごとの `reachedCount` `reachRate` しか持ちません。
**開封率・クリック率・失敗数は入っていません。**

画面はそれを隠さず、そのまま `—` で出しています。

> LINEでは友だち単位の開封を取得できません。クリック率も、この集計にはまだ接続していません。
> 配信失敗数は、この集計からは取得できません。

**段ごとの集計が来なかったときも `—` です。** 段はあるのに
`stats.steps` が空の場合を作って確かめました。

| | 画面 | CSV |
|---|---|---|
| 到達人数 | `—人到達` | `"—"` |
| 到達率 | `到達率 —` | `"—"` |
| 開封率・クリック率 | `開封率 —・クリック率 —` | `"—","—"` |

**CSVにも作り物の数が入りません。**

## 固定データを1つ直しました

`SCENARIO_STATS.steps` の鍵が **`reachedRate`** になっていました。
`ScenarioStats` の正しい綴りは **`reachRate`** です。
この画面は率を自分で計算するので絵は変わりませんが、
**別名で書くと握りつぶされ、何も試していない絵が基準になります。**
