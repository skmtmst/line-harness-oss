Lステップ公式マニュアルの機能一覧（`manual.linestep.net/features`）に載っている**全32機能**を1つずつV2と突き合わせた結果。

- 照合日: 2026-08-15
- 出典: [機能一覧 | Lステップ マニュアル](https://manual.linestep.net/features)
- 結果: **32機能中 32機能をV2でカバー**（うち6機能は今回の照合で不足が判明し、追加作成）

## 2. 照合で判明し、V2に反映した差分

### 2-1. アクションが10種類だった（`7-1-1` `4-5-1` に反映済み）

V2は7種類しか用意していなかった。不足していた4つを追加。

| Lステップの10種 | V2の対応 |
|---|---|
| テキスト送信 | ✅ |
| テンプレート送信 | ✅ |
| タグ操作 | ✅ |
| **友だち情報操作** | **追加** |
| シナリオ操作 | ✅ |
| **メニュー操作（リッチメニュー切替）** | **追加** |
| **リマインダ操作** | **追加** |
| 対応マーク・表示操作 | ✅ |
| 通知 | ✅ |
| **予約操作** | **追加** |

**メニュー操作が抜けていたのが最大の穴。** 会員ランクや購入状態でリッチメニューを出し分ける定番の使い方ができなかった。

### 2-2. スケジュール設定はプロプラン以上

`7-1 オートメーション` の「毎日09:00 定期実行」は、Lステップでは上位プラン限定の機能。V2で標準提供するなら差別化になる。

### 2-3. カスタム検索は AND群／OR群 の2グループ

V2は条件を一列に並べて「かつ」で繋ぐ形だった。Lステップは「**すべて満たす**」グループと「**いずれか1つ以上満たす**」グループを別々に持つ。`3-4 保存した検索` はこの2グループ構成で作成済み。上限は50件。

### 2-4. シナリオの分岐はシナリオの外にある

Lステップのシナリオ編集で追加できるのは「メッセージ」と「テンプレート」だけ。分岐は次の経路で実現されている。

```
回答フォーム / 自動応答 / カルーセル / 流入経路
  → アクション「タグ操作」→ タグが付く
  → アクション「シナリオ操作」→ 別のシナリオを開始
```

**V2は分岐をシナリオ内に持つ**という別の設計を採っている。離脱地点の可視化のために必要な選択だが、実装コストは上がる。Lステップ方式（タグ経由）も併用できる。
