# バナー生成の中を承認済みの絵どおりにそろえる

- 一覧の型に来た道の案内（crumbs）の置き場所を足し、題・説明の下の行に案内と操作のボタンを並べるようにした（★BG-B `qIp42`）。
- 生成パネルの棒の上に見出し「利用量」を出すようにした。共通部品の既定は変えず、板がそう描いている V8 だけが渡す。
- 下の帯のボタンの言葉を「生成する（N枚）」にそろえ、パネルの見出し「画像を生成」と同じ言葉が2か所に出ていたのを解消した。
- 板にあって実画面に出ていなかった文字の内訳と、縦の照合が合わない作りの違いを `src/v8/hq-banners/BEHAVIOR.md` に記録した。
