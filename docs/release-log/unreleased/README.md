# ここに、PRごとの1ファイルを置きます

```
198-kenta-auto-reply-all.md
```

ファイル名は `<PR番号>-<担当>-<何の話か>.md`。

中身は `## 追加` `## 変更` `## 修正` のどれかの見出しの下に、1行ずつ。

```markdown
## 追加
- 自動応答で、キーワードを問わず全部のメッセージに応答できるようにした @kenta #198 2026-08-20 09:30
```

**1ファイルに全員が書き足す形をやめたのは、必ずぶつかるからです。** 全員が同じ場所
（`## 追加` の直後）に行を差し込むので、PRのたびに突き合わせが要りました。一晩で
9本のPRが全部ここで止まり、そのうち1回は取り込みの目印がそのまま入りました。

親の `../unreleased.md` はこれまでのぶんが残っています。**新しい行はそちらに足さないでください。**

## PRを作ってから、ファイルを作ってください

ファイル名にPR番号が入るので、**番号を先読みすると、中身だけでなくファイル名も
直すことになります。**

一晩で3回外しました（担当2人とも）。順番はこれです。

1. コードを書いてコミットする
2. push して PR を作る
3. **番号が分かってから**このファイルを作る
4. もう一度コミットして push する
