# 機能6 一斉配信を設計へ寄せる

V6設計の機能6のうち5枚（一覧・作成の基本設定／対象／メッセージ／送信設定）を実装と並べた。

## 変更
- 一斉配信の一覧の表で、見出しが1つずれて中身と食い違っていたのを直した @kenta 2026-09-02 14:40
  「開封（率）」の下に状態、「状態」の下に削除ボタンが並んでいた。設計どおりの6列にそろえた
- 配信の作成に、いまどこまで進んだかを表す5段（基本設定・対象者・メッセージ・送信設定・確認）を出すようにした
- 配信日時が、見ている端末の時計で書かれていたのを日本時間にそろえた
- 配信名に「14 / 60文字」を出し、長すぎるものは保存の前に止めるようにした
- 日時を指定した予約に「送る直前にもう一度対象を数え直す」ことを書いた
- まだ送っていない配信の配信数・開封に、数のかわりに「—」を出すようにした
