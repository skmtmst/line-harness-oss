## 修正

- NEN配信の「マイペット」で、登録済みのペットを消さずに直せるようになった。種別は犬・猫・その他、性別は男の子・女の子・わからないから選べ、誕生日は生まれた年が分からない子も「03-15」のように月日だけで登録できる。誕生日を変えると、古い日付へ予約されていた誕生日クーポン配信は自動で取り消される。
- NEN配信の「送った履歴」の検索が、画面に読み込んでいる分だけでなく履歴全体に効くようになった。宛先の名前と配信名のどちらでも探せる。
- NEN配信の「コラム」画面に、コラム配信を止める・動かす操作を追加した。誕生日配信はこれまでどおり「自動配信」タブで止められる。
- 誕生日クーポンがECで使われた記録が残るようになり、「使われた率」が正しく数えられるようになった。
- 誕生日クーポンの発行でECとの通信が1件失敗しても、他の子への発行と通常のNEN配信が止まらなくなった。失敗した分は次の日の処理でやり直し、運用者への通知にも出せる。 @devin 2026-09-19 15:55
