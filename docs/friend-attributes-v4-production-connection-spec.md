# 友だち属性V4を本番画面へ接続する別PR仕様

## 目的

PR #271で確認した静的な4状態を、現行 `/tags` の機能を失わず本番画面へ接続する。
この仕様の実装はPR #271へ追加せず、最新 `codex/development` から別ブランチ・別PRで行う。

## 残す機能

- 友だち属性の取得・追加・編集・削除
- ドラッグによる並び替え
- CSVテンプレート取得、事前検証、一括登録、出力
- フォルダと実データ一覧
- 現行の権限、エラー、読込中、空状態

## 実装すること

- 現行APIと状態管理を `page.tsx` 側へ残し、V4 Viewへpropsで渡す
- ボタン、タブ、検索、並び替え、ページ切替、モーダルを実データで動かす
- 共通サイドバーを含むグローバルシェルをV4設計と比較する
- CSVモーダル背面のフォルダと実データ一覧を同じ状態・同じ横幅で比較する

## 受け入れ条件

- 現行機能の機能テストが成功する
- `pnpm check:v4-architecture` が成功する
- `apps/web/v4-screens.json` に `missing` が残らない
- 1920pxの設計画像と実装画像を横並びで比較済み
- 1440pxと1920pxでページ・表の横スクロールがない
- 本番配備を行わず、検証環境までを対象とする
