## 3. 字幕の付け方

1. YouTube Studio へ**限定公開（Unlisted）**でアップロードする（非公開では審査員が見られない）
2. 動画を選び「字幕」→「言語を追加」→ **English**
3. 「字幕」の追加方法で**「ファイルをアップロード」→「タイミング情報あり」**を選び、
   `docs/manuals/google-business-demo-video-subtitles.srt` を選ぶ
4. 画面でずれていたら、字幕エディタで各行の開始時刻を前後にずらして「公開」
5. ログインしていないブラウザで動画URLを開き、再生と字幕が出ることを確認する

**日本語の字幕は付けなくてよい。**審査担当は英語で読む。

## 4. 申請フォーム（`/auth/verification`）貼り付けシート

Google Cloud コンソール → APIとサービス → OAuth同意画面 → 「確認センター」。
上から順に、この表のとおりに入れる。

| フォームの欄 | 入れる値 |
| --- | --- |
| Application home page | `https://musubo.jp/` |
| Application privacy policy link | `https://musubo.jp/privacy/` |
| Terms of service | `https://musubo.jp/terms/` |
| Authorized domain | `musubo.jp` |
| Demo video | 撮影した限定公開YouTubeのURL |
| `.../auth/business.manage` の justification | `google-business-verification-application.md` 2-1 の**英語ブロック全文**をそのまま貼る |
| `openid` の justification | 同 2-2 の英語ブロック |
| `.../auth/userinfo.email` の justification | 同 2-2 の英語ブロック（同じ文を両方に入れてよい） |
| 補足リンク1 | `https://musubo.jp/privacy/` |
| 補足リンク2 | `https://musubo.jp/terms/` |
| 補足リンク3 | `https://musubo.jp/` |

**管理画面（`admin.musubo.jp`）とAPI側（`api.musubo.jp`）のURLはこのフォームに書かない。**
Googleはログインの内側のページをホームページやポリシーとして認めない。
管理画面は動画の中だけで見せる。

Reviewer notes 欄があれば、次の2文を入れる。

> The dashboard UI is available in Japanese only; the demo video has English subtitles.
> All write operations are executed only when the store's own staff open a confirmation screen and press the confirm button.

試用アカウントを求められた場合の手順は `google-business-review-package.md` 3章。
**認証情報はこの文書にもリポジトリにも書かない。**

## 5. 提出後

- 審査は通常3〜5営業日。追加質問が来たら `google-business-review-package.md` 4章の回答集を使う
- 通ったら、OAuth同意画面を「本番環境」へ公開する（これで100人上限と7日でトークンが切れる制限が外れる）
- 撮影で変えた口コミ返信・店舗情報・写真・投稿を元に戻す（`google-business-review-package.md` 1-3）
