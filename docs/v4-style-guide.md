# V4 基本パーツ・スタイルガイド

Pen.devの実ノードは `w2Nv6`。画面名は `V4 0-1 基本パーツ・スタイルガイド（1920）`。

V4制作領域の左端に置き、8/22現行画面の右側には置かない。

## 掲載した標準候補

- カラー9色: メイン、濃い緑、薄い緑、本文、補助文字、境界線、背景、削除、リンク。
- 文字5段階: ページタイトル、見出し、本文、補助文字、数値。
- ボタン: 追加、キャンセル、コピー、削除。
- 入力: 検索、プルダウン、チェック、トグル。
- 状態: タブ、対応マーク、共有・無効バッジ。
- 一覧: 表ヘッダー、状態、編集、削除。

設計画像は [`visual-qa/v4-style-guide/design-v4-style-guide-1920.png`](./visual-qa/v4-style-guide/design-v4-style-guide-1920.png)。

## 削除操作

- 赤い文字だけではなく、赤い `trash-2` アイコンと「削除」を組み合わせる。
- 取り消せない操作は確認モーダルを必須にする。
- 表の行操作でも同じアイコン・色・文言を使う。

## 運用

このページは標準候補であり、既存V4の2画面以上で同じ寸法だと確認できたものから正式な共通部品へ昇格する。今後の変更依頼は「V4基本パーツのコピーを変更」のように部品名で指定する。
