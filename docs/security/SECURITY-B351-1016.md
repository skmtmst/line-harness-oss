## 公開入口とCSP

[PUBLIC-ENTRYPOINTS](PUBLIC-ENTRYPOINTS.md) は管理認証の外の173経路を実登録と照合。署名/専用鍵/LINE本人確認のある経路も含め、静的配信とSPAを別記。匿名の取得ができる物と、個別認証で拒否する物を区別する。添付画像/動画の無期限URL、公開素材の誤配置、明細の資格情報付きURL、全資源ID×本人の組合せの未検証は残る。

公開入口の網羅試験では表の1行削除と架空経路の追加が検出される。既存の非公開写真の署名・審査原本・書類・配信素材・添付・LINE本人と店の拒否試験も保持した。

[CSPの記録](CSP-REVIEW-1016.md) に外部資源の洗い出し、通常ビルドとブラウザの確認、強制すると止まる候補と未検証を記載。Report-Onlyのままにし、Next.jsのinline起動・blob Worker・添付PDF・SDKの追加窓の条件を勝手に直さない。CSP違反の自動収集先は未設置。
