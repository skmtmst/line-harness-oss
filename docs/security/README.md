## 担当者との確認の進め方

点検表は40項目（済21・未9・分からない10）。高リスクの未11項目をすべて確認し、S19の全参照履歴検査とS23・S36のコード試験を「済」に更新しました。S07・S15・S21・S26にも修正はありますが、残条件があるため「未」です。「済」はその行に書いた範囲だけの確認です。たとえば署名を検証するコードがあっても、本番に鍵が正しく設定されている証明にはなりません。

危なさ「高」の未解決項目は、対処結果か、公開判断に必要な残るリスク・担当・期限をオーナーとマサトさんが確認してから公開を判断します。「分からない」を「問題なし」に読み替えません。

記録するのは、点検ID・担当の名前・確認日・結果・秘密を除いた証拠の場所だけです。顧客情報、アカウントのメールアドレス、秘密の値、復元点の実値、認証画面の写しは載せません。
