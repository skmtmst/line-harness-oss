# B-179 リサーチのイベント操作

`event_booking` の設定は `{ eventId, op?: 'register' | 'cancel', slotId?: string | null }`。省略時は申込。

画面担当への残り：共通の行うことの `apps/web/src/components/scenarios/action-editor.tsx` は現在イベント選択だけ。申込／取消と任意の回の選択・表示をこの設定へ接続する。回を指定しない申込は次の空き回を選ぶ。

- 申込: 指定回、または日時が次の申込可能な空き回へ1名で登録。承認が必要なら承認待ち。締め切り・停止回・待ちの仮押さえ・同一人物の上限を守る。
- 取消: その友だちのそのイベントの有効な申込を取消。回指定時はその回だけ。
- 空き無し・申込無し: 監査記録に理由を残し、失敗時に止める設定でも後続の処理を続ける。
- 必須質問のあるイベントは回答を作らず、回答が必要な理由を記録する。
- 同じ回答工程の再送は予約を増やさない。確定時は既存の通知登録、取消時は通知停止と待ちの繰り上げ処理を行う。
- 「1回だけ」の行うことは、下書きと公開版で同じ操作キーを使う。同時実行・版の変更でも別の回へ二重に申し込まない。
