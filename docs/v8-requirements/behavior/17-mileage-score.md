## 3. 日々の操作の手順

毎日（朝）：
1. マイル → 友だちの残高：上の「承認待ちのマイル変更」があれば、依頼した人と別の owner が承認・差し戻し（自分の依頼は承認できない）。
2. 使い道：数の帯「渡せなかった」が 0 か。0 でなければ表の下の「要対応の交換」を開き、理由を見て「もう一度届ける」。何度も失敗するものは owner が返却を判断。
3. 履歴：種類「確定待ち」で絞り、注文が確定したもの・取り消されたものを理由つきで確定・取消。

毎週：
1. たまる決めごと：各決めごとの「過去30日の対象・付与・除外」を見る。除外が急に増えた決めごとは回数上限・期間を見直す（直すときは新しい版で）。
2. 友だちの残高：「30日以内に失効」の合計を見て、失効前の案内を送るか決める。
3. 行動スコア：「30日で下がった人数」と低い帯の人数を見る。高い帯は「この帯の人に送る」で一斉配信へ。

異常の気づき方：
- 付与が 0 の日が続く → きっかけのできごとが届いていない（決めごとの状態・機能のオンオフを確かめる）。
- 同じ友だちに同じ時刻の付与が2行 → 二重付与（すぐ止めて報告）。
- 残高と履歴の合計が合わない・点数と明細が合わない → 運用状態の照合の警告。
- 「渡せなかった」が増え続ける → LINE の送信上限・共通アクションの設定不備。
