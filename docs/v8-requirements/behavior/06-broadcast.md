## 日々の操作の手順

毎日（朝）
1. ダッシュボードの「接続の異常」の帯が無いことを見る（あれば鍵の入れ直しが先。送ってもすべて失敗する）。
2. 一斉配信の一覧で、数の帯「予約中」「今月の送信枠（残り）」を見る。残りが今日・明日の予約の合計より少なければ、予約を見直す。
3. 状態の札「承認待ち」を押し、自分が承認する物を開いて承認・差し戻す（予約時刻を過ぎると期限切れになる）。
4. 状態の札「エラー」を押し、昨日の「失敗」「一部失敗」を開く。一時的な失敗だけなら［失敗した相手に送り直す］。送達不明は送り直さず、必要なら個別に連絡。
5. 通知センターで「〇〇を送れませんでした」（送信枠不足・止めていたので送らなかった）を確かめる。

配信を作るとき
1. ［配信を作る ▾］→［詳しく作る］（短い知らせは［かんたんに送る］）。
2. 対象者で人数と除外の内訳（ブロック・非表示・重複）を見る。
3. 確認で警告（0 人・20 人未満・名前が無い人・24 時間以内の同じ内容・同時刻の配信・送信枠）を全部読む。
4. ［テストを送る］で自分のスマホで見え方を確かめてから、予約・送る（1,000 人以上は承認を頼む）。

毎週
1. 送信済みの開封率・クリック（平均の開封率・過去 28 日）を前週と比べる。急に下がったら本文・時刻を見直す。
2. ブロックの数が増えた配信を見つけ、頻度・内容を見直す。
3. 下書きが溜まっていれば、要らない物を消す。

異常の気づき方
- 予約時刻を 5 分過ぎても「予約中」のまま → 見回り（cron）の遅れか、承認・送信枠・機能オフで止まっている。詳細の理由を見る。
- 「送信中」が長く続く → 大きい対象は少しずつ進む。送った数が増えていなければ運営へ。
- 失敗が多い → まず LINE との接続（鍵）を疑う。
