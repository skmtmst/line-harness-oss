# 04 友だちの属性 操作と挙動（受け入れ）

要件の正本：[4 友だち属性](../../v6-requirements/v6-04-friend-attributes-requirements-draft.md)・[友だちの決まった欄と表示項目](../friend-fixed-fields.md)・[共通基盤 §3・§6-2・§9・§11・§15](../../v6-requirements/v6-shared-platform-requirements.md)・[30 ログインユーザー §7〜§8](../../v6-requirements/v6-30-login-users-requirements-draft.md)。この文書は「操作したらどう動くか」を試験が書ける形にしたもの（2026-10-16 B-333）。食い違ったときは要件が勝つ。

対象は「タグ」の画面の4つのタブ（タグ・友だち情報欄・対応マーク・保存した検索）と、そこから開く作る・編集・移行・フォルダ・CSV で一括登録。友だち詳細や受信箱の右の欄でタグ・情報欄を付け外しする動きは、定義側に関わる所だけ書く。

オーナーの決定で関係する物：B-8（タグの並べ替え）・B-10（タグの星を戻す）・B-26（受信箱の右の欄でその場で直す）・B-36/B-52（統括から配る）・B-71/B-94（「友だち属性」→「タグ」・×で外すときは確かめ）・B-75（文言）・B-163（選ぶ物が多い欄は窓で選ぶ）・B-173③（タグ・対応マークの保管は戻せる）・B-217（一覧の表の形）・B-234/B-235/B-238（決まった欄・アレルギー）。B-294〜B-332 に、この機能の動きを変える決定は無い。

## 日々の操作の手順

毎日（受信箱の担当）

1. 受信箱で新しいメッセージを開き、右の欄でタグ・対応マーク・情報欄をその場で直す（B-26。押した瞬間に変わり、失敗したら元に戻って「もう一度」）。
2. 対応マークのタブの数の帯で「未対応」の人数を見る。前日より大きく増えていれば、受信時の自動変更のきまりが止まっていないか、担当が付いていないかを見る。
3. 「過去7日の変更」が急に 0 になったら、自動変更が動いていない合図。マークの編集の「きまり」を開いて止めていないか確かめる。

毎週（運用の責任者）

1. タグのタブで「付いている人 0」「使っている所なし」のタグを絞り込み、要らない物を保管する（保管は戻せる）。
2. タグの連動・マイルを変えたら、編集画面の「使っている所」で失敗・待ちの数を見る。失敗が残っていれば理由を読み、直してから再開する。
3. 友だち情報欄のタブで「入っている人」が 0 の項目、回答フォームで使われていない項目を見直す。種類を変えたいときは削除せず「移行」を使う。移行中の項目があれば、結果の見守りで件数が合っているか見る。
4. 保存した検索のタブで「該当 0 人」「未集計」「要修正」の検索を見る。要修正は条件に使ったタグ・項目が保管された合図なので、条件を直す。未集計は 0 人と同じではない。
5. スタッフの入れ替えがあったら、個人情報の項目（電話・住所など）を見られる人を設定で見直す。

異常の気づき方

- 一覧の数の帯に「—」が続く：集計が取れていない。読み直して直らなければエラー報告へ。
- タグの「付いている人」が急に減った：誰かが保管で置き換えた可能性。操作の記録で確かめる。
- 連動で送ったはずのメッセージが届かない：実行の記録の失敗理由を見る（ブロック・上限）。
