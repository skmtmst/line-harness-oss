## 日々の操作の手順

1. 朝：ウェビナー一覧の数の帯で「申込」「視聴率」を見る。前日より大きく下がっていたら参加者の「見ていない」を開く。
2. 開催の前日：該当の回の申込数と定員を見る。満員に近ければ回を足す。④通知の「前日のご案内」が「送る」になっているか、テスト送信が済みかを見る。
3. 開催の 1 時間前：運用状態に通知の失敗が無いか。失敗があれば要対応から理由を見て直す（ブロック・上限）。
4. 開催のあと：参加者を「途中で離れた」「見ていない」で絞り、見逃し案内・行うことが動いたか（失敗の件数 0 か）を確かめる。
5. 毎週：分析の線で、CTA を出した時刻の前後で人が大きく減っていないかを見る。CTA の反応（押した人）とフォームの送信（人）を比べる。
6. 終わったウェビナー：公開を止め、アーカイブへ。記録は残る。
- 異常の気づき方：視聴率が急に 0 に近い（計測の欠落か動画の失敗）／平均視聴が数秒（母数・計測欠落の注意が出る）／通知の失敗が増える（LINE の上限・トークン切れ）。
