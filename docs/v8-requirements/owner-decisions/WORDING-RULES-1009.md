# 言葉の決まり（2026-10-09 オーナー決定・B-146）

管理画面（Pen の板とコードの両方）で、同じ意味の操作・文は同じ言葉にする。Pen をそろえてから、コードを Pen に合わせる。

## 決まり
1. **消す操作は「削除する」**（オーナー）。
   - ボタン・「…」の中：「削除する」（目的語が付くなら「〇〇を削除する」：フォルダを削除する）
   - 確かめの窓の題：「「〇〇」を削除しますか？」・主ボタン「削除する」
   - 注の文：「削除しても、中の〇〇は未分類に残ります」（「消しても」→「削除しても」）
   - 「消す」「削除」（する無し）は使わない
2. **作ったものを直す操作は「編集する」**（オーナー）。
   - ボタン・「…」の中：「編集する」。画面・窓の題：「〇〇を編集」
   - 「直す」「編集」（ボタンで、する無し）は使わない
   - 表の列名・履歴の「変更」（変わったこと）は別の意味なので対象外
3. **ボタンの動きは「〜する」で終える**（オーナー）。
   - 保存する・複製する・公開する・追加する・送信する・配信する・選ぶ（「選ぶ」はそのまま）・確定する
   - 目的語が付くものは今一番多い形のまま：「下書きを保存」・「フォルダを追加」・「〇〇を作る」・「この版を公開」
   - 「キャンセル」「閉じる」はそのまま（入力をやめる＝キャンセル、窓を閉じるだけ＝閉じる）
   - 1つのボタンに同じ意味の言い方を混ぜない（「保存」「保存する」「変更を保存」→「保存する」。既存を直す画面で区別が要るときだけ「変更を保存する」）
4. **複製は「複製する」**。「コピー」は文字・URL を写す時だけ（「コピーする」）。「複製して作る」は「複製する」に。
5. **「やめる」は「キャンセル」**に（入力をやめる意味のとき）。窓を閉じるだけなら「閉じる」。
6. **文末の「？」は全角**（Pen は全部全角。コードの半角約40を直す）。
7. **閲覧のみの帯**：「閲覧のみで見ています。変える操作はオーナーか管理者に頼んでください。」（統括の画面は「統括の管理者に頼んでください」）。言い回しを増やさない。（10-09 B-159 で頼む先を 403 とそろえた）
8. **アカウント未選択の空の表示**：「LINE公式アカウントを選んでください」に1つ（「選択してください」「LINEアカウントを選んでください」は使わない）。
9. 作る：ボタンは「〇〇を作る」（「作成」「新規作成」「新しく作る」は使わない）。追加する物が入れ物の中の項目なら「〇〇を追加」。

## 進め方
- Pen：Pen 担当が全板（V8・V8-B）のボタン・メニュー・窓の題・注の文を上の決まりにそろえ、座標表と html を作り直す。そろえた言葉の表（前→後と板の数）を PEN-UPDATE-1009.md に足す。
- コード：Codex が画面と共通部品（ConfirmDialog の既定・FolderPanel の注・ListState・閲覧のみの帯）を同じ言葉にそろえ、言葉を固定している試験も直す。反映履歴の言葉もこの決まりで書く。
