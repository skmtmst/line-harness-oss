# 言葉の表（正本）

musubo の画面（管理画面とお客さまの画面＝LIFF）に出す言葉を、この1枚で決める。
オーナーの決定 **B-345**（2026-10-16）：システムの中の表現・言葉を統一する。スタイル（標準・飲食店・サロン・面談・教室・EC）で言葉が変わる所も、ずれないように1か所の言葉の表から出す。画面は表を読み、表に無い言い方を画面に直書きしたら見張りで落ちる。

- **正本の順位**：オーナーの決定（`~/lh-work/design/v8/V8-INTRO-CHECKLIST.md`）＞この表＞`docs/v8-design-rules.md` §6.6・§6.12＞画面のコード。食い違ったら、この表を先に直してからコードを直す（要件が先。B-337）。
- **前の用語集との関係**：`docs/v6-requirements/v6-00-glossary.md`（送り仮名・状態の言葉・空の値など）の決まりは全部この表に取り込んだ。新しい言葉はこの表にだけ足す。
- **対象**：画面に出る言葉（ボタン・札・見出し・列名・知らせ・確かめの窓・LIFF の文）。変数名・型・API の値（`no_show` など）は対象外。
- **列の読み方**：「使う」＝画面に出す言葉。「使わない」＝今の画面・文書にある揺れ（見張りで落とす側）。「場面」＝どこで使うか。「根拠」＝決定の番号。番号の無い物は B-337（「おすすめで」）に従い司令塔が選んだもので「決定：おすすめ」と書く。
- **ID**：`TM-` で始まる。画面のコードの言葉の表（`packages/shared` の terms）のキーと 1 対 1 にする（§8）。
- 今の揺れの数と場所は `~/lh-work/design/v8/review/TERMS-DRIFT-1016.md`。
