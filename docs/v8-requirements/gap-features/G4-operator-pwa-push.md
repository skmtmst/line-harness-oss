## 1. 目的・効く目標・ライバルとの差

- 目的：スタッフは PC の前にいない。新しい問い合わせ・予約・取消・無断を手元のスマホで知り、その場で返事・来店の印を付けられるようにする。
- 効く目標：②直感的（2 画面だけ・下のタブの帯）、③作り込み（種類ごと・静かな時間）、④プロの仕上げ（ホーム画面のアプリのように開く）。
- ライバル：Lステップ・Liny・エルメはアプリがある。通知が多すぎて切られる → 種類ごと・静かな時間。アプリストアの審査で更新が遅れる → **PWA（Web のまま更新）**。

### 2-2. 通知の種類と既定

| 種類 | 既定（受け取る人） | 押すと開く所 |
|---|---|---|
| 新しい問い合わせ | オン（担当が決まっていない会話＝受信箱を見られる全員） | 会話 |
| 自分が担当の会話に返事が来た | オン（本人） | 会話 |
| 返事の期限が近い・過ぎた（G3） | オン（担当と責任者） | 会話 |
| 新しい予約・取消 | オン（その予約の担当。担当なしは予約を見られる全員） | 今日の予約（その予約の日） |
| 無断の可能性（開始から 15 分たっても来店の印が無い） | オフ | 今日の予約 |
| 接続の異常（カレンダーが切れた・会議の URL の失敗＝B7・決済の失敗） | オン（オーナー・管理者） | PC で開く案内（スマホの形が無い画面） |

- 運用者のお知らせのルール（要件 24・F-14 のチーム）と**同じ宛先の決まり**を使い、プッシュはその「届け方」の 1 つとして足す（ルールを 2 つに分けない）。
- 本文に**お客さまの本文・電話・メールを入れない**。「新しい問い合わせ：山田さま」「新しい予約：11/20 14:00 カット」まで。ロック画面で他人に見えるため。**決定：おすすめ**
- 静かな時間：既定 22:00〜8:00（人ごと）。その間は送らず、明けたら「夜の間に 3 件」の 1 通にまとめる。接続の異常だけは静かな時間でも送る（Q-36 の隠せない物と同じ考え）を選べる（初期オフ）。**決定：おすすめ**
- まとめ：同じ種類が 1 分に 5 件を超えたら「新しい問い合わせ 12 件」の 1 通にまとめる。**決定：おすすめ**

### 2-3. 権限

- 受け取れるのは、その画面を見る権限がある物だけ（受信箱を見られない人に問い合わせは届かない。担当範囲の外の店は届かない）。押した先でも権限を確かめ直す。
- 閲覧のみ：受け取れる。スマホの形でも返事・来店の印のボタンは出さない（閲覧のみの帯）。
- 統括：統括の「対応が要るもの」（B-312）の件数を受け取れる（押すと店を切り替えて開く）。
- 代理ログイン：端末を登録できない（運営の端末に店の通知が届かないように）。**決定：おすすめ**
- ログアウト・ログインユーザーの停止・パスワードの再設定・役割の変更で、その人の端末の登録を全部外す。

### 2-4. 状態と言葉

- 窓：このブラウザは通知に対応していない（「このブラウザでは受け取れません。iPhone はホーム画面に追加してから開いてください」）／許可していない（「ブラウザの設定で通知を許可してください」と手順）／受け取っている（緑）／試しに送った（「届きましたか？」）。
- スマホの形：読み込み中（スケルトン）・失敗（「読み込めませんでした」［もう一度］）・空（「未対応の問い合わせはありません」「今日の予約はありません」）・通信が切れた（上に灰色の帯「オフラインです。つながると読み直します」。オフラインで送る・来店の印は受け付けない）。
- 言葉：「通知の受け取り方」「この端末で受け取る」「静かな時間」「試しに送る」「ホーム画面に追加」。「プッシュ」「PWA」「Service Worker」は画面に出さない。

### 2-5. 隣の決定（お客さまのお知らせを止める・B-308 追記 3 ②）

運用者の通知とは別の機能。LIFF のマイページで、お客さまが**宣伝**（一斉配信・シナリオの宣伝・誕生日など）を止められる。**取引のお知らせ**（予約の確定・リマインド・取消・会議の URL＝B7・キャンセル料＝B1・回数券の残り＝B2・振替＝B3）は止められない（Q-10）。要件の正本は `docs/v8-requirements/v8-liff.md`（マイページのお知らせ）と要件 24。この系の機能が送る物は全部「取引のお知らせ」に分類する。

## 3. データと API の形の案（Codex が作る・マイグレーション）

- `operator_push_subscriptions`：`id`・`staff_id`・`endpoint`（一意）・`p256dh`・`auth`・`user_agent_label`（「iPhone の Safari」など）・`created_at`・`last_success_at`・`last_error_code`・`revoked_at`。
- `operator_push_preferences`：`staff_id`・`kinds_json`・`quiet_start`・`quiet_end`・`quiet_allow_critical`・`version`。
- `operator_push_deliveries`：`id`・`subscription_id`・`kind`・`ref_id`・`status`（sent／failed／gone／suppressed_quiet／batched）・`created_at`（同じ物を二重に送らない一意キー）。
