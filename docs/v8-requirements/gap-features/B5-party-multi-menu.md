# B5 同伴・複数人・複数メニューを 1 回で予約

- 作った日時：2026-10-16 03:52（日本時間）。担当：司令塔の作業役（予約・LIFF・運用者スマホの系）。
- 正本の順：B-306（割り当て）・B-308・B-337 → 要件 27・28 → この文書。**飲食の席の予約（人数＝卓の大きさ）は対象外**（席は今の飲食の仕組み。memory「予約は人と席で分かれる」）。ここは人（担当）で受ける予約（サロン・整体・面談・教室の個別）。
- 絵：B5-1（LIFF ① 人数と追加メニュー）・B5-2（② 人ごとの担当）・B5-3（盤と詳細の組）、点検 C の hhUtj（2 人の合計の内訳が無い・2 人目のメニューを選ぶ手順が無い）・Nx1kq（組の 2 人が同じ担当で重なる見本）・zYErQ（合計・文）・横断 4（「同時に予約できる人数」「追加メニュー」を出し入れする管理の設定が無い）。

## 1. 目的・効く目標・ライバルとの差

- 目的：親子・友だち同士・カップルの来店を 1 回の予約で取る。「カット＋カラー」「60 分＋ヘッドスパ」の組み合わせを 1 回で選べる。
- 効く目標：②直感的（既定は全員「指名なし」で 1 回押せば済む・合計の時間と料金を自動で足す）、③作り込み。
- ライバル：Square・Fresha・Booksy にある。Square は Google 経由で 1 回に複数メニュー不可・複数スタッフは有料。LINE ツールには無い（今の musubo は `party_size` が 1 以外を 422 で拒む）。

### 2-2. 決めること・既定値

| 項目 | 既定 | 備考 |
|---|---|---|
| 同時に予約できる人数 | 1（メニューごとに上げる） | 組のメニューで一番小さい上限に従う |
| 2 人目以降のメニュー | 1 人目と同じ（変えられる） | 違うメニューを選べるのは、店がそのメニューにも人数 2 以上を許したときだけ |
| 追加メニュー | 人ごとに 0〜3 個 | 時間と料金を足す。オプションだけの予約は不可 |
| 担当の既定 | 全員 指名なし | B-306 の割り当てを**人ごとに順番に**回す（同じ担当に偏らない・同時に受けられない担当は外す） |
| 同じ時刻にそろえる | 同時に始める（担当が別）／同じ担当で続けて | お客さまが「同じ担当で」を選んだときだけ続けて |
| 組の LINE | 予約した人（1 人目）にだけ送る。お連れさまは友だちでなくてよい | お連れさまの個人情報は名前（任意）だけ。**決定：おすすめ** |
| 取消 | お客さまは組をまとめて取消・人を減らす（2→1）の両方 | 人を減らすのは期限内だけ。キャンセル料（B1）は人ごとに計算 |
| 支払い | 合計を 1 回で（先払い・デポジットも合計に掛ける） | 回数券は 1 人目の分だけ使える（お連れさまの券は使えない）。**決定：おすすめ** |
| 承認制 | 組で 1 回の承認 | |
| 来店・無断の印 | 人ごと | 無断の印（B1）は予約した人に付く |

### 2-3. 権限

予約を入れる・変える・取り消すは今の予約の権限（オーナー・管理者・スタッフ）。メニューの設定はオーナー・管理者。閲覧のみ＝組は見える、操作は隠す。代理ログイン＝見るだけ。

### 2-4. 状態と言葉

- LIFF ③：全員がそろう時刻が無い日は灰色。「2 人そろって空いている時間がありません。別の日か、人数を分けてご予約ください」。
- LIFF ⑤：合計の内訳（hhUtj）＝「1 人目 カット 60 分 ¥5,500＋ヘッドスパ 15 分 ¥1,500／2 人目 カット 60 分 ¥5,500／合計 ¥12,500（同時に 75 分）」。
- 言葉：「何人で予約しますか」「1 人目（あなた）」「2 人目（お連れさま）」「追加メニュー」「全員 指名なし」「この組」。「同伴者」「パーティ」は使わない。

## 3. データと API の形の案（Codex が作る・マイグレーション）

- `booking_groups`：`id`・`line_account_id`・`owner_friend_id`・`size`・`start_mode`（parallel／sequential）・`status`・`version`・`created_at`。
- `bookings` に `group_id`・`group_index`・`guest_label`（任意の名前・1 人目は null）。`party_size` は使わず 1 予約＝1 人のまま（今の 422 の守りは残す）。
- `booking_addons`：`booking_id`・`addon_menu_id`・`duration_min`・`price_at_booking`。
- メニューに `max_party_size`・`addon_menu_ids_json`・`addon_only`。

## 5. 連携とエラー

- Google カレンダー（B7）：人ごとの予約を担当ごとのカレンダーへ。どれか 1 人の担当が読めないと、その担当を候補から外す。
- LINE：知らせは 1 人目だけ。お連れさまへは送らない（友だちでない）。
- Stripe：合計 1 回。人を減らした分の返金は期限内なら全額（その人の分）。

## 6. 決めていない所（B-337：おすすめで決定）

1. 上限 6 人。**決定：おすすめ**
2. お連れさまは名前だけ（任意）・LINE は 1 人目だけ。**決定：おすすめ**
3. 回数券は 1 人目の分だけ。**決定：おすすめ**
4. 人を減らした分の返金は全額（その人の分）＝一部返金になるので、Q-20 に合わせて**最初の版は「人を減らす」を期限内・先払いでないときだけ**許し、先払いの組は組ごとの取消だけ。**決定：おすすめ**
