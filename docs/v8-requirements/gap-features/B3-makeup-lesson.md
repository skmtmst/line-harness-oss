# B3 欠席の振替（教室・レッスン）

- 作った日時：2026-10-16 03:38（日本時間）。担当：司令塔の作業役（予約・LIFF・運用者スマホの系）。
- 正本の順：B-308（全部入れる）・B-337 → [B2](B2-tickets-monthly.md)（券の土台。B2 が先）→ 要件 29 イベント予約（`event_bookings` の出欠・キャンセル待ち）→ この文書。
- 絵：B3-1（友だち詳細）・B3-2（LIFF 履歴）、点検 C の kzE16（欠席の入口・選ぶまで押せない）・F0e5ue（取消の窓・入口・次の人へ）・i1NoP（埋まった回・LINE で知らせる）。LIFF の予約の履歴は `nWby5` にそろえる（B-319）。

## 1. 目的・効く目標・ライバルとの差

- 目的：教室で「休んだ分をいつまでにどの回へ振り替えられるか」を電話で聞かれるのをなくす。欠席の連絡が早く来るほど空いた席を次の人に回せる。
- 効く目標：②直感的（LIFF の上に「振替 1 回・11/30 まで」を常に出す）、③作り込み（何時間前の連絡なら振替を渡すか店が決める）。
- ライバル：hacomono・STORES 予約・RESERVA・Mindbody。LINE ツールには無い。期限・残りが見えず電話になる不満（推論）→ 常に見せる。

### 2-2. 決めること・既定値

| 項目 | 既定 | 備考 |
|---|---|---|
| 振替を使う | オフ（教室のスタイルの初期セットではオン） | スタイルで出し入れ（PROPOSAL 0-2） |
| 欠席の連絡の締め | 開始の 3 時間前まで | 締めの後の欠席・無断は振替なし（店は手で渡せる）。**決定：おすすめ** |
| 振替の期限 | 元の回から 30 日 | 月謝の店は「元の回の翌月末まで」も選べる。**決定：おすすめ** |
| 振替先 | 同じクラスの種類の回（定員の空きがある回だけ） | 振替で埋まる席は通常の予約と同じ定員を使う |
| 1 か月の上限 | 2 回 | **決定：おすすめ** |
| 振替先を選ばずに欠席だけ | できる（振替は後で選べる） | kzE16：振替先を選ぶまで「欠席する」が押せない形にはしない。欠席の確定と振替先の選択は別の操作。**決定：おすすめ** |
| 回数券・月謝との関係 | 締め内の欠席は回数を戻さず「振替 1 回」を渡す（振替を使うメニューのとき）。振替を使わないメニューは B2 の「期限内の取消は 1 回戻す」 | 二重に得をしない |
| 空いた席 | 欠席で空いた席はキャンセル待ちの先頭へ知らせる（今の仕組み・F-6） | F0e5ue「次の人へ」 |
| 振替先が埋まった | 選ぶ時点で空きを確かめ直す。埋まっていたら「この回は埋まりました」と近い 3 回 | i1NoP |

### 2-3. 権限

オーナー・管理者＝決まりの設定・手で渡す・延長・取消。スタッフ＝名簿で欠席と振替を渡す・友だち詳細で手で渡す（理由必須）、決まりの設定は不可（隠す）。閲覧のみ＝見るだけ（ボタンを隠す）。統括＝ひな形の券・クラスに決まりの見本。代理ログイン＝見るだけ。

### 2-4. 状態と言葉

- 友だち詳細：振替なし（段を出さない）／残り N 回・期限／期限切れ（札「期限切れ」・履歴に残る）／使った（振替先の回へのリンク）。
- LIFF：振替の帯（残り・最も近い期限）／振替がもらえない欠席（窓に「今の欠席は振替の対象外です（3 時間前を過ぎています）」）／振替先が 0 件（「期限内に空いている回がありません。お店にご相談ください」と［お店に問い合わせる］）。
- 言葉：「欠席する」「振替」「振替先を選ぶ」「振替の期限」。「代替」「補講」は使わない。

## 3. データと API の形の案（Codex が作る・B2 と同じ束のマイグレーション）

- `booking_makeup_credits`：`id`・`line_account_id`・`friend_id`・`source_event_booking_id`（元の回）・`entitlement_id`（null 可）・`expires_at`・`status`（open／used／expired／revoked）・`used_event_booking_id`・`reason`・`granted_by`（system／staff_id）・`version`・`created_at`。元の回で一意（同じ欠席に 2 回渡さない）。
- クラス・券の種類に `makeup_rule_json`（`{enabled, cutoffHours, validDays, monthlyCap, target:'same_kind'|'list', targetIds}`）。

## 5. 連携とエラー

- LINE：期限前の知らせが届かない → 記録に「届かない」、再送しない。
- キャンセル待ち（F-6）：欠席で空いた席は今の仕組みで先頭へ（30 分の仮押さえ・2 時間前は 10 分）。振替の予約とキャンセル待ちの取り合いは保存の時に 1 件ずつ（Q-56）。
- D1：振替を使う予約と席の減算は同じ batch。

## 6. 決めていない所（B-337：おすすめで決定）

1. 締め 3 時間前・期限 30 日・月 2 回。**決定：おすすめ**
2. 欠席と振替先の選択は別の操作（選ぶまで押せない形にしない）。**決定：おすすめ**
3. 振替を使うメニューでは締め内の欠席は回数を戻さず振替を渡す。**決定：おすすめ**
