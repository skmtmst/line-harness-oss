# B9 タグで出し分ける予約メニューと指名料

- 作った日時：2026-10-16 04:24（日本時間）。担当：司令塔の作業役（予約・LIFF・運用者スマホの系）。
- 正本の順：B-306（自動の割り当て）・B-308・B-337 → 要件 04（タグ）・28（メニュー・担当）→ この文書。会員ランクの限定メニュー（G5）も同じ仕組みを使う。
- 絵：B9-1（メニューの見せる相手）・B9-2（担当の指名料）・B9-3（LIFF ② 指名料）、点検 C の C6NcOH（指名なしなのに合計に指名料 ¥500・文「指名料なし」と札「+¥500」が逆）・L6ifay（見せる相手の見本）。

## 1. 目的・効く目標・ライバルとの差

- 目的：会員だけ・初めての人だけ・常連だけのメニューを LINE の予約画面で出し分ける。人気の担当に指名料を付けられる。
- 効く目標：③作り込み、②直感的（「この人で見る」で、なぜ見えないかを店が確かめられる）。
- ライバル：Lステップ・Liny・エルメの上位プラン。エルメは自動の割り当てで指名料を取らない → musubo も**指名したときだけ**。見えない理由が店に分からない → 「この人で見る」の見本。

## 2. 要件

### 2-1. 置き場と板

| 置き場 | 板 | 足す物 |

### 2-2. 決めること・既定値

| 項目 | 既定 | 備考 |
|---|---|---|
| 見せる相手 | 全員 | タグの条件は「どれか 1 つ」。「すべて」は次の段 |
| 見えないメニューへの直のリンク | 「このメニューはご予約いただけません」と［ほかのメニューを見る］ | 隠しても API で弾く（予約の作成で確かめる） |
| 予約の後でタグが外れた | 既にある予約はそのまま | 変更（日時を変える）はできる・新しい予約はできない。**決定：おすすめ** |
| 指名料の掛かり方 | お客さまが LIFF ② で担当を選んだ時だけ。店が電話予約で担当を入れた時は「指名あり／なし」を選ぶ（初期＝指名なし） | B5 の同伴は人ごとに指名料 |
| 指名料の支払い | 料金に足す（先払い・デポジット・キャンセル料の計算の元にも入る） | 回数券の予約では指名料だけ別に「お店で払う」。**決定：おすすめ** |
| 予約の後で指名料を変えた | 予約の時の額のまま（`price_at_booking` と同じ考え） | |
| 担当を変えた | 指名ありの予約で店が担当を替えたら指名料は 0 にする（お客さまが選んだ担当でないため） | 詳細パネルの確かめの窓に「指名料 ¥500 を外します」。**決定：おすすめ** |

### 2-3. 権限

オーナー・管理者＝見せる相手・指名料の設定。スタッフ＝自分の指名料は見るだけ（変えられない）。閲覧のみ＝見るだけ（「この人で見る」は使える＝何も変えないため）。統括＝ひな形のメニューに見せる相手の見本（タグは配り先の店で選び直す）。代理ログイン＝見るだけ。

### 2-4. 状態と言葉

- メニューの一覧に札「タグで限定」。見せる相手のタグが消された（保管）→ 金の札「見せる相手のタグがありません（誰にも見えません）」。
- 言葉：「見せる相手」「この人で見る」「指名料」「指名なし（指名料なし）」「おまかせ」。C6NcOH の逆転（文「指名料なし」と札「+¥500」）を直し、指名なしの合計に指名料を足さない。

## 3. データと API の形の案（Codex が作る・小さいマイグレーション）

- メニューに `audience_mode`（all／include_tags／exclude_tags）・`audience_tag_ids_json`。
- 担当に `nomination_fee`（0 以上の整数）。
- `bookings` に `nominated`（0／1）・`nomination_fee_at_booking`（STYLE-PLAN の M4 と同じ束）。

| 道 | 入力 | 出力 | 権限 |
|---|---|---|---|
| 既存のメニューの保存（拡張） | `audienceMode`・`audienceTagIds` | | owner/admin |
| GET `/api/booking/admin/menus/preview-as?friend_id=` | 友だち | その人に見えるメニューと見えない理由 | owner/admin/staff/閲覧のみ |
| 既存の担当の保存（拡張） | `nominationFee` | | owner/admin |
| 既存の LIFF のメニュー一覧（拡張） | — | 本人のタグで絞った一覧 | 本人 |
| 既存の LIFF の予約（拡張） | `staffId` が入っていれば指名あり | 見えないメニューは 403 `menu_not_available`。指名料を合計に足す | 本人 |

## 5. 連携とエラー

外のサービスは無い。G5 の会員ランクの限定メニューは、ランクをタグとして持つ形でこの仕組みを使う。B8（Google で予約）にはタグで限定したメニューを載せない。

## 6. 決めていない所（B-337：おすすめで決定）

1. 予約の後でタグが外れても既存の予約は残す。**決定：おすすめ**
2. 回数券の予約の指名料はお店で払う。**決定：おすすめ**
3. 店が担当を替えたら指名料を外す。**決定：おすすめ**
