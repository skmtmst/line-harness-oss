## 1. 目的・効く目標・ライバルとの差

- 目的：届いた問い合わせが「誰も見ていない」にならないよう自動で担当を決め、最初の返事の期限を見える化し、遅れそうなら知らせる。
- 効く目標：② 直感的（色で急ぎが分かる）・① 引き継ぎ（誰がいつ割り当てたか残る）・③ 作り込める（店の体制に合わせた割り当て方）。
- ライバルとの差：チャネルトーク・Zendesk にはある。Lステップは優先度、エルメはランダム・優先順だけ。musubo は ①B-306 と同じ割り当て方（均等まで入れれば LINE ツールで唯一）②期限は「最初の返事」1 つだけ（Zendesk の 3 つは難しい）③営業時間の中だけ数える（夜中の問い合わせで朝に全部赤くならない）④勤務表とログイン中を見る（休みの人に割り当てない）。

### 2-4. 状態と言葉

- 一覧の札：「待ち 5 分」（灰）・「あと 12 分」（金）・「20 分過ぎ」（赤）・営業時間外は「営業時間外（9:00 から数えます）」。
- 担当の列：「Kenta（自動）」「未割り当て」。担当の食い違い（Fk2FC）：一覧と会話の頭の担当は同じ口の値を出す。
- 空：期限超過 0 件で絞ったとき「期限を過ぎた会話はありません」。
- 準備中：期限を使っていない店は札の色を付けず、上の数「期限超過」も出さない。
- 失敗：割り当てに失敗（対象 0 人・設定の読み込み失敗）は未割り当てのまま、運用状態に「割り当てできませんでした（理由）」。
- 言葉：「割り当て」「返事の期限」「最初の返事」「期限超過」「不在」。使わない：「SLA」「ラウンドロビン」「エスカレーション」。

## 3. データと API の形（案・Codex）

- 表（マイグレーション・小）：
  - `inbox_routing_settings`（店ごと）：`account_id`・`strategy`（none/even/priority/random_weighted）・`target_staff_json`（人とチーム）・`priority_order_json`（人・優先度・上限）・`default_cap`・`sla_enabled`・`sla_first_response_minutes`・`sla_business_hours_only`・`notify_before_minutes`・`escalate_after_minutes`・`escalate_team_id`・`version`・`updated_by`。
  - `chats` に欄：`assigned_by`（auto/manual/null）・`assigned_at`・`pending_since`（未対応になった時刻）・`sla_due_at`・`first_response_at`・`sla_notified_stage`（0/1/2/3）。
  - `inbox_assignment_logs`：`chat_id`・`staff_id`・`strategy`・`reason`（even/priority/random/manual/reassign/unassigned_no_one）・`decided_at`（引き継ぎ用・目標 ①）。
  - `staff_presence`：`staff_id`・`away`（不在）・`last_seen_at`（今の管理画面の操作から）。
- 口：
  - `GET/PUT /api/inbox/routing-settings`（`expectedVersion`）。
  - `POST /api/inbox/routing/apply-unassigned`（今の未割り当てに当てる・Idempotency-Key）→ `{ assigned, skipped }`。
  - `PUT /api/me/presence` `{ away }`。
  - 受信（Webhook）の中：未割り当てなら割り当てる（同じ会話は 1 回だけ・条件付き更新）。
  - 定時の見回り（毎分）：`sla_due_at` を見て知らせの段を進める。
  - `GET /api/analytics/inbox-response?from&to` → `{ byStaff: [{staffId, medianFirstResponseMinutes, withinSlaRate, count}], automatic: {count}, weekly: [...] }`。
  - 一覧の口（今の `GET /api/chats`）に `slaDueAt`・`slaState`（none/ok/soon/overdue/outside_hours）・`assignedBy` を足し、`sort=sla_due`。
