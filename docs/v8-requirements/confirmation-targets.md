# 操作する対象の確認

消す・移す・外へ反映する・一括停止する操作の確認では、実際の要求に使うLINEアカウントと、店舗を対象にする操作ではその店舗を表示する。現在の画面の先頭の店や、ほかのアカウントの店を代入しない。長い名前は1行で省略し、全文をtitleで確認できるようにする。

環境は既存の `/admin/version` の `deploy_env` を使い、検証環境・本番環境を表示する。取得中は「確認中」、失敗・未設定は「確認できません」と区別し、URLや名前から推測しない。表示の追加によって、既存の実行可否・権限・再試行・停止の条件は変更しない。環境不明で新しく操作を停止する決まりは今回追加しない。

UIDの本移行・切り戻しは、実行する履歴に保存された移行元・移行先のLINEアカウントを表示する。標準・ECを含む全スタイルで使う操作であり、店舗との対応は持っていないため店名を推測して表示しない。

確認の表示はAPIの宛先や権限検査の代わりではない。確認中に店・アカウントを切り替えた場合も、表示が実際の操作先と一致するかを動作試験で確認する。
