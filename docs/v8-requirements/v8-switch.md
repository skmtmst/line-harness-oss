# 本番を V8 に切り替える手順書

> **正はこの文書**（2026-10-07 オーナー「おすすめで全部」）。司令塔の手元の `ROLLOUT.md`（10-01）・`COMPLETION-PLAN.md`（10-04/05）・`SWITCH-READINESS.md` の条件の書き方、記録の「主要 68 画面」と食い違うときは、この文書が勝つ。

## 1. 切り替えてよい条件
- **管理画面の 434 枚（測る対象）がすべて合格**していること。合格＝絵の文字の位置が ±4px で 90% 以上合う（`measure.sh`、幅 1440・1152）＋重ねた絵を目で確かめて `PASSED.tsv` に記録したもの（`docs/v8-design-rules.md` §3）。
- **機能追加待ちの板**（板の名前に「機能追加 F-n・API待ち」）は別に数える。機能が入るまで条件の分母に入れない。
- **LIFF（お客さまの画面）の 28 枚は別の関門**。LIFF も 28 枚すべて合格してから出す。分母はあわせて 462 枚（管理画面 434＋LIFF 28）。
- 進み具合は `SWITCH-READINESS.md`（`tools/hq/switch-readiness.py` が作る）で、この条件の数え方で言う。

## 2. 切り替えの日にすること（1つの PR）
切り替えの日は**環境変数を変えるだけ**。v7 の画面・試験・分かれ道は消さない。
1. 本番の配備（`deploy-cloudflare-admin.yml`、`main` への push で配備）に `NEXT_PUBLIC_ADMIN_THEME: 'v8'` を足す。
2. `theme-switch-contract.test.ts` の「本番に変数を付けない」の確かめを、反対（付いている）に直す。
3. **前に v7 を選んだ人のブラウザの選択（localStorage `lh-admin-theme`）は、切り替えの日から無視して全員 V8 にする。**この直し（`THEME_BOOT` が 'v7' を読まない・設定画面の「画面の見た目（試作）」の切り替えを外す）は**この切り替えの PR に入れる**。巻き戻しは配備だけで行う。
4. **LIFF は管理画面と同じ日にそろえて出す。**LIFF には切り替えの仕組みが無く、★V8 の値は無条件で効くので、**それまで V8 の LIFF を本番（`main`）へ配備しない**。
5. **絵も V8 も無い 41 ページ**（`/login`・`/register`・`/password/*` など）は、今の作りのまま **V8 の色と書体だけ当てて出す**。絵は後で描く。
6. 反映履歴に1行（`docs/release-log/unreleased/<PR番号>-<担当>-<内容>.md`）と、運用者へのお知らせ。

## 3. 切り替えの日の確かめ（検証環境で先に）
検証環境の既定はすでに V8（`deploy-cloudflare-staging.yml`）。配備は手動（`tools/hq/deploy-staging.sh`、run が success かを見る）。
- **全画面を開いて落ちないこと**：管理画面の全ルートを開き、白い画面・エラーの画面・はみ出しが 0（幅 1152・1440・1920）。
- **主な流れ**：ログイン → ダッシュボード → 友だち一覧と詳細 → 一斉配信を作る → シナリオ・自動応答・リマインダを作る → 受信箱で返信 → 予約（管理画面と LIFF で予約・変更・取り消し）→ 回答フォーム → 設定とスタッフ。閲覧のみの人で、押せないボタンが隠れていること。
- **巻き戻しの練習**：検証環境で変数を外して再配備し、v7 に戻ることを1回確かめてから本番へ。
- 本番の配備のあと、同じ「全画面を開く」と主な流れを本番で見る。

## 4. 巻き戻しの手順（切り替えから1週間のあいだ）
1. 本番の配備の `NEXT_PUBLIC_ADMIN_THEME: 'v8'` を外す PR を出し、`main` へ入れて再配備する（v7 の作りは残っているので、これで v7 の見た目に戻る）。
2. LIFF は切り替えの仕組みが無いので、戻すときは LIFF の V8 の変更を revert して再配備する。
3. 戻した理由と、どの画面で何が起きたかを記録し、直してから同じ手順で切り替え直す。

## 5. 1週間後の別の PR（v7 を消す）
切り替えから約1週間、問題が無ければ別の PR で消す（消すと変数での巻き戻しは効かなくなる）。
- v7 だけが辿る画面ファイル、入口の page.tsx の v7 側、v7 だけを読む試験・見た目の契約
- `useAdminTheme` / `isV8` の分かれ道、`v7-only`・`v8-only`、`[data-theme='v8']` の囲み（値は `:root` へ）、Tailwind の `v7:` 接頭
- `layer-order: V8 移行後に消す` の1行（CSS Modules の頭）
- 設定の試作の切り替え・`THEME_BOOT`・`NEXT_PUBLIC_ADMIN_THEME`、CI の v7 の写真の比べ（`v7-pixel-diff.mjs`）
- 代わりに「合格した V8 を変えない」見張りを用意する
