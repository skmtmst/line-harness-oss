| 機能 | 入力 | 出力と動作 | 権限・失敗 |
|---|---|---|---|
| 一斉配信の期間 | GET /api/broadcasts の from/to（日本時間の YYYY-MM-DD、片側省略可） | 配信日（送信・予約・作成の順）で全件を絞ってからページ送り。状態別件数も同じ期間 | 既存の可視アカウント範囲。実在しない日付・逆転は400 |
| 自動応答の実行期間 | GET /api/auto-reply-runs の from/to（同上） | 実行日時で一覧・件数・集計・トリガー内訳を統一。CSVにも渡す | 既存の閲覧権限と入力マスク。日付不正400、不可視ルール404 |
| 自動応答のひな形 | 既存の下書き保存 actions（タグ追加・担当者通知） | ひな形の選択から実際の後続処理へ接続。通知先・タグは利用者が選び、保存時に既存検証 | 既存編集権限。未選択・他アカウント参照400/403。自動送信に manual ヘッダーは付けない |
| 成果1件あたりの広告費 | GET /api/ad-costs の accountId/from/to | 同じ期間・アカウントの広告費と確定成果数から計算。成果0件・円以外混在は金額null | 可視範囲厳守。F-21/F-22 の既存対応表・再送契約を維持 |
| 有効友だちの前月差 | GET /api/friends/stats | 前月末の有効人数・現在との差。過去記録のない期間はnull（推測しない） | 既存閲覧範囲。履歴が無いことと0人を分ける |
| 会場・申込ページ見本（d4adD4） | 既存イベント作成/更新の venue_address、venue_url。保存前の見本は入力状態 | 住所を保存して読み直せる。見本は顧客向け情報のみ、未保存のイベントは公開しない | 既存イベント権限・版チェック。文字長/URL不正400、競合409 |
| 掲載順・掲載追加報酬 | 掲載順保存（対象IDの順列・既読版）。掲載時の追加ポイント（0以上の整数・冪等キー） | 順番を保存。掲載状態変更と報酬予約を原子的に行い、同じ掲載の再操作で二重付与しない | 既存投稿権限・アカウント範囲・同意。競合409、未同意422、無効値400 |
| 登録前のタグ（GwKE2） | connect/check・connect のタグID。LINEから取得した displayName/basicId/pictureUrl | 秘密を返さず確認結果へ取得項目を載せ、登録とタグ関連を保存 | 既存owner権限、不可視タグ拒否、接続失敗は保存しない。親/担当範囲は登録後に設定 |
| サイト最終受信・広告接続 | サイト一覧の lastReceivedAt。広告の作成/更新/確認/費用再取得の既存APIを画面に公開 | サイトIDごとの最終受信。広告は疎通確認が成功したときだけ接続済み | 可視アカウント範囲・ownerの広告設定権限。秘密値を再表示しない。外部失敗は成功扱いしない |
