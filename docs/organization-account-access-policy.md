# 組織内アカウントと機能権限

## 仕様

- この環境に登録されたLINE公式アカウントは、同じ組織の管理対象として扱う。
- 認証済みの管理者・スタッフは、組織内のすべてのLINE公式アカウントへ切り替えて操作できる。
- スタッフに設定する「最初に表示するLINEアカウント」はログイン直後の既定値であり、閲覧・操作範囲を狭める認可条件ではない。
- 操作範囲はアカウント割当ではなく、役割・閲覧のみ設定・機能権限で制御する。

## 機能権限

- 受信箱のLINE・メール・担当者一覧・友だち画面内のメッセージ履歴と送信は、受信箱権限が必要。
- 友だちの一覧・詳細・タグ付けは、友だち権限が必要。
- タグ・分類・友だち情報欄・対応マーク・保存した検索・フォルダは、友だち属性権限が必要。
- URLが友だち配下にあっても、メッセージは受信箱、情報欄と対応マークは友だち属性として判定する。
- 権限が未設定または不足しているスタッフは403で拒否する。管理者は従来どおり全機能を操作できる。

## 変更時の確認

アカウント選択を使うAPIを追加するときは、担当アカウントとの差では拒否しない。新しい受信箱・友だち・友だち属性APIを追加するときは、共通の機能権限表へ登録し、権限なし・権限ありの両方をテストする。
