# Sidebar V2 実装仕様（v0.25.0 第1段階）

設計ファイル `pencil-new.pen` の再利用コンポーネント `Sidebar V2`（id `khQh9`）を、そのまま実装に落とすための仕様。
**V2の85画面すべてがこの1コンポーネントを参照している**ため、ここを合わせると全画面の印象が変わる。

- 作成日: 2026-08-16
- 対象: `apps/web` のサイドバー
- 区分 **9** ／ 項目 **30**

---

## 1. 構造

```
Head   ─ 「然」ロゴ ＋ 「然-NEN- 公式」 ＋ 「アカウントを切り替え」（ドロップダウン）
Nav    ─ 区分見出し ＋ 項目（下表）
Foot   ─ アバター ＋ ユーザー名 ＋ 権限ラベル ＋ ログアウトアイコン
```

- 幅 **256px**、常時表示（タブレット幅では 64px のアイコンレールに畳む）
- 区分見出しは項目ではない。クリックできない
- 「ダッシュボード」だけ区分に属さず、Navの先頭に単独で置く

## 3. 現行実装からの差分

現行は **6区分46項目**。46 → 30 に減るのは、機能が消えるからではなく**タブに統合されるため**。

### 3-1. 名前を変えるもの

| 現行 | V2 | 変える理由 |
|---|---|---|
| 未対応 | **受信箱** | LINE・メール・返信待ちを1か所に集約した実態に合わせる |
| 友だち管理 | **友だち** | 「管理」は全項目に付くので情報量ゼロ |
| タグ管理 | **友だち属性** | タグ／情報欄／対応マーク／保存した検索の4タブの総称 |
| アフィリエイト ＋ CV計測 | **成果とアフィリエイト** | 成果地点を決める→誰が生んだかを見る、が一続き |
| フォーム回答 | **回答フォーム** | フォームを作る画面なので、回答は結果 |
| リファラルリンク ＋ サイトスクリプト ＋ 広告連携 | **流入と計測** | どこから来たかを測る設定の総称 |
| Webhook | **外部連携** | 通知先設定も含むため |
| ユーザー一覧 ＋ スタッフ管理 | **ログインユーザー** | 予約の「スタッフ」と紛らわしいので分離 |
| BAN検知 ＋ 緊急コントロール ＋ アップデート履歴 | **運用状態** | 気づく→履歴を見る→止める、が一続き |
| 自動返信ルール | **自動応答** | Lステップと用語を統一 |
| 表示設定 ＋ メニュー設定 | **機能設定** | どちらも管理画面の見え方 |
| メニュー（予約） ＋ スタッフ（予約） ＋ 受付時間 | **予約設定** | どれも予約枠を決める設定 |
| LINEアカウント ＋ プール管理 ＋ データ移行 | **アカウント** | 追加→振り分け→引き継ぎが一続き |

## 4. 選択状態

- 開いている画面の項目に `$accent-soft` の背景、アイコンと文字を `$accent-focus`、文字を `700`
- **子画面は親の項目を選択状態にする**（例：`/events/bookings` → 「イベント予約」）
- 設計ファイルでは 83 ページすべてにこの上書きを入れてあるので、対応表として使える
