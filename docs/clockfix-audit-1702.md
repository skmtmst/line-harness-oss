# 列車21 clockfix：時刻依存の試験の点検（#1702）

## 原因と再現

原因は **(a) 試験の時計の混在**。`vi.setSystemTime` はJavaScriptのDateを止めるが、SQLiteのDEFAULT・triggerの`now`は実時計のまま。予約入りのイベント日時が固定時計より未来になると、その通知はまだ送らず、24時間前の通知だけ送るため、期待2通に対し1通になる。製品コード・DBスキーマ・配備・反映履歴は変更しない。

取得・取り込み確認した本線：`d5deaebec39819a933b58179a9b0dd67c745e9ba`。列車21と本線の対象試験・送り方の製品コードは同一。本線は別の作業ツリーでも実行した。

| SQLの実時計を見立てた時刻（TZ=UTC） | 修正前の列車21 | 修正前の本線 |
| --- | --- | --- |
| 2026-10-11T09:00:00Z | 23件合格 | 23件合格 |
| 2026-10-11T15:40:00Z | 指定の2件失敗（expected 1 to be 2） | 同じ2件失敗 |

機械の時計は変更せず、試験用の設定でDateとSQLiteのSQL時刻をそれぞれ見立てた。既存の試験内で設定される固定時計は保ち、SQLiteの`now`・CURRENT_TIMESTAMP等だけを外側の時刻に置換して再現した。
