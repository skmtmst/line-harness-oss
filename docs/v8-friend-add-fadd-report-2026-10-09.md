## 今回の修正

- 入力不足は名前・リンクの選択欄・シナリオ欄で理由を示し、最初の誤りへ移る。同じ理由を上の帯へ重ねず、入力後に消す。保存と次へ、先の手順へ進む操作で確認する。
- 共通 CheckCard に任意の `invalid` / `describedBy` を追加。未指定時の見た目は変えず、誤りを渡した欄だけ赤くし、フォーカス中も残す。
- 1152の作る②は、任意の期間・友だち条件を共通 Dialog で編集できる。閉じても同じ設定値を保ち、保存する。狭い版のLINEプレビューを横幅いっぱいの共通ボタンにした。
- 実行詳細のカード・処理行・補足箱の線を内側のoutlineにし、borderによる行ごとの高さの増加を解消。線の色・箱の数は変更していない。
- 受け皿の停止案内は共通小窓の既存propで幅600・上280を指定し、自前の注意文を共通Noticeへ置き換えた。人数不明を0人に置き換えない。
- 作成・確認・完了・実行結果・実行詳細のページ内の戻るリンクと未使用の専用CSSを削除。戻り先と絞り込みはパンくず・キャンセル側に残す。題の寸法は型に任せた。

## 司令塔の判断が要る差

- C0lfUP は受け皿メニューに「止める」が無い。一方 cFo2p は「止める」から開く説明の絵。安全な説明へ進む機能を消して合わせていない。共通 RowMenu は実際の受け皿行へ追従し、絵の固定位置とは違う。
- cFo2p は絵が左から主ボタン→キャンセル、共通 Dialog は右寄せのキャンセル→主ボタン。共通 Notice の注意には枠が付く。既定の見た目をページで上書きしていない。
- h8uNW の日時欄は共通 DateTimeField の高さ40で、絵の旧テキスト欄の36と違う。共通部品を小さくして合わせていない。
- wDzkc は撮影対象が保存済みの下書きで、対象の種類を変更不可とする既存の安全条件が働く。絵の選べるカードへ戻さず、無効の理由も残した。
- LEwkJ のフォルダ欄の印・注記や、全画面の左メニューの名前・項目数は共通担当の領域。「友だち属性」→「タグ」、対応状況の札など専用担当の変更はこのレーンで上書きしていない。
- 書き出し画像の縦位置の崩れは位置の正本TSVと食い違う。測定値と生の重ね画像を同じ基準だと扱わない。
