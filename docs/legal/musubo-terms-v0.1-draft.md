## 第1条（適用）

1. 本規約は、当社が提供する飲食店向け予約・顧客管理サービス「musubo」（以下「本サービス」といいます）の利用条件を定めるものです。
2. 本サービスを利用する法人または個人事業主（以下「利用者」といいます）は、本規約に同意したうえで本サービスを利用するものとします。
3. 当社が本サービス上に掲示する個別の規定・ガイドライン・マニュアルは、本規約の一部を構成します。

## 第2条（定義）

| 用語 | 意味 |
|---|---|
| 統括アカウント | 利用者が複数の店舗をまとめて管理するための単位 |
| 店舗アカウント | 個々の店舗を管理するための単位 |
| 管理ユーザー | 利用者が本サービスの利用を許諾した、利用者の役員・従業員等 |
| エンドユーザー | 利用者の店舗を利用する消費者（予約者、LINE公式アカウントの友だち等） |
| エンドユーザー情報 | エンドユーザーに関する情報（氏名、連絡先、予約内容、メッセージ等） |
| 運営管理者 | 当社が本サービスの保守・運用のために指定した者 |

## 第3条（登録）

1. 本サービスの利用を希望する者は、本規約に同意し、当社所定の方法で登録を申請するものとします。
2. 当社は、次のいずれかに該当すると判断した場合、登録を承認しないことがあります。
   1. 申請内容に虚偽がある場合
   2. 過去に本規約に違反したことがある場合
   3. 反社会的勢力に該当し、またはこれと関係を有すると認められる場合
   4. その他、当社が不適当と判断した場合

## 第4条（アカウントの管理）

1. 利用者は、管理ユーザーのアカウント情報（ID、パスワード、連携するLINEアカウント等）を、自己の責任で管理するものとします。
2. アカウント情報の第三者への貸与、共有、譲渡はできません。
3. アカウント情報の管理不十分により生じた損害の責任は、利用者が負うものとします。ただし、当社の責めに帰すべき事由による場合を除きます。
4. 利用者は、管理ユーザーが退職・異動した場合、速やかに当該アカウントを無効化するものとします。

## 第5条（本サービスの内容）

1. 本サービスは、次の機能を提供します。
   1. 店舗の予約情報の受付・管理
   2. LINE公式アカウントを通じたエンドユーザーへの連絡
   3. 複数店舗の横断的な管理
   4. 外部予約媒体からの予約情報の取り込み
   5. その他、当社が定める機能
2. 本サービスの機能は、事前の通知なく追加・変更されることがあります。ただし、利用者に重大な影響を及ぼす変更については、当社は合理的な期間をもって事前に通知します。

## 第6条（LINE公式アカウントの連携）

1. 本サービスの利用には、利用者自身が開設したLINE公式アカウントおよびLINE Messaging APIのチャネルが必要です。
2. LINE公式アカウントの開設・維持にかかる費用および、LINEヤフー株式会社の定める規約の遵守は、利用者の責任とします。
3. 利用者は、本サービスに登録するチャネルの認証情報について、正当な権限を有していることを保証するものとします。
4. LINEヤフー株式会社の仕様変更、アカウント停止その他当社の管理を超える事由により本サービスの一部が利用できなくなった場合、当社は責任を負いません。

## 第7条（利用料金）

1. 本サービスの利用料金および支払条件は、当社が別途定めるところによります。
2. 本規約の制定時点において、本サービスは開発中であり、利用料金は発生しません。
3. 有償化する場合、当社は少なくとも30日前に利用者へ通知し、利用者は通知期間内に解約することができます。

## 第8条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為を行ってはなりません。

1. 法令または公序良俗に違反する行為
2. 当社または第三者の権利を侵害する行為
3. 本サービスの運営を妨害する行為
4. 不正アクセス、リバースエンジニアリング、脆弱性の探索行為
5. エンドユーザーの同意を得ずに、その情報を本来の目的以外に利用する行為
6. エンドユーザーの意思に反する広告・勧誘の送信
7. 本サービスを通じて取得した情報を、当社の許可なく第三者に提供する行為
8. その他、当社が不適当と判断する行為

1. エンドユーザー情報について、**利用者が管理する主体（個人情報取扱事業者）**であり、当社はその取扱いを利用者から**委託されて処理する立場**とします。
2. 利用者は、エンドユーザーに対し、自己の責任において、個人情報の利用目的の通知・公表その他法令上必要な手続を行うものとします。
3. 当社は、利用者の指示の範囲および本規約に定める目的の範囲を超えて、エンドユーザー情報を利用しません。
4. 当社は、エンドユーザー情報の安全管理のために必要かつ適切な措置を講じます。

## 第10条（運営管理者によるデータの参照）★重要

1. 当社は、次の目的に必要な範囲に限り、運営管理者を通じて利用者のデータ（エンドユーザー情報を含みます）を参照することがあります。

   2. 利用者からの問い合わせ・サポート対応
   3. 本サービスの保守、およびセキュリティ上の確認
   4. 法令に基づく対応
2. 前項の参照は、**原則として閲覧のみ**とします。データの変更・削除を伴う操作は、利用者の依頼があった場合、または障害復旧に必要な場合に限り行います。
3. 当社は、運営管理者による参照および操作について、**実施者・日時・対象・内容の記録を保存**します。
4. 当社は、運営管理者に対し、本条に定める目的以外での利用を禁止し、秘密保持義務を課します。
5. 利用者は、当社に対し、本条に定める範囲でのデータ参照について、あらかじめ同意するものとします。

## 第12条（サービスの停止・中断）

1. 当社は、次の場合、事前の通知なく本サービスの全部または一部を停止することがあります。
   1. システムの保守・点検を行う場合

1. 当社は、本サービス上のデータを、利用契約が有効な期間中は保存します。

# 別紙1：個人情報の取扱いについて（仮）

## 1. 当社の立場

エンドユーザー情報について、当社は利用者からの**受託者**として取り扱います。

## 2. 取り扱う情報

| 区分 | 例 |
|---|---|
| 予約に関する情報 | 予約者名、人数、来店日時、連絡先、備考 |
| LINEに関する情報 | LINEのユーザー識別子、表示名、プロフィール画像、送受信メッセージ |
| 店舗の運用情報 | 管理ユーザーの氏名、メールアドレス、操作履歴 |

## 3. 利用目的

1. 本サービスの提供
2. 障害対応およびサポート
3. 本サービスの品質改善（**個人を特定できない形に加工したうえで**行います）
4. 法令に基づく対応

## 4. 安全管理措置

1. 通信の暗号化
2. LINEチャネルの認証情報の暗号化保存
3. アクセス権限の管理、および参照記録の保存
4. 検証環境と本番環境の分離

## 5. 第三者提供

当社は、次の場合を除き、エンドユーザー情報を第三者に提供しません。

1. 利用者の指示による場合
2. 法令に基づく場合
3. 第11条に基づく再委託の場合

## 6. 保存期間

利用契約の終了後90日間保存し、その後削除します（本規約第13条）。
