# 契約終了時の削除と保護トリガー（migration 759）

保護対象21表の通常の DELETE 拒否条件は残す。例外は、対象行の所属を親または LINE アカウントまでたどり、削除中の統括と表が両方一致するときだけ認める。

削除処理は、対象統括が契約終了または期限切れの試用で、削除要請済みまたは保存期限を過ぎ、未完了であることを DB で確認する。そのうえで表と統括を指定した一時的な許可行の追加、対象表の DELETE、許可行の削除を一つの原子的な D1 batch にする。失敗時は batch 全体が戻る。許可行は batch の外に残らず、別の通常操作や並行処理は利用できない。親子順と R2 の先消しは変更しない。

この境界は、通常のアプリ操作が任意 SQL や許可表への書き込みを提供しないことを前提とする。DB 管理権限で任意 SQL を実行できる者から保護する仕組みではない。許可は統括と表ごとに限定し、取消・期限や完了状態は batch 内で確認する。通常操作、他統括・他表、失敗後の残存、21表それぞれの許可と拒否を試験する。
