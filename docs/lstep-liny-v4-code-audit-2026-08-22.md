# Lステップ22分析と現行コードの照合

一次資料は [`lstep-liny-v4-source.md`](./lstep-liny-v4-source.md)。V4で見た目を変更するときに、現行機能を消さないための確認結果を記録する。

## 確定した4点

| 確認項目 | 現行 | Lステップ実機との差 |
|---|---|---|
| 友だち情報欄の型 | 10型。既定値・フォルダ・★・並び順あり | 画像・PDF・日時が無い。現行独自の数値・複数選択・チェック・URL・電話・メールは残す |
| 条件ビルダー | 13軸。AND群・OR群と友だち情報の10演算子は実装済み | イベント予約・カレンダー予約・共通情報・リマインダ等と、保存条件からコピーする入口が不足 |
| 動作ごとの条件 | 1動作ごとの条件・並び順・再発動設定は実装済み | 共通部品は5動作。テキスト・テンプレート・リマインダ・イベント予約等と、全画面から呼ぶ入口が不足 |
| 友だち詳細 | 情報欄フォルダが上段タブになり、★項目とフォーム回答を表示 | アクション実行、リマインダ、イベント・カレンダー予約等の関連タブは一部データ取得口が未完成 |

## 今回のV4へ反映したこと

- ダッシュボード: 2つの送信枠、有効友だち、対応マーク、個別再読込を提案。
- 受信箱: 3ペインとメール統合を残し、変数挿入と共通アクションの入口を提案。
- 友だち情報欄: 既定値・型固定・削除影響の説明を追加。
- 対応マーク: メッセージ受信時の自動変更設定を同じ画面へ追加する案を明記。
- 保存した検索: 15軸への拡張と「保存条件からコピー」を追加。
- CSV操作: テンプレート取得、最大500件、事前検証の4段階を明記。

## Pen.devの配置ルール

- V4は必ず8/22現行画面より左側へ置く。
- 左から「分析反映V4 → 提案ページ → 元V4 → 8/22現行画面」の順に並べる。
- 提案ページには、残す機能、変える内容、追加候補、実装時の注意を書く。
- 8/22現行画面の右側へV4制作物を追加しない。

## 実装時に落としてはいけない機能

- タグ・情報欄・対応マーク・保存検索の取得、追加、編集、削除、並び替え。
- フォルダ、★表示、CSV取込・タグCSV出力、影響確認。
- LINEとメールの統合受信箱、担当者、期限、内部メモ、添付、テンプレート送信。
- EC連携、複数人運用、Webhook、緊急停止などの自社独自機能。
