# プライバシーポリシーへ足すInstagramの節（文案）

Metaのアプリレビューでは「取得したデータを何に使い、どこに保管し、いつ消すか」を
**公開された方針として示していること**が条件です（<./instagram-app-review.md>の4番）。

いまの `musubo.jp/privacy/` にはGoogleビジネスプロフィールの節（第6項）がありますが、
Instagramについての同じ節がありません。この文書はその**文案**です。

> **これは文案です。まだ公開していません。**
> 2026-10-12のご判断は「文案を作る」でした。`musubo.jp` への反映（公開）は
> ご本人のご判断です。ご指示をいただいてから反映します。
> 反映のしかたは下の「入れる場所と手順」にまとめてあります。

## 文案（第7項として入れるもの）

見出し：**7. Instagram連携で取り扱うInstagramユーザーデータ**

本文：

> 利用者が管理画面からInstagramのプロフェッショナルアカウント（ビジネスまたはクリエイター）を
> 接続した場合、Instagramの許可画面で同意された範囲に限り、Instagram API with Instagram Login を
> 通じて次の情報を取得します。（1）接続したInstagramアカウントの識別情報、ユーザー名および
> アカウント種別、（2）そのアカウントの公開プロフィール情報および直近の投稿の一覧（接続状態と
> 投稿先を管理画面に表示するための控え）、（3）当社から送信した投稿の識別情報および公開URL、
> （4）接続を維持するためのアクセストークン。これらは、管理画面での接続状態と投稿先アカウントの
> 表示、利用者が内容を確認して実行した操作に基づくInstagramへの投稿の送信、送信結果の表示、
> ならびに接続状態の維持にのみ使用し、それ以外の目的には利用しません。
> Instagramへの投稿は、利用者が管理画面で画像と文章を確認し、「Instagramにも投稿する」を
> 自ら有効にして投稿ボタンを押したときにのみ送信し、当社が自動で送信することはありません。
> 自動の定期投稿、一括投稿、および利用者が接続したアカウント以外への投稿は行いません。
> ダイレクトメッセージおよびコメントの取得・送信・返信は行わず、その権限を求めません。
> 将来自動送信を伴う機能を追加する場合は、初期状態を無効とし、対象店舗、送信内容、実行条件、
> 頻度および停止方法を示した上で、利用者が別途有効化したときにのみ動作させます。
> Instagramに関わる操作は、利用者が管理画面にログインした状態でのみ実行でき、長期間有効な
> APIキーを用いた外部プログラムからの利用はできません。
> 当社は、Instagramから取得した情報を販売せず、広告配信、ユーザープロファイリング、与信判断、
> および汎用的なAI・機械学習モデルの開発や学習には一切利用しません。本サービスの提供に必要な
> 委託先での処理と、法令に基づく場合を除き、第三者に提供しません。当社担当者による内容の閲覧は、
> 利用者からの明示的な依頼に基づくサポート、セキュリティ上の調査、法令上の要請、または集計・
> 匿名化された形で行う場合に限ります。アクセストークンは暗号化して保存し、管理画面にも記録にも
> 表示しません。利用者が管理画面で接続を解除した場合、またはInstagram側でアクセス権を取り消した
> 場合は、トークンおよびそのアカウントについてInstagramから取得した内容（識別情報、ユーザー名、
> アカウント種別、プロフィール、投稿の一覧）を直ちに削除します。利用者が退会した場合も同様に
> 削除します。Instagramから取得した情報の取扱いは、Metaのプラットフォーム利用規約および
> 開発者向け方針に従います。

## 仕組みと一致していることの確認

文案に書いた内容が、実際の作りと合っていることの対応です。

| 文案の記述 | 根拠 |
| --- | --- |
| 取得するのは識別情報・ユーザー名・種別・プロフィール・投稿一覧・トークン | `packages/db/migrations/603_instagram_connections.sql` の `instagram_connections`（`instagram_id` / `username` / `profile_json` / `posts_json` / `page_token_encrypted` / `user_token_encrypted`） |
| 投稿は利用者が有効にしたときだけ | `packages/db/migrations/611_instagram_cross_post.sql` の `instagram_enabled`（既定値 `0`＝無効） |
| 送信結果（投稿の識別情報・公開URL）を保存する | 同611の `instagram_media_id` / `instagram_permalink` / `instagram_status` |
| 自動送信はしない | `apps/worker/src/routes/restaurant-google-posts.ts`。投稿は管理画面の操作でのみ走る |
| DM・コメントは扱わない | 求める許可は `instagram_business_basic` / `instagram_business_content_publish` の2つだけ（<./integrations/instagram-connection.md>） |
| トークンは暗号化して保存 | `META_TOKEN_ENCRYPTION_KEY` による暗号化。列名は `*_encrypted` |
| 解除時に消す | 接続解除の窓口（`apps/worker/src/routes/instagram.ts`） |

## 入れる場所と手順（公開のご指示をいただいてから行います）

`musubo.jp` は Cloudflare ではなく **Xserver 上の別の静的サイト**です
（<./musubo-service-site.md>）。プライバシーポリシーのHTMLは直接置かれておらず、
`sites/musubo/src/legal.mjs` から生成されます。

| やること | 場所 |
| --- | --- |
| 1. 上の文案を第7項として追加 | `sites/musubo/src/legal.mjs` の `kind === "privacy"` の並び（第6項の直後） |
| 2. いまの第7〜13項を第8〜14項へ番号をずらす | 同じ並びの中 |
| 3. 第2項の「第6項に定めます」を「第6項および第7項に定めます」へ直す | `sites/musubo/src/legal.mjs`（88行目） |
| 4. 第5項の委託先の列挙にMeta（Instagram）を足す | 同（100行目） |
| 5. 国外での取扱いの文の列挙にもMeta（Instagram）を足す | `sites/musubo/site.config.mjs`（47行目） |
| 6. テストとビルドを通す | `node --test sites/musubo/test/` と `node sites/musubo/build.mjs` |
| 7. 公開 | `node sites/musubo/deploy-production.mjs`（まず下見）→ `--apply` |

- 項の番号を直接見ているテストはありません（`sites/musubo/test/site.test.mjs` を確認済み）。
  番号をずらしても落ちません。第5項の「AI画像生成では」という言い回しだけは
  テストが見ているので消さないこと。
- 公開は `privacy/index.html` を含む11ファイルの転送です。`--delete` は使いません。
- 公開後の確認：5つのページがHTTPSで表示されること、施行日 `2026-10-04`、
  保存期限の記載、`noindex` が無いこと、`sitemap.xml` の `<loc>` が5件。
- **DNS・MX・SPF・DKIM・メール設定・ネームサーバー・`.user.ini` は触りません。**

## 施行日について

第7項を足すと方針の内容が変わるため、**施行日の更新が必要かどうかはご判断ください**。
いまの施行日は `2026-10-04` です。足すのは「新しくInstagramを接続した場合の取扱い」であり、
既にお使いの範囲の取扱いを変えるものではありません。
