## 1. Codexへの依頼：APIが3つ足りない

**3つとも同じ性質。「そのタグがどこで、どう使われているか」を数えて返す口が
1つあれば全部埋まる。** 推測で埋めていないので、いまは空欄か2値に落ちている。

| 列 | 設計が出すもの | いま | 要るもの |
|---|---|---|---|
| **自動付与のもと** | EC連携／LINE Login／回答フォーム／EC購入／手動／誕生日ルール（6種） | 連動の有無から2種だけ | タグごとの付与元 |
| **使用先** | `配信3・フォーム1` `シナリオ2` `自動応答1` `保存検索2` | `—` | 使われている場所と数 |
| **連動の「他N」** | 灰色の札 `他1` `他3` | 出していない | マイル以外の連動アクション数 |

### 提案する形

`GET /api/tags` の各行に足す。別の口にすると、一覧のたびにN+1回叩くことになる。

```ts
type Tag = {
  // …既存
  /** 付与のきっかけ。取れないときは省く（'manual' で埋めない）。 */
  assignSource?: 'ec' | 'line_login' | 'form' | 'ec_purchase' | 'manual' | 'birthday'
  /** 使われている場所と数。0件の種類は入れない。 */
  usedIn?: { broadcasts?: number; forms?: number; scenarios?: number; autoReplies?: number; savedSearches?: number }
  /** マイル以外の連動アクションの数。 */
  otherActionCount?: number
}
```

**取れないものを既定値で埋めない。** `0` と「取れていない」は別。
`他0` と出すと、設定してあるのに無いように見える。

### 入れる場所

- `apps/web/src/components/friend-fields/tags-page-v4.tsx` の
  `sourceLabel()` / `usageLabel()` / `linkChips()` に1行ずつ。
  **どこに何を足すかはコメントで書いてある。**

## 3. 4-1で見つかった不具合（ほかの画面にも同じものがあるはず）

**画像で並べたから見つかった。テストは全部通っていた。**

| 不具合 | 中身 | ほかも見るべきか |
|---|---|---|
| `--text-title`(20px) が未定義 | トップバーが `var(--text-title)` を読んでいたが変数が無く、画面名が16pxに落ちていた。**CSSは未定義の変数を黙って無視する** | **要**。`var(--…)` が全部定義ずみか一度洗う |
| `--radius-mini`(6px) が未定義 | 行の中の札の角丸が書けなかった | 同上 |
| 「付与済み友だち」の数え方 | タグごとの人数を**足していた**。2つタグが付いた人を2人と数える | **要**。ほかの一覧も画面で数えていないか |
| 設計のフォントが2系統 | Noto Sans JP 6,753 と Inter 4,565 が混在。Inter は共通関数の既定値が入り込んだもの | 済。設計側を統一した |
| 共通部品があるのに自前で組んでいた | ページ送りは設計と一致した部品が既にあった | **要**。ほかの一覧も同じはず |

## 4. 画面を見る手順

**これが無いと、設計と比べられない。** ローカルで開くのに4つ要る（`v6-shell-contract.md` §10）。

```bash
# 1. 共有パッケージを建てる（無いと全ルート500）
pnpm --filter "@line-crm/shared" --filter "@line-crm/line-sdk" --filter "@line-harness/update-engine" build

# 2. Workerの代わり（ローカル専用・GET以外は405・固定データ）
pnpm qa:mock

# 3. 管理画面
pnpm qa:web

# 4. 画像で比べる（1440・1920）
pnpm qa:shot
```

- `scripts/visual-qa/mock-api.mjs` … 本番では起動しない。更新は必ず失敗する
- `scripts/visual-qa/fixtures.mjs` … **Pencil の絵に書いてある値そのまま**。
  タグ101件・フォルダ6つ・KPI 4枚。**6件だけで比べない**（桁あふれも折り返しも
  ページ送りも出ず、「一致した」と言えてしまう）
- `scripts/visual-qa/routes.mjs` … 見張るルート。いま**7ルート × 1440/1920 = 14件**。落ちる5ルートは `NOT_READY` に分けてある。
  増やすときは、そのルートが本当に描けることを手で1回確かめてから足す

**初回は基準の画像が無いので全件「失敗」になる。** 撮り終えてから
もう一度走らせると通る。基準画像は `capture.spec.mjs-snapshots/` に入る。

### 見張っている3つ

1. 描けているか（「画面を表示できませんでした」「店舗が選ばれていません」が出ていない）
2. **1440px と 1920px の両方で横スクロールが出ていないか**
3. 前回の画像と変わっていないか（Next.js の開発表示は隠して比べる。
   写し込むと毎回3〜4%ずれて、誰も見なくなる）

### 落ちたときに多いもの

**`◯◯.filter is not a function`。** モックが器（`{items,…}`）で返しているが、
その口は配列を返すもの、という取り違え。`mock-api.mjs` の `ARRAY_PATHS` か
`ARRAY_PREFIXES` にその口を1つ足す。**推測で足さない。落ちた画面のコンソールを見る。**
