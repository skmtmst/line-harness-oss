# 環境設定と秘密情報の名前

基準: `4af277b424e1d171a47ab1437238b1dbcf95799c`、2026-10-18。コードと追跡済み設定の一覧。実際の.env/.dev.vars・Cloudflare secretの値・顧客情報は取得も掲載もしていない。稼働環境の設定がこの一覧どおりであることを保証する点検ではない。

## 手元・検証・本番での置き場所

| 対象 | 手元 | 検証 | 本番 |

NEXT_PUBLIC_* と VITE_* は配信JavaScriptに入る公開情報。認証token・署名鍵・暗号鍵を入れない。既存のNEXT_PUBLIC_ADMIN_API_KEYは例外的な旧公開キー設計として残っている。ここで新たな値の設定は勧めず、S02/司令塔に利用経路の確認を渡す。Workerのsecretは環境ごとに別保管し、vars・例・文書・ログに値を書かない。

.env.exampleは空値の名前表で、コピーだけで起動できる設定ではない。空文字と未設定ではコードの??/||判定が異なるため、使わない任意行は削除してから使う。実送信・決済・外部書込の許可はこの文書から発生しない。

## 配備・CIだけの名前

CLOUDFLARE_API_TOKEN/CLOUDFLARE_ACCOUNT_ID、CF_API_TOKEN/CF_ACCOUNT_ID等は配備用スクリプトやGitHub Secretsでも使う。Workerの同名secretと手元シェルの認証は別の保管場所。laneの通常作業にはCloudflare認証は不要で未設定が正しい。DOCTOR_LOCAL=1はdoctorの手元検査だけの指定。GitHub secretsの値はこの一覧の作成では取得していない。

required-pr-gateのWorker同梱画面buildに渡すVITE_LIFF_ID/VITE_BOT_BASIC_ID/VITE_CALENDAR_CONNECTION_IDと、V8_SPEED_ENFORCEMENTはGitHubの公開vars。未取得と空設定を区別して、司令塔が実一覧で照合する。V8_SPEED_ENFORCEMENTは製品の旗ではなく検査の判定設定。省略して合格扱いにしない。
