# V8 移行 ① — V5/V6 名の試験の仕分け表

対象: `src/` 配下の試験ファイルのうち、ファイル名または `test`/`it`/`describe` の
名前に `v4`/`v5`/`v6` を含むもの（計 164 本）。

- **機能を守る**（32 本）: 動き・文言・API・状態を固定する試験。⑥ でも消さない。
- **混在**（113 本）: V6 実ノード・構造の固定と、動きの固定が同居する契約試験。⑥ で見た目を固定する行だけ削る。
- **古い見た目を守る**（19 本）: V5/V6 の寸法・骨格・部品値・配置を固定する試験。V8 では値が変わるため ⑥ で消す（または V8 の値へ書き換える）。

判定はファイル内容から行い、命名だけでなく「実Node ID・data-design・寸法・構造を
アサーションしているか」を基準にした。境界のものは ⑥ の作業時に再判定してよい。
