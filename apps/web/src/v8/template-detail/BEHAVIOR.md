## 受け付ける URL と指定
- `/templates/detail?id=<テンプレートID>`。`id` が無い・見つからない（404・形の違う応答）・読めないときは TargetMissing（一覧へ戻る／もう一度読み込む）。

## 呼ぶ口
- `api.templates.get`（詳細・使っている所）・`versions`（版の履歴）・`api.folders.list('template')`（フォルダ名）・`api.templates.list`（今月送った数）。
- 公開 `publish`（`expectedVersion`・`expectedDraftRevision`）。409 は窓の中に「ほかの人が先に…」と出して読み直す。
- この版に戻す `revert`（確かめの窓）。削除 `delete`（使っている所が 0 のときだけ。1 か所でもあれば「まだ消せません」の窓）。
- 複製 `create`：**いま使っている版（公開済み）の中身**で「〇〇のコピー」を作り、その詳細へ。直しかけの下書きは写さない。公開済みの版が無いときは複製のボタンを置かない。

## 画面
- 頭：戻る・名前・「種類・フォルダ・更新 日時」。型は「作る」の頭（下の帯は無い）。
- 左：未公開の帯（比べる＝いまの版と下書きの差を下に出す・公開する）→ 本文（編集する）→ 使っている所（4 行まで・「ほか N か所を見る」・行の「開く」）→ 版の履歴（下書き・いま使っている版・前の版。比べる・この版に戻す）。
- 右：一斉配信で使う・複製する・…（使っている所をすべて見る・削除する）→ このテンプレートについて（種類・フォルダ・今月送った数・差し込み）→ LINEでの見え方。カード型は形を確かめ、壊れていれば誤りと直し先を出す。
- 窓：公開（反映される所 4 行・ほか N か所・変わるところ（－ 消えた行／＋ 増えた行）・キャンセル／公開する（N か所に反映））。削除できない（2 行・開いて差し替える・ほか N か所・閉じる／使っている所をすべて見る）。
- 閲覧のみ（owner/admin 以外）：編集する・公開する・比べる（帯）・この版に戻す・一斉配信で使う・複製する・… を置かない（隠す）。
