# 電話の画面の対応（BEHAVIOR.md）

入口 `app/m/todo/page.tsx`（`/m/todo`）。下のタブの「対応」。決まりは `docs/v8-design-rules.md` §6.48。絵はまだ無い（司令塔があとで描く）。

- 返事を待っているトーク：受信箱の「未対応」（`GET /api/chats?status=unread&accountId=…&limit=20`）。受信箱を見る権限がある人だけに出す。押すと既読を付けて（`POST /api/chats/:id/read`。担当者ごとの既読で、対応の状態は変えない）電話の画面の会話を開く。20 件ちょうどの時は［すべて見る］でトークの一覧へ。
- 確かめるお知らせ：通知の中心の「エラー」（`GET /api/notifications/center?category=error&limit=20`）のうち、まだ読んでいない物。押すと既読を付けて行き先を開く。行き先は PC と同じ判定（`v8/notifications/destination.ts`）で、電話の画面に当たる画面（受信箱）は /m へ、無い物は PC の画面を開く（カードに「PC の画面で開く」）。
- 読み込み中・失敗（［もう一度試す］）・空（「今、対応が要るものはありません」）を段ごとに出す。取れない数を 0 にしない。
- アカウントを切り替えたら、前の店の答えが後から届いても出さない（世代で照合）。
- 新しい口（API）は作らない。予約の承認待ちなどは段②（今日）以降で足す。
