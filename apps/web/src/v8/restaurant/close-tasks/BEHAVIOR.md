# 他のサイトの枠を閉じる知らせ（V8）の動き

入口：`app/restaurant-test/close-tasks/page.tsx`（新しい画面なので V8 だけ）。絵：提案 E-5 `YMVFD`。今日のお店の帯の「すべて見る」から。

## 読む口・書く口
- 店舗：選んでいる店舗（`store-context`）→ 無ければ先頭。
- `GET /api/restaurant-test/channel-close-tasks?storeId=`：知らせ（枠×媒体で1件）。`GET /api/restaurant-test/channels`：媒体の名前。
- ［閉じた］：`POST /api/restaurant-test/channel-close-tasks/:id/done`（媒体ごと）。

## 一覧
- 1行＝1つの枠（時刻）。列：枠の日時（と「残り 2席になりました」「満席になりました」「卓が重なる予約が届きました」）・閉じる媒体（札。閉じた媒体は ✓）・状態・操作。
- 状態：未対応（どれも閉じていない）・残り Nつ（一部閉じた）・もう開けてよい（席が戻った）・閉じた（全部閉じた）。
- タブ：未対応（閉じた以外）／閉じた。数はタブの右。
- 探す：枠の日時・媒体の名前で絞る。媒体：その媒体を含む枠だけ。
- ［✓ 閉じた］：まだ閉じていない先頭の媒体を済みにする（名前は読み上げと title で分かる）。ほかの媒体は「…」の「〇〇を閉じた」。

## 今の口で出せないもの（口ができたら足す）
- 予約の日時・人数・名前・入った経路（知らせが予約ではなく枠に付いているため）。
- ［管理画面を開く ↗］（媒体の管理画面の URL を保存する口が無い）。
- 「もう開けてよい」の行の［開けた］（開けた印の口が無い。いまは札だけ）。

## 閲覧のみ
- owner・admin・staff 以外には［閉じた］と「…」を置かない。
