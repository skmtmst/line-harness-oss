# 電話予約・ウォークイン（V8）の動き

今日のお店（`../dashboard`）の頭のボタンから開く。絵：提案 E-2 `wEzuG`（引き出し）・E-3 `nNujj`（窓）。

## 電話予約（phone-drawer.tsx・右から出る引き出し）
- 電話番号：4桁から、打つのが止まって 250ms 後に `customerSearch` で探す。LINE の友だちだけを候補に出す（3件まで）。押すと選択中になり、お名前が入る。打ち直すと選び直し。
- お名前・人数（−/＋、1〜100）・日付（今日／明日／日付を選ぶ）。
- 時刻（空いている時刻だけ）：その曜日の開ける時間（`openingHours`）のうち2時間いられる30分ごとの始まり。読めないときは 17:00〜21:00。今日は過ぎた時刻を出さない。人数が入る空いた卓が無い時刻は出さない（`reservationsDay` で重なりを見る。取消・無断・期限が過ぎた押さえは数えない）。
- 卓：人数が入る空いた卓のうち余る席がいちばん少ない卓を自動で割り当てる（口の自動配席と同じ）。2つ以上あれば「変える」で選べる。
- メモ（任意）→ 予約のメモ。
- 「LINE で確認を送る」：友だちを選んだときだけ出す（既定オン）。
- ［✓ 予約を入れる］：`POST /api/restaurant-test/reservations/manual`（source=phone・2時間・選んだ卓・notifyLine）。LINE が送れなかったら「予約は入れました。LINE の確認は送れていません。」。失敗は引き出しの下に理由。
- 手数：電話番号 → 候補 → 時刻 → ［予約を入れる］の3〜4手。
- 入力中は題に「*」が付く。閉じると入力を破棄する（開くたびに空から始める）。

## ウォークイン（walk-in-dialog.tsx・中くらいの窓 560）
- 頭：「いま 18:12 ・ 空いている卓 5」（動いている卓のうち、いま予約が重なっていない卓）。
- 人数（−2＋）を変えると、今すぐから2時間座れる卓だけに絞り直す（余る席が少ない順。いちばん合う卓を選んでおく）。
- 満席：「いま座れる卓はありません」と、人数が入る卓がいちばん早く空く時刻（約N分）。
- ［入店にする］：`walk-in.ts` の `seatWalkIn`（1か所）。2手で済む。

## ウォークインの口（walk-in.ts・1か所）
- いまは「予約なしの来店」の口が無い（Codex が作り中）ので、手動予約の口（source=manual・お客さま名「ウォークイン」・メモ「ウォークイン（予約なしの来店）」・今から2時間・LINE は送らない）で作り、すぐ `postSeatVisitMark(kind=visited)` で来店にする。
- 来店の印だけ付かなかったときは予約を残し、「表の［来店］を押してください」と知らせる。
- 口ができたら `seatWalkIn` の中身だけを差し替える。今日の数の「ウォークイン」は `isWalkIn`（メモの頭）で数えているので、そこも一緒に差し替える。
