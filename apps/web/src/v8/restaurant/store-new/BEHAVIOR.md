# 店舗を追加（V8）の動き

入口：`app/restaurant-test/stores/new/page.tsx`（V8だけ）。
絵：①利用規約への同意 `ao15G`・②店舗の基本情報 `faGn4`。③〜⑤は絵が無いので①②と同じ形。

## 受け付ける URL と指定
- `/restaurant-test/stores/new`：指定なし。開いたとき `termsAgreement` で、いまの版に同意済みなら②から始める。

## 呼ぶ口（今の画面と同じ）
- `termsAgreement`・`agreeToTerms(key, version)`・`connectStore({ name, alias, channelId, channelSecret })`・`selectStore`（登録後「この店舗の管理画面へ」でダッシュボードへ）。

## 決まり（今の画面と同じ）
- ①：枠の中の規約を最後まで読む（スクロール不要なら読んだことにする）→ チェック → 「同意して次へ進む」。
- ②：店舗名は必須。略称は空なら店舗名。
- ③：「LINE公式アカウントを作成済みです」にチェックで次へ。
- ④：チャネルID・チャネルシークレットは必須。シークレットは登録後に画面から消す。
- 入力が残っている間に離れると確認（R161）。
- 同意した手順①は「利用規約」へのリンクになる。

## 変えた所
- 「同意して次へ進む」・「次へ」・「キャンセル」は下の線の下の中央（絵どおり）。キャンセルは統括（/hq）へ。今の画面の右上「統括へ戻る」はキャンセルが兼ねる。
- 同意した日時は日本時間の「10/2 23:41」（今の画面は日付だけを端末の時刻として読んでいた）。
- マニュアルの URL が空の間は、ボタンを出さない（押しても行き先が無いボタンを置かない）。「アカウント作成方法・連携ガイド」はマニュアルの正本表の手順キー `onboarding-line-guide`（`GET /api/manual-links/lookup?keyKind=task`）から引き、URL がある時だけ出す。
- 規約の本文は今と同じ TERMS_DOCUMENT。見た目だけ V8（見出し12/700・本文11/19）。仮の規約の注意は枠の先頭に出す。
