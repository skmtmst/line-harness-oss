# 店舗ダッシュボード（V8）の動き

入口：`app/restaurant-test/dashboard/page.tsx`（V8 だけで出す。今までどおり完全切り替え）。絵：`CHz31`。

## 受け付ける URL と指定
- `/restaurant-test/dashboard`：指定なし。

## 呼ぶ口（今の画面と同じ）
- `restaurantTestApi.snapshot(accountId, { from: 今日0時, status: 'pending,confirmed,seated,visited', limit: 500, offset: 0 })`。

## 数（今の画面と同じ根拠）
- 予約数・ご来店予定：今日以降に始まる、取消・無断キャンセルでない予約。
- 空席率：1 −（ご来店予定 ÷ 全店舗の収容数の合計）。時間帯ごとの空きではない（「？」に書く）。
- 売上予測：コース単価×人数。コース未設定の予約は含めない。無いときは「—」と「コース設定がありません」。
- 未返信口コミ：Google口コミの未返信。1件以上で琥珀色。
- 店舗一覧の右上：LINE エラーの店舗数＋予約媒体の受信口のエラー・要確認の数。0なら「すべて正常」。

## 表
- 列：店舗（名前・コード）・エリア・予約・予定人数・収容数・LINE・Google・予約媒体（レストランボードの受信口の状態。無ければ「未設定」）。
- 表は div の並び（role="table"）。絵の列幅（100・64・80・72・90）どおり。

## 押せないもの
- 全店アクション（Google 一斉投稿・LINE 一斉配信）は未接続のため押せない形のまま（今と同じ）。
