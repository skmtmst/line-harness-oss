# 今日のお店（店舗ダッシュボード・V8）の動き

入口：`app/restaurant-test/dashboard/page.tsx`（V8 だけで出す）。絵：提案 E-1 `hKRRF`（採用 2026-10-07）。
全店の一覧（前の店舗ダッシュボード `CHz31`）は `?view=stores` で残す（`stores.tsx`。動きは下の「全店の一覧」）。

## 受け付ける URL と指定
- `/restaurant-test/dashboard`：今日のお店（選んでいる店舗＝`store-context`。無ければ先頭の店舗）。
- `/restaurant-test/dashboard?view=stores`：全店の一覧（CHz31）。

## 板の頭・店のタブ
- 題「今日のお店」、説明は「10月7日（水）・営業 17:00〜22:00・更新 13:31」（営業時間は `openingHours` の今日の曜日。休みの日は「休み」。読めないときは出さない）。
- 右に［＋ ウォークイン］（副）［＋ 電話予約］（主）。閲覧のみには置かない。
- 店のタブ（`store-tabs`）：ダッシュボード・予約（今日・今月・一覧）・座席・卓・予約枠・在庫。予約台帳・座席・卓管理・予約枠・在庫の頭にも同じタブが出る。左メニューの項目は残す。

## 読む口（use-store-today.ts）
- `snapshot`（今日0時〜明日0時・500件）：店舗と卓。`store-context`：選んでいる店舗。
- `reservationsDay(店舗, 今日)`：今日の予約の表と数。30秒ごとに読み直す（媒体・知らせも一緒に）。
- `GET /api/restaurant-test/channels`：予約サイト・グルメ媒体の名前（受信の口＝手入力・レストランボード・レス在庫は除く）。
- `channelCloseTasks(店舗)`：枠を閉じる知らせ。
- Google：`restaurant-test/google/connection`（つながっているか・平均・件数・未返信の数）と、未返信の口コミの新しい1件・古い1件（`reviews?filter=unreplied`）。

## 他の予約サイトの枠を閉じる知らせ（帯）
- 未対応（まだ閉じていない媒体がある枠）があるときだけ出す。題「他の予約サイトの枠を閉じてください（未対応 N件）」、Nは枠の数。
- 文：いちばん早い枠の「10/7（水）19:00 の枠が残り 2席になりました → ホットペッパー・食べログ の枠を閉じてください」。
- ［〇〇の管理画面を開く ↗］：媒体の管理画面の URL が保存されたら出る（保存の口は Codex が作り中。いまは出ない）。
- ［✓ 閉じた］：いちばん早い枠のまだ閉じていない先頭の媒体を `completeChannelCloseTask` で済みにする（媒体ごと）。閲覧のみには置かない。
- 「すべて見る」：枠を閉じる知らせの一覧（`/restaurant-test/close-tasks`）。

## 今日の数（数の帯・4つ）
- 今日の予約（組）：取消・無断キャンセル・押さえを除く今日の予約。補足は経路の内訳（LINE・電話・ウォークイン・予約サイト。0 の経路は出さない）。→ 予約台帳を開く。
- 来店予定（人）：同じ予約の人数の合計。補足はいちばん人が多い時（00分の1時間ごと）。→ 時間ごとに見る（予約台帳の今日）。
- 空席（いま）（卓）：動いている卓のうち、いま予約が重なっていない卓。補足は「全 N 卓・カウンター N 席」。→ 席を見る。
- 未返信の口コミ（件）：Google の未返信の数。いちばん古い未返信の「最長 N日前」の札。補足は「Google ★4.2（24件）」。→ 返信する。Google とつないでいないときは「—」と「つなぐ」（SNS 連携へ）。

## 今日の予約の表
- 列：時刻・名前・人数・卓・経路・状態・来店。取消は出さない。時刻の順。
- 経路：ウォークインで入れた予約（メモの頭が「ウォークイン」）は「ウォークイン」、ほかは予約元の名前。
- 状態：来店済み（緑）・予約中（青）・承認待ち（琥珀）・押さえ・無断キャンセル。
- ［✓ 来店］：承認待ち・予約確定の行だけ。`postSeatVisitMark(kind=visited)`。失敗したら知らせて読み直す。
- 「…」：予約台帳で見る／来店の印を取り消す（来店済みの行だけ・`deleteSeatVisitMark`）。

## 右の列
- 予約サイト・グルメ媒体：媒体の名前の一覧。店舗ページ・管理画面のリンクは保存の口ができたら行に出る（いまは名前だけ）。
- Google の口コミ：未返信の新しい1件（星・名前・何日前・未返信の札・本文・［返信する］＝口コミの返信の下書きへ）。つないでいなければ「SNS 連携でつなぐ」。
- Instagram の新着：Instagram はつなげるようになったが（投稿の同時公開まで）、DM・コメントを受け取る口がまだ無いので「まだここに出せません」と SNS 連携への案内だけ。

## 電話予約・ウォークイン
- ［＋ 電話予約］は右の引き出し、［＋ ウォークイン］は窓。動きは `../front-desk/BEHAVIOR.md`。保存したら知らせを出して読み直す。

## 閲覧のみ
- 役割はサーバ（`useStaffRole`）から読む。owner・admin・staff 以外には［ウォークイン］［電話予約］［閉じた］［来店］［返信する］と「…」の取り消しを置かない（サーバの 403 が最後の守り）。

## 全店の一覧（`?view=stores`・`CHz31`）
- 前の店舗ダッシュボードのまま：数5（予約数・ご来店予定・空席率・売上予測・未返信口コミ）→ 店舗一覧 → 全店アクション／同期方針。
