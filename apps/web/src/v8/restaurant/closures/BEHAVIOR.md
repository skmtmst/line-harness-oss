# 休業日・貸切（V8）の動き

入口：予約枠・在庫（`app/restaurant-test/inventory/page.tsx` → `v8/restaurant/inventory/inventory.tsx`）のタブ「休業日・貸切」。`?tab=closures` で開く（押したタブも URL に残す）。絵：提案 E-10 `UVnvR`（タブ）・`nVvXy`（足す窓）。新しいタブなので V8 だけ。

## 読む口
- `GET /api/restaurant-test/closures?storeId=`（月を付けずに全部）：カレンダーと「これからの休業・貸切」。
- `GET /api/restaurant-test/opening-hours`：曜日ごとの営業時間。時間帯が1つも無い曜日を「定休」として升に出す（営業時間を読めないときは出さない）。
- `GET /api/restaurant-test/channel-close-tasks`：休業・貸切の閉じる知らせ（`reason=closure`・`closureId`）。上の帯と右の列の「他サイト 未対応 N／閉じた n/m」。
- `GET /api/restaurant-test/media-links`：媒体の名前・管理画面の URL・「予約が入ったら閉じる」。窓の「〇〇に閉じる知らせを出す」の名前はこの「閉じる」媒体。
- `restaurantTestApi.snapshot`（見ている月と今日から3か月先）：記録ごとの「予約 N件」を数える（取消・無断キャンセルを除く・卓を選んだ記録はその卓と卓未定の予約）。範囲の外の記録は件数を書かない。
- `GET /api/restaurant-test/google/profile`：特別営業時間。読めない（つないでいない）ときは「Google ビジネスとつないでいないため…」と［つなぐ］。

## 画面
- 板の頭：説明は「店舗名 ・ 1つの時間帯の総数 N席（稼働中の卓 M）」。右上に［＋臨時休業・貸切を足す］（今日で開く）。店舗が2つ以上のときだけ店舗を選ぶ欄も出す。検証環境の帯は出さない（絵どおり）。
- 上の帯：まだ閉じていない媒体がある、いちばん近い休業・貸切。「〇月〇日（曜）の臨時休業：他の予約サイトの枠を閉じてください（未対応 N件）」「LINE の受付は止めました → 媒体名の 〇月〇日 を終日閉じてください」。［〇〇の管理画面を開く ↗］（URL があるときだけ・別のタブ）・［✓閉じた］（先頭の媒体を済みにする）・すべて見る（他のサイトの枠を閉じる知らせの一覧）。
- カレンダー：日曜はじまり。前の月・次の月・今月。臨時休業・設備点検・その他は桃、貸切は琥珀、定休は灰の札。升には種類・「終日・全卓」か時間帯・「予約 N件」か閉じる卓。同じ日に2件以上あれば「ほか N件」。今日は緑の太字。
- 日を押す：記録のある日はその記録を変える窓、無い日はその日で足す窓。今日より前の日は押せない。
- 右の列「これからの休業・貸切」（終わりの日が今日以降、始まりの順、6件まで）：日付・種類の札・「…」・範囲・メモ・「予約 N件 ・ 連絡済み N件 ・ 他サイト 未対応 N」（未対応があれば赤）。予約・連絡済みの数は `GET /closures/:id/contact-status`（休業を作った後に担当者が LINE で送った予約。閲覧のみも読める）。読めない記録は読んだ予約から数え、連絡済みは書かない。
- 「…」：変える・予約台帳でこの日を見る・消して開ける（確かめる窓）。閲覧のみは「予約台帳でこの日を見る」だけ。
- Google の営業時間：まだ Google の特別営業時間に入っていない、いちばん近い店全体の休み（貸切・卓を選んだ記録は除く）。［Google にも〇〇を入れる案を作る］＝`POST /google/hours/from-closure`。作ったら「案を作りました」と［Google ビジネスで確かめる］。自動では送らない。

## 足す・変える窓（nVvXy）
- 種類（臨時休業・貸切・設備点検・その他）・はじめの日〜おわりの日・時間（終日／時間帯だけ：30分刻み、終わりは 24:00 まで）・閉じる卓（全部の卓／卓を選ぶ）・メモ（任意・200字）。
- 入力が変わると 0.3 秒待って重なる予約を出す。`POST /closures/preview`（電話番号・LINE の友だちか・連絡済みが返る）。変える窓は `excludeId` で自分自身を除く。口が読めないときは読んだ予約から数える。
- 重なる予約：「この日の予約が N件あります（保存しても取り消しません）」（変える窓は「・連絡済み N件」も）。LINE の友だちは［LINE で連絡する］＝受信箱のその友だち（`/chats?friend=`）へ移る（自動では送らない）。連絡済みの予約は［連絡済み（会話を見る）］。それ以外は［電話で連絡（番号）］＝予約台帳のその日へ。番号は preview の `customerPhone`（無ければ読んだ予約）。キャンセル待ちがあれば件数を出す。
- ほかの休業・貸切と重なる（preview・保存の 409 `closure_overlap`）ときは赤い文。`ApiError.data.conflicts` から相手の日付・時刻・種類・名前を書く（例「10月24日（土） 18:00〜22:00の貸切「会社の宴会」と重なっています。日付か卓を変えてください。」）。
- 他の予約サイトと Google：閉じる知らせ（`notifyMedia`、既定はオン）は外せる。外すと新しい閉じる知らせを作らない（各サイトの管理画面で閉じる）。Google の案は owner・admin だけ、足す窓だけ。既定は入れる（貸切は外す）。卓を選んだときは作れない（店全体の休みになるため）。
- 保存：足す＝`POST /closures`、変える＝`PATCH /closures/:id`（expectedVersion）。予約は取り消さず、お客さまへは送らない。知らせ：「〇月〇日を閉じました。重なる予約 N件は取り消していません。1件ずつ連絡してください。」
- 失敗：重なり 409・版の競合 409（「ほかの人が先に変えました」）・権限 403 はそれぞれの文を窓の中に出す。
- 消す：`DELETE /closures/:id`（expectedVersion）。閉じる知らせを出していたら「他の予約サイトに『もう開けてよい』の知らせを出しました」。

## 予約台帳の帯
- 予約台帳（`v8/restaurant/reservations`）の今日の見方は選んだ日、ほかの見方は今日の `reservations/day` の `closures` を読み、休業・貸切なら琥珀の帯（「〇月〇日（曜）は臨時休業（終日・全卓）です。閉じた時間帯は LINE からの予約を受け付けません。入っている予約は取り消していません。」と［休業日・貸切を見る］）。

## 閲覧のみ
- 足す・変える・消す・［閉じた］・日を押すことは owner・admin・staff だけ（口と同じ）。閲覧のみには置かない。Google の案は owner・admin だけ。

## 知らせる相手
- 「もう開けてよい」の LINE の知らせと知らせる相手は、予約サイト・グルメ媒体（E-4 `aSmph`）の画面で店ごとに決める（`close-notification-settings`）。
