# 共通情報の一覧の動き（BEHAVIOR.md）

対象：`src/v8/common-vars/list.tsx`（現役V8一覧）。
板：一覧 `FM94M`・1152 `XIzkJ`・閲覧のみ `OxSw8`・止める窓 `Hhl9M`・削除の窓 `xxKtW`・状態 `RqO7O`。

## 入口
- `app/contents/vars/page.tsx`：`@/v8/common-vars/list` に固定。

## 受け付ける URL と指定（今と同じ）
- `?folder=<フォルダID>`：選んでいるフォルダ。未分類は `__ungrouped__`。押すと `router.replace` で書き換える。
- `?row=<共通情報ID>`：右から出る詳細パネルの今の行（`useDetailPanelUrl('row')`）。

## 読み込み（API）
- `api.commonVars.list(accountId)`：一覧。`meta.limited` のときは「最初の200件まで」の帯。
- `api.folders.list('common_var', accountId)`：フォルダと未分類の数。失敗してもフォルダの列にだけ小さく出し、一覧は止めない。
- アカウントが切り替わったら、遅れて返った前のアカウントの結果は映さない（`latestAccountRef`）。選択も外す。
- 失敗：403 は「見る権限がありません」、ほかは「読み込めませんでした」＋もう一度試す。取れていない数は「—」（0 と言わない）。

## 権限
- 役割はサーバ（`/api/staff/me`、`useStaffRole`）で確かめ、答えが来るまでは手元の `isOwnerOrAdmin()`。
- 編集権限がない人は閲覧のみ：帯（`OxSw8`）を数の帯の上に出し、作る・フォルダを追加・選ぶ箱・変更項目は隠す。行の「…」では差し込み名のコピーだけを使える。CSVは書き出す権限で判断。

## 数の帯
- 共通情報（下書き・止めたの数）／使っている所（使用数の合計。未取得は数えない）／空のまま使われている（「直す →」で空のままに絞る）／期限が近い（7日以内）。

## 絞り込み・並び
- 札（1つだけ選べる・もう一度押すと外れる）：空のまま・期限つき・使われていない・下書き・止めた。期限切れの札は、期限切れがあるとき（選んでいるとき）だけ出す。
- 探す：名前・差し込み名・中身。
- 並び（印だけのボタン）：使われている数が多い順（既定）・更新が新しい順・名前順。
- 表示件数：10・20・50件。

## 一覧の行
- 選ぶ箱／名前（編集へのリンク）／中身（空は「（空）」）／状態の札（使用中・M/dまで・下書き・止めた・期限切れ）／使っている所（1152 の板では列ごと隠す）／「…」。差し込み名 `{{var.<キー>}}` の全文コピーは「…」から使う。
- 行を押すと詳細パネル。本文は項目名と中身の段、下の帯の主操作は「編集する」（閲覧のみでも読み取りで開く）、止める／再開・削除は「…」。名前のその場の書き換えと変更操作は、閲覧のみでは灰色＋理由、本人未確認は通常のdisabled。前後の行も移動できる。更新日と次の予定は行の `title` とパネルに出す。
- 「…」と右クリックは同じ項目：コピー・編集・止める（止めているときは再開する）・削除する。閲覧のみはコピーだけ。

## 窓
- 止める（`Hhl9M`）：理由が必須。予約中の配信が差し込んでいれば「送られなくなります」の帯。決めた日の切り替え予約があれば注意。
- 削除（`xxKtW`）：開いてから使用先を読む。使われていれば「まだ消せません」→差し替えて消す（候補と影響を読む）か、消さずに止める。使われていなければ差し込みキーを打って削除。どれも理由が必須（版履歴に残す）。409 は読み直し。
- まとめて削除：20件まで。使用先を確かめ、使われているものが混ざっていたら止める。
- フォルダ：追加・名前変更・削除（中身は未分類に残る）。名前変更・削除はフォルダの行の「…」から（選んでいない行は乗せたときだけ出る）。1152 はフォルダの印のメニューから。

## CSVを書き出す
- 作成・もう一度書き出す・ダウンロードは、サーバーが本人確認を求めた時に既存の確認窓へ進み、その操作専用の確認票でやり直す。閲覧のみ・代理・権限不足の拒否は確認窓へ回さない。
- 確認の取消、アカウントやフォルダ・未分類の切替、画面離脱後に前の対象への依頼を再開しない。操作中の二重依頼を止める。
- 応答が分からない依頼を自動再送しない。履歴を読み直し、失敗理由を表示する。成功すれば前の失敗は消える。
- 状態の帯と新しい失敗の帯は重ねず、新しい失敗を優先する。過去の書き出しは履歴に残し、ダウンロードと再生成も認証付きの同じ経路で使う。
- 再生成は保存済みの書き出しの所属と絞り込みで判定し、現在の機能設定・担当範囲・フォルダを確かめる。新しい出力依頼として監査へ残す。

## 削除確認の入力と操作
- 窓の題は対象名を含む削除の問いを1行で示し、長い題は共通TruncatedTextで省略し全文のtitleと吹き出しを保つ。対象名は直下の項目にも全文を表示する。
- 使用先の確認が済み削除できる場合は、理由/差し込みキーが未入力でも削除操作を薄い赤で残し、押せない理由を操作の補足に出す。必要条件と削除の処理は変えない。
- 開いた直後に欄のエラーは出さず、操作した欄から離れた時に欄のそばへ示す。入力中の消し方は共通Fieldに従い、失敗しても入力を保つ。開き直しで未操作へ戻る。
