# 共通情報の一覧の動き（BEHAVIOR.md）

対象：`app/contents/vars/list-v8.tsx`（今の V8 一覧）。このファイルから写して `list.tsx` を一から書いた。
板：一覧 `FM94M`・1152 `XIzkJ`・閲覧のみ `OxSw8`・止める窓 `Hhl9M`・削除の窓 `xxKtW`・状態 `RqO7O`。

## 入口
- `app/contents/vars/page.tsx`：`theme === 'v8'` のときだけ `@/v8/common-vars/list` を出す。v7 側は触らない。

## 受け付ける URL と指定（今と同じ）
- `?folder=<フォルダID>`：選んでいるフォルダ。未分類は `__ungrouped__`。押すと `router.replace` で書き換える。
- `?row=<共通情報ID>`：右から出る詳細パネルの今の行（`useDetailPanelUrl('row')`）。

## 読み込み（API）
- `api.commonVars.list(accountId)`：一覧。`meta.limited` のときは「最初の200件まで」の帯。
- `api.folders.list('common_var', accountId)`：フォルダと未分類の数。失敗してもフォルダの列にだけ小さく出し、一覧は止めない。
- アカウントが切り替わったら、遅れて返った前のアカウントの結果は映さない（`latestAccountRef`）。選択も外す。
- 失敗：403 は「見る権限がありません」、ほかは「読み込めませんでした」＋もう一度試す。取れていない数は「—」（0 と言わない）。

## 権限
- 役割はサーバ（`/api/staff/me`、`useStaffRole`）で確かめ、答えが来るまでは手元の `isOwnerOrAdmin()`。
- owner・admin 以外は閲覧のみ：帯（`OxSw8`）を数の帯の上に出し、作る・フォルダを追加・選ぶ箱を押せない形にする。行の「…」は開けるが中は押せない（理由つき）。CSVで書き出す・差し込み名のコピーは使える。

## 数の帯
- 共通情報（下書き・止めたの数）／差し込んでいる所（使用数の合計。未取得は数えない）／空のまま使われている（「直す →」で空のままに絞る）／期限が近い（7日以内）。

## 絞り込み・並び
- 札（1つだけ選べる・もう一度押すと外れる）：空のまま・期限つき・使われていない・下書き・止めた。期限切れの札は、期限切れがあるとき（選んでいるとき）だけ出す。
- 探す：名前・差し込み名・中身。
- 並び（印だけのボタン）：使われている数が多い順（既定）・更新が新しい順・名前順。
- 表示件数：10・20・50件。

## 一覧の行
- 選ぶ箱／名前（編集へのリンク）＋差し込み名 `{{var.<キー>}}`＋コピーの印／中身（空は「（空）」）／状態の札（使用中・M/dまで・下書き・止めた・期限切れ）／使っている所（1152 の板では列ごと隠す）／「…」。
- 行を押すと詳細パネル（名前のその場の書き換え・止める／再開・削除・前後の行）。更新日と次の予定は行の `title` とパネルに出す。
- 「…」と右クリックは同じ項目：編集・止める（止めているときは再開する）・削除する。

## 窓
- 止める（`Hhl9M`）：理由が必須。予約中の配信が差し込んでいれば「送られなくなります」の帯。決めた日の切り替え予約があれば注意。
- 削除（`xxKtW`）：開いてから使用先を読む。使われていれば「まだ消せません」→差し替えて消す（候補と影響を読む）か、消さずに止める。使われていなければ差し込みキーを打って削除。どれも理由が必須（版履歴に残す）。409 は読み直し。
- まとめて削除：20件まで。使用先を確かめ、使われているものが混ざっていたら止める。
- フォルダ：追加・名前変更・削除（中身は未分類に残る）。名前変更・削除はフォルダの行の「…」から（選んでいない行は乗せたときだけ出る）。1152 はフォルダの印のメニューから。
