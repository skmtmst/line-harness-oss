# 権限なし（★V8 O5tUeE）

部品：`no-permission.tsx`（板全体の形）。画面の一覧の口が 403 を返したとき、その画面ごとこれに替える。
今ある一覧の中に置く版（`app/no-permission/no-permission-v8.tsx`・共通情報の一覧が使う）を写して、題・説明・板の真ん中の札にした。

## 使っている画面
- シナリオ配信の一覧（`src/v8/scenarios/list.tsx`）：`GET /api/scenarios` が 403 のとき。500 などは今までどおり「読み込めませんでした」

## 出すもの
- 題（機能名）・「この機能は、あなたの役割では開けません。」
- 札：鍵・「〇〇を開く権限がありません」・いまの役割（`GET /api/staff/me` の役割をオーナー／管理者／スタッフ／閲覧のみで出す）
- 要る役割・頼む管理者の名前は、口が返さないので出さない（分からない役割を断定しない）
- 役割でできることを見る（ログインユーザー）・ダッシュボードへ戻る

## 絵と違うところ
- 絵の役割「受付」「運用」は今の役割の名前に無い。管理者名（「管理者：〇〇」）は口が無いので出ない
