# シナリオ配信の編集の動き（BEHAVIOR.md）

対象：`detail.tsx`（★V8 稼働中 `PMLkX`・始めた直後 `nMSiE`・停止中 `ARuZ4`・競合 `kz2B6`、窓：止める確認 `OPGU2`・複製 `Al4Ek`・開始の確認 `F1LK4e`）。
今までの V8 `app/scenarios/detail/detail-v8.tsx` から動きを写し、見た目だけを絵の寸法（`--tpl-sd-*`）で組み直した。
`start-checklist.ts`・`scenario-reach-display.ts`・`scenario-step-audience.ts`・`scenario-simulation-refresh.ts` は `app/scenarios` からの写し（src/v8 は @/app を読めない）。

## 入口
- `app/scenarios/detail/page.tsx` が `theme === 'v8'` のときだけこの画面を出す。v7 は今までどおり `scenario-detail-client.tsx`。
- 古い V8 の `app/scenarios/detail/detail-v8.tsx` は消していない（契約試験が読んでいるため。切り替えの日に v7 と一緒に片づける）。

## 受け付ける URL と指定
- `?id=<シナリオ>`（無ければ入口が「見るシナリオが指定されていません」）。
- `?started=1`：始めた直後の知らせ（`nMSiE`）を出す。今までと同じ名前・同じ意味。

## 読み込み（API）— 今までと同じ
- シナリオ：`scenarioReferenceData.scenario`（通つき）。数：`scenarioReferenceData.stats`。テンプレート・タグ：`scenarioReferenceData.templates/tags`。
- 試算 `api.scenarios.simulate`・運用記録 `api.scenarios.runs`・開始のきっかけ `api.scenarios.triggers.list`・届く日時の例 `api.scenarios.preview`・アクション件数 `api.scenarios.actions.list`・フォルダ `api.folders.list('scenario')`。
- 別のタブから戻ったら更新日時だけ取り直し、ずれていたら競合の帯を出す（画面は書き換えない）。

## 画面の並び（絵どおり）
- 板の頭：戻る「← シナリオ配信へ」・題・状態の札・鉛筆（名前・説明・置き場・同時購読を変える窓）・説明の1行。右に「配信結果を見る」「まとめて下見」「まとめてテストを送る」「…」（このシナリオを複製／このシナリオを削除）。
- 左：①保存（保存済みの日時 or 未保存の変更あり）②開始のきっかけ（設定を変える）③配信（一時停止する／配信を再開する）→ 数の帯（購読中・読み終えた・始まる見込み・離脱が多い所）→ 最後の1通の後（変える）→ メッセージの行（上へ・下へ・…）と「＋ ここに挿入」→ 通ごとの数 → 足すボタン3つ。
- 右：選んだ通（N通目）の見え方。共通のスマホ（`LinePreview`）を使い、部品が持つ題「LINEでの見え方」はこの欄の題が兼ねるので隠す。
- 下の帯（追従・常に画面の下）：左端「このシナリオを削除する」、中央「キャンセル・複製する・保存する」（競合中は「比べてから保存」）。

## 今までと変えたところ
- 「同時購読」の切り替えは説明の行のリンクから、鉛筆の窓のチェックへ移した（説明の行は絵どおり1つの文）。保存は下の「保存する」。
- 「保存する」は変更が無くても押せる（絵は常に押せる緑）。保存が 409（ほかの人が先に保存）なら、入力を残して競合の帯（`kz2B6`）を出し、ボタンは「比べてから保存」になる。今までは 409 も「保存に失敗しました」だった。
- ③の箱のボタンは「止める」→「一時停止する」、止める確認の題は「配信を止めますか」、実行は「一時停止する」（`OPGU2`）。
- 複製の窓（`Al4Ek`）：新しい名前・引き継ぐもの・引き継がないもの・停止中で作られる案内。操作は真ん中（共通の窓の右寄せの段は使わない）。
- 「まとめてテストを送る」を板の頭に足した（今までは通ごとの「…」のテストだけ）。全通のテスト送信の窓（`TestSendDialog`、stepId なし）を開く。
- 右のスマホに選んだ通の中身が出るようにした（今までは常に「配る内容がまだありません」の空の箱だった）。
- 行の時刻：時刻指定は1通目だけ「購読開始から0日後 10:00」、2通目からは「1日後 20:00」。札は「テキスト・カルーセル・質問・テンプレート」。テンプレートを使う通の題は「本文（テンプレート「名前」）」。
- 通ごとの数：配信対象は「購読中の全員／タグ「名前」／詳細条件 N件」、到達は「到達 N人・P%」、下書きの通は棒の代わりに「下書き」の札と「—」、到達タグがあれば「到達タグ：名前」、無ければ「配信後：続ける／配信後に止める」。

## 閲覧のみ（staff・viewer）
- 役割は `/api/staff/me`。閲覧のみの帯を出す。
- 変える操作のボタンは置かない（押せない形でも出さない）：まとめてテストを送る・…（複製・削除）・鉛筆・設定を変える・一時停止する／配信を再開する・変える・＋ ここに挿入（行の間は同じ高さで空ける）・上へ・下へ・行の…・足すボタン3つ・削除・複製する・保存する。
- 見る操作（配信結果を見る・まとめて下見・行を押して右のスマホで見る・キャンセル）は残す。

## 絵にあって置いていないもの
- 止める確認（`OPGU2`）の「止める理由（任意）」：理由を受け取る口（保存先）が API に無い。口ができたら足す。
