# 予約台帳 予約の詳細の動き（BEHAVIOR.md）

対象：`detail-dialog.tsx`（板 AjZhH「予約台帳 予約の詳細 V8」・V8-B）。台帳の本体は `../restaurant/reservations/`。

## 開き方
- 今日（時間×卓）の**予約の箱**を押す。押さえの箱は今までどおり押さえの窓（解除）を開く。
- 右の「次の予約」の「詳細を見る」。「卓を変える」は今までどおり変更の窓を直接開く。

## 中身（絵のとおり）
- 題：「{お客さま}さん・{人数}名」。右上の×で閉じる。
- 灰の箱：
  - 「10/2（金）19:00〜21:00 ・ T4（4人卓）」：卓は座席・卓管理の記号と最大人数。卓が無ければ「未配席」。
  - 「秋の鹿肉コース 8,800円 ・ Hot Pepper から」：値段はメニューから。コースが無ければ「席のみ」。
  - 「アレルギー：{内容}」（無ければ「なし」）。赤字。
  - 「これまでの来店 3回・前回 8/14」：`customerHistory(store, 電話 or LINE UID)`（今ある口・来店済みだけを数える）。連絡先が無ければ口を呼ばずに「数えられません」。読めなければその旨。
  - 取消・無断の予約は「取り消した予約です」などを足す。
- 下：閉じる・取り消す・変更する（主・鉛筆の印）。取消・無断の予約は 取り消す・変更する の代わりに「予約を有効に戻す」。

## 操作（今の口だけを使う。新しい口は作っていない）
- 取り消す：詳細を閉じ、確かめの窓（「この予約を取り消しますか？」）を通してから `updateReservation(id, { status: 'cancelled' })`。
- 変更する：詳細を閉じ、今の変更の窓（`EditReservationDialog`）を開く。保存は `updateReservation`。
- 予約を有効に戻す：`updateReservation(id, { status: 'confirmed' })`。

## 閲覧のみ
- 予約の口は owner・admin・staff に開いている。それ以外（閲覧のみ）には 取り消す・変更する を置かない（閉じるだけ）。
- 同じ判定で、台帳の「卓を変える」「枠を押さえる」「電話の予約を入れる」「＋ 予約を入れる」も置かない。役割が読めるまでは出す（最後の守りは口の 403）。

## 今と変わるところ
- 予約の箱・「詳細を見る」は、変更の窓ではなく詳細の窓を開く（変更は詳細の「変更する」から）。
