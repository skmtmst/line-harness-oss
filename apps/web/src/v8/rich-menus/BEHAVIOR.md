# リッチメニュー一覧の動き（BEHAVIOR.md）

対象：`list.tsx`（V8一覧、板 `rZEGN`・1152 `Y9ASp`・閲覧のみ `ZoKow`・消せない理由 `yOyCg`）。
型（ListPage）と共通部品で描く現役の一覧。ファイルの案内は [README](README.md)。

## 入口
- `app/rich-menus/page.tsx`：`list.tsx` を直接表示する。管理画面はV8に固定。

## 受け付ける URL と指定
- 検索・フォルダ・絞り込み・並び・件数・ページはURLへ残す。`showExternal=true`はLINE上のメニューの窓を開き、窓の開閉で検索とページを変えない。

## 読み込み（API）
- 一覧：`richMenuGroups.listPage(accountId, { page, limit, query, folderId, filter, sort })`。件数・公開中・出し分け・フォルダごとの数は返事の `facets`。
- 集計：`richMenuGroups.tapStats`（取れなくても一覧は出す。数の帯と回数の列は「—」）。
- タグ名：`tags.list`（「タグ『◯◯』」を出すため。取れなければ条件の説明文）。
- フォルダ：`folders.list('rich_menu')`。
- LINE上の外部状態：`richMenuGroups.external`（「LINE上にあるメニュー」を開いてから読む）。
- 役割：`/api/staff/me`（`useStaffRole`）。変更権限がなければ作る・変える・消す操作を隠し、数の帯の上に閲覧のみの帯。
- アカウントを切り替えたら、開いている窓・読み込み結果を捨てて読み直す。

## 並び・絞り込み
- 札（公開中・予約・下書き・出し分け）は1つだけ選べる。もう一度押すと外れる。
- 並び：出す順番（既定）／今月押された順／更新が新しい順／名前順。件数の左の印だけの箱で選ぶ（絵に無いが機能は残す）。
- 件数：10・20・50件。
- 出す順番のつまみ（ドラッグ・上下キー）は「出す順番」の並びで絞り込みが無いときだけ。全件が見えていないときは全件を取り直してから計算し、`reorderPriorities` で保存。失敗したら元に戻す。

## 一覧の行
- 順番（つまみ＋番号）／見本（画像が無ければ面の区切り）／名前（編集へのリンク）と「大きさ・面・切替タブ・ボタン「…」・更新日」／誰に出すか（タグ・すべての友だち・まだ決めていない＋人数・既定・「10/5 から既定」）／状態の札（公開中・「10/5 公開」・下書き）／今月押された（月の集計 → 期間の集計 → 「—」。0 は「0回」）／「…」。
- 「…」：編集・表示先を変える（公開中）・切替のつながりを見る・複製する・取り下げ・削除する。
- 行を押すと編集へ。

## 数の帯
- 公開中（下書きの数）・今月押された・いちばん押された（ボタンの名前とメニュー・回数）・出し分け。

## 窓
- 削除：開いてから消したときの影響（`deleteImpact`）を読む。読めないときは消させない。409 は新しい影響で描き直す。
- 消せない理由があるとき（`yOyCg`）：「まだ消せません」の窓。理由は短く1行ずつ、外す操作を右に（既定→ほかのメニューを既定に、登録中・LINE上に残る→LINEから取り下げる（1行にまとめる）、切替先→切替を外す）。下に「閉じる」と「LINEから取り下げる」。
- 複製（下書きとして）・LINE上のメニューの取り込み・取り込み完了・フォルダを追加・表示先を変える（ApplyToTagModal）。

## 切替のつながり（connections.tsx・絵 wxIQ7）
今の画面（app/rich-menus/connections/page.tsx）と同じ読み込み（`api.richMenuGroups.get`・古い応答を捨てる・404 と失敗を分ける・アカウント違いは見せない）と、
調べ方（connection-analysis：保存済みのページと切替ボタンだけから、戻れない・届かない・切替先なしを見る）。
- 受け付ける URL：`/rich-menus/connections?id=<メニュー>`
- 図：入口のメニュー（このメニュー・タブA）と、ほかのメニューへの行き来（「タブB ⇄ タブA」、戻りが無ければ「→ 戻りなし」）
- 見張り：戻るタブが無いメニューごとに帯と「〇〇を開いて直す」（ボタンの動きの手順へ）。切替先が無いタブ・どこからも来られないメニューは、あるときだけ行を出す。切替先が下書き（公開中なのに LINE に無いページ）・「誰に出すか」の違い（束ごとに決めるので起きない＝なし）
- 右の列：編集する・切替のつながり・「…」（メニューを開く・一覧へ）、いまの状態（状態・出す相手・出る人・今月押された。取れない数は「—」）
- 下の帯：メニュー一覧へ・ボタンの動きを直す（今の「リッチメニューを保存する」は保存せず編集へ移るだけだったので、言葉を動きに合わせた）

## LINE上のメニュー
- `showExternal=true`で開く。共通Dialogの本文だけをスクロールし、一覧そのものを全面表示で置き換えない。右上の×・Esc・本文の「リッチメニュー」は同じURLの閉鎖処理を通る。検索・ページは残す。
- 取り込み・削除の確認を子の窓で開く。Escは一番上の窓だけを閉じ、取り込み中・削除中は親も閉じない。閉じた後の焦点は共通部品で戻す。
- 読取失敗は0件と区別し、窓内で理由と再読込を出す。LINEの認証確認不可・LINE側の混雑・管理画面での閲覧権限不足は安全な固定文で分け、外部の本文や秘密値は表示しない。失敗時に前の候補を現在の物として見せない。
- Workerの一覧読取の外向HTTP500とアクセス検査は維持し、LINE側の401/429だけ既存の機械符号を保つ。取り込み時の詳細・画像の失敗分類は今回の対象外。
