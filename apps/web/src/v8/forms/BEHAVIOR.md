# 回答フォーム一覧の動き（BEHAVIOR.md）

対象：`app/form-submissions/list-v8.tsx`（今までの V8 一覧）。このファイルの動きを写して `list.tsx` を一から書いた。見た目は型（ListPage）と部品で組み直した。板は 一覧 `I3L41O`・1152 `GrnO4`・閲覧のみ `JV2oR`・アーカイブ・削除の窓 `GVizd`。

## 入口
- `app/form-submissions/page.tsx`：`@/v8/forms/list` を出す（このルートは V8 だけ）。今までの `list-v8.tsx` と、それを読む動きの試験は切り替えの日まで残す。

## 受け付ける URL と指定（今までと同じ名前・同じ意味）
- `?q=`：探す言葉（フォーム名・質問文）。
- `?filter=`：`published`（公開中）・`draft`（下書き）・`stored`（情報欄に保存）・`pending`（後処理の未完）。無ければすべて。
- `?sort=`：`answers`（回答が多い順）・`updated`（更新が新しい順）・`name`（名前順）。無ければ最新の回答順。
- `?limit=`：10・20・50（無い・ほかの値は 20）。
- `?page=`：1から。総ページ数を超えたら最後のページへ直す。
- フォルダ・管理者確認・開いている行は URL に残さない（画面の中だけ）。

## 読み込み（API）
- `GET /api/forms?account_id&folder_id&with_list_summary=1&page&limit&filter&sort&q`：1ページ分と総数（`total`）・フォルダ範囲の総数（`all_total`）。絞り込み・並び・ページ切りは Worker（規則の正本は @line-crm/shared）。
- `api.folders.list('form', accountId)`：フォルダと件数（`itemCount`）・未分類の件数（`unfiledCount`）。フォームと別々に回収し、箱だけ失敗したら箱の場所に「フォルダを読み込めませんでした。」と「もう一度」。
- `api.listStats.get(accountId)`：数の帯 4枚（公開中・今月の回答・答え終えた割合・後処理の未完）。取れなければ「—」（0 とは言わない）。
- 管理者確認（担当未割り当て）：`GET /api/forms/unassigned`。全件が来るので画面で絞り込み・並び・ページ切り。403/404 は「確認できる未割り当てフォームはありません」。
- 検索語は 300ms 遅らせてから読む。古い返事は番号で捨てる。アカウントが替わったらフォルダ・窓・選択・帯を消してから読み直す。

## 権限
- フォルダの追加・名前・色・並び・削除はオーナーと管理者だけ。役割はサーバ（`/api/staff/me`、`useStaffRole`）で決め、答えが来るまでは手元の値（`isOwnerOrAdmin`）。
- 変えられない人には、見出しの下に「閲覧のみで見ています。変える操作は管理者に頼んでください。」の帯（`JV2oR`）。「フォルダを追加」は出さない（押せない飾りの口を置かない決まり：issue-709 の契約試験）。フォームの作成・編集はサーバが決める（今までどおり押せる）。

## 一覧の行
- 名前（押すと右の詳細パネル）＋後処理の未完の札／説明・Nブロック／保存先（友だち情報 N・タグ N）／状態（公開中・下書き）／回答（件数＝集まった回答へのリンク、今月・完了%）／URL をコピー／「…」。
- 1152 の板では保存先の列を出さない（絵 `GrnO4`）。
- 「…」：編集・名前を変更・集まった回答・複製・受付を止める（公開中だけ）・フォルダへ移す・アーカイブ・削除。右クリックでも同じ項目。読み上げ名は「「〇〇」のその他の操作」（操作の一覧は title。読み上げ名に「削除」などの項目名を入れない）。
- 数の帯の「未完を見る」は `?filter=pending` へ（ほかの指定は残す）。選んでいる間だけ「後処理未完」の札が出て、外すとすべてに戻る。

## 窓・パネル
- アーカイブ・削除（`GVizd`）：開くと影響（回答数・利用先・版・公開URL）を読む。「アーカイブする（おすすめ）」「削除する」の説明と利用先の注意。削除は未公開・回答なし・利用先なしのときだけ押せる。危ないボタンは左端、キャンセル・アーカイブは真ん中。応答が失われたら読み直し、消えていれば成功として扱う。
- 受付を止める：影響口で版を読んでから `PUT /api/forms/:id`（`isActive:false`・`expectedContentRevision`）。409 は「ほかの人が先に保存しました」。
- 名前を変更：1件取得で版を読み、同じ更新口へ。詳細パネルの名前のその場の書き換えも同じ。
- 複製：名前を決めて `api.forms.duplicate`。できたら編集画面へ。
- フォルダへ移す：右のパネルで選ぶ（`PUT /api/forms/:id` の `folderId`。422 は「そのフォルダはありません」）。
- フォルダ：追加・名前と色（右のパネル）・並び替え（押した瞬間に変え、5秒は元に戻せる）・削除（入っている件数を数えてから確認）。
- 作る：`api.forms.createDraft` で下書きを作って編集画面（`?id=…&tab=basic`）へ。

## 読み込みの状態
- 読込中（骨の行）・アカウント未選択・読み込めない（403 は再試行なし、そのほかは「もう一度読み込む」）・まだ無い（作るボタン）・条件に合うものが無い（条件を外す）を分ける。
