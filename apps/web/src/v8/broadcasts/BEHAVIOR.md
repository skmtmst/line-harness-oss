# 一斉配信一覧の動き（BEHAVIOR.md）

対象：`app/broadcasts/list-v8.tsx`（今までの V8 一覧）。このファイルの動きを写して `list.tsx` を一から書いた。見た目は型（ListPage）と共通部品（KpiBand・KpiCard・FolderPanel・FilterChip・DataTable）で組み直した。

## 入口
- `app/broadcasts/page.tsx`：`theme === 'v8'` のときだけ `@/v8/broadcasts/list` を出す。v7 の一覧（BroadcastsPageContent）と v7 の試験、古い `list-v8.tsx` は触らない。

## 受け付ける URL と指定
- 今までどおり URL の指定は読まない（絞り込み・フォルダ・件数・並びは画面の中だけ）。
- 行き先：詳細 `/broadcasts/detail?id=<ID>`、編集を続ける `/broadcasts/new?draft=<ID>`、複製 `/broadcasts/new?duplicateFrom=<ID>`（今までと同じ）。

## 読み込み（API）
- `api.broadcasts.list({ accountId, limit, cursor, displayStatus, folderId, sort, from, to })`：一覧・数の帯（`kpis`）・札の件数（`statusCounts`）・総数。条件を変えたら1ページ目へ戻し、この口だけ取り直す。
- `api.tags.list`・`api.scenarios.list`：宛先の名前解決だけ。アカウントが変わったときだけ。失敗しても一覧は止めない。
- `api.dashboard.overview`：今月の送信枠（quotaLimit・quotaUsed）。
- `api.broadcasts.savedViews.list / create`：保存した検索。保存の形（filters・sortKey `scheduled`・pageSize 20）は今までと同じ。
- `api.broadcasts.getInsight(id)`：一覧に集計が同梱されていない送信済みだけ1回ずつ。
- `api.folders.list('broadcast')`・`swapOrder`・`delete`：フォルダ。`api.broadcasts.update(id, { folderId, expectedVersion })`：フォルダへ移す（押した瞬間に移した形を見せ、失敗したら戻して「もう一度」）。
- `api.broadcasts.delete(id)`：削除（確認の窓のあと）。

## 権限
- 役割はサーバ（`/api/staff/me`、`useStaffRole`）。読めるまでは今までどおり出す（最後の守りはサーバの 403）。
- 変えられるのはオーナー・管理者と、配信の編集キー（`broadcast.definition.edit`）を持つ運用担当。手元の役割（`lh_staff_role`）は古いことがあるので見ない。
- 変えられない人：数の帯の上に「閲覧のみで見ています。…」の帯（`NtCE3`）。作る・この条件を保存する・フォルダを追加・行の「…」の変える項目・詳細パネルの変えるボタンは押せない形で残す（理由は title）。

## 数の帯
- 1440：予約中（件・今日は未取得）／今月の送信枠（通 残り・「N 通のうち M 通を使用」）／今月の配信（件・N人に届いた）／平均の開封率（%・過去28日）。
- 1152（`jjFNi`）：送信枠の代わりに 下書き（件・編集の途中）。読めるまで「—」。

## 道具の段・絞り込み
- 1440：探す（タイトル・内容、手元で絞る）・配信日（開始〜終了の小窓、外を押す・Esc で閉じる）・この条件を保存する … 保存した検索（メニュー：保存した検索を選ぶ・外す・＋この条件を保存する）。2段目：状態の札（すべて・予約中・下書き・承認待ち・送信済み・エラー、件数つき）… 件数（10・20・50件）・並び（新しい順⇔古い順を押して入れ替え）。
- 1152：1段目の先頭に「配信を作る」とフォルダ選び、札は「状態：すべて 24」の選ぶ欄。「この条件を保存する」は保存した検索のメニューの中。
- フォルダ：左の列（すべて・各フォルダ・未分類、件数つき）。各フォルダの「…」で名前の変更・並び替え・削除（中身は未分類に残る）。

## 作る
- 「配信を作る ▾」（フォルダの列のいちばん上、1152 は道具の段の左端）→ メニュー「新しく作る」「テンプレートから作る」。どちらも今までと同じく一覧の上にその場の作る欄（`BroadcastForm`）を開く。

## 一覧の行
- タイトル（詳細へのリンク）＋種類／状態の札（点つき・5色）／配信条件（1152 では出さない）／配信日時（予約は2行目に「予約」、下書きで日時が無いと「未設定」）／結果（送信済みだけ「N人に届いた」＋開封・クリック）／「…」。
- 行を押す・Enter で右の詳細パネル（前後へ・開く・編集を続ける・複製する・削除する）。右クリックは「…」と同じ項目（「…」でも必ず開ける）。
- 「…」：編集を続ける（下書き・予約）・複製・フォルダへ移す（同じメニューの2段目で行き先）・削除する。

## 読み込みの状態
- 読込中（骨格の行）・見る権限が無い・読み込めない（もう一度試す）・まだ無い（＋配信を作る）・条件に合うものが無い（条件を外す）を分ける。
- 件数：1ページなら「N件」、複数なら「N件中 a〜b件」とページ送り。

## 絵と違うところ（データの口が無い）
- 下書きの2行目「◯月◯日 更新」：一覧の口に更新日時が無いので出さない。
- 数の帯の各マスの「…」：絵に操作の中身が無いので置いていない。
