## 作る（new.tsx）
- 口：`api.folders.list('common_var')`・`api.commonVars.create`（`status: 'draft' | 'active'`）。保存できたら一覧へ。
- 入力：共通情報名（200字）・フォルダ・差し込み名（英小文字はじまり・32字・名前から自動で候補・あとから変えられない）・種別8つ（作ったあと変えられない）・中身（種別ごとの欄）・使える期間（始まり・終わり・期間の外では 止める／代替値）・社内メモ（1000字）。
- 確かめ：名前・差し込み名は欄を離れたときに確かめる。値の形・期間の前後・代替値・秘密の形（鍵・トークン）は保存の前に止める。パスワードらしい文は確認の窓（直す／内容を確認して登録する）。409 は「その差し込み名は既に使われています」。
- アカウントが切り替わったら入力をやり直してもらう。未保存で離れるときは確かめる。
- **変えたところ**：文字数の「0/200」の表示を欄の下から外し、欄の title に移した（絵に無い・maxLength はそのまま）。差し込み名のコピーは文字だけのボタン（コピーできないときは文で知らせる）。
- 閲覧のみ：下書きを保存・保存して公開を置かない（隠す）。閲覧のみの帯を出す。

## 編集（edit.tsx）
- 口：`api.commonVars.detail`・`schedules`・`api.folders.list`・`deleteImpact`（値が同じとき）／`impactPreview`（値を変えたとき、400ms 待って）・`update`（PATCH、`expectedVersion`・`changeReason` 必須・`impactProof`）・`addSchedule`・`deleteSchedule`・`setStatus`・`delete`。
- 影響の行：3件まで出し「ほか N か所を見る」で開く。前（赤）・後（緑）。CSV で書き出す。保存を止める問題があれば下の帯の左に理由。
- 競合（409）：頭の下に琥珀の帯（誰がいつ保存したか・違いを比べる・最新を読み込んで続ける）。保存ボタンは「比べてから保存」になり、比べる窓から上書きできる。**409 のとき本文の上の赤い帯は出さない**（帯が知らせる）。428 は文だけ。
- 右の列：名前とフォルダ・使える期間・社内メモ（ひとまとまり）→ 決めた日に変える → これまでの変更（止める・再開する・公開するの3つを並べ、いまの状態で押せるものだけ押せる）→ 差し込んだときの見え方。競合中は 決めた日 → 見え方 → 名前など → 履歴 の順（消さない）。
- 1152（幅 1280 以下）：右の列は 幅280・余白16。上に「LINEでの見え方を見る」（窓で開く）、決めた日 → 名前など → 履歴。
- 決めた日に変える：予定が1件のときは行に×を置かず「予定を消す」で消す（2件以上は行の×と「予定をすべて消す」）。予定を足す窓は共通の Dialog。
- 下の帯：削除（左）・キャンセル・止める（使用中のとき）・N か所に反映して保存。
- 閲覧のみ：保存・止める・削除・予定の操作・状態の操作を置かない（隠す）。欄は読み取りだけ。閲覧のみの帯を出す。
