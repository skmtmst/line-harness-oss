# 案件を作るの動き（BEHAVIOR.md）

対象：今までの画面 `app/affiliate-offers/new-offer-v8.tsx`。ここから動きを写して `create.tsx` を一から書いた。見た目は作る型（CreatePage）で組んだ。
板：案件を作る `Td4TN`（機能追加 F-23）。

## 入口と受け付ける URL
- `app/affiliate-offers/new/page.tsx` が `create.tsx` を出す。写し元は切り替えの日まで残す。
- 受け付ける指定は無い（今と同じ）。

## 呼ぶ API（今と同じ）
- 読む：タグ（`api.tags.list({ accountId })`）・シナリオ（`api.scenarios.list({ accountId })`）。上のバーで選んだアカウントで絞る。
  失敗したら「〇〇の候補を読み込めませんでした」＋「もう一度読み込む」。取り直すまで保存しない。
- 書く：`api.affiliateOffers.create`（操作 UUID つき・`isActive` は押したボタンで決める）。2回目からは `update`。返事の公開状態が違えば直す。

## 動き
- 保存して公開：公開で作って一覧（`/conversions?tab=offers&highlight=<id>`）へ。
- 保存して続けて作る：下書きで作り、入力を空にして「下書きに保存しました。続けて作れます。」。
- 断る条件（今と同じ文）：案件名が空・アカウント未選択・候補の読み込み失敗・タグ／シナリオをオンにして選んでいない・報酬が両方空・報酬が負や小数。
- アカウントを替えたら、作った下書き・選んだタグとシナリオを持ち越さない（新しい操作 UUID）。
- 未保存で離れると確認（`useUnsavedGuard`）。
- 閲覧のみ（owner・admin 以外）：保存の2つのボタンを置かず、帯を出す。入力は読むだけ（2026-10-06 オーナー決定）。

## 絵と違うところ・口が無いところ
- 「何を成果として数えるか」の成果地点：案件に成果地点をつなぐ口が無い（F-23）。押せない欄「まだ選べません」と、題の「？」に説明。
- 説明は絵どおり1行の欄（今までは3行の欄）。
- 「現金とマイルは併用できます…」はマイルの題の「？」へ。
- 「誘導するLINEアカウント」は右の列の「気をつけること」の2行目へ（絵の左の列には無い）。
