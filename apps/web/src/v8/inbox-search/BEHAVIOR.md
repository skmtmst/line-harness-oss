# 受信箱：会話の中を探す（V8.pen M0393 段13・枠 v7GV2・会話 W5pVg）

2026-10-07 オーナー採用。入口は `app/chats/page.tsx`（受信箱）。V8 の見た目のときだけ出す（v7 の本番には出さない）。

## 開き方・閉じ方
- 会話の頭の🔍（顧客情報の出し入れの左）を押す、または会話を開いている間に ⌘F / Ctrl+F。ブラウザのページ内検索の代わりに帯を出し、探す欄へ入る
- Esc（探す欄の中）・帯の×・🔍をもう一度押す → 閉じる。枠も消える
- 別の会話へ替えたら閉じる（前の相手の当たりを残さない）

## 探す
- 打って 300ms 止まったら、会話の検索の口（API-9 `GET /api/chats/:friendId/messages/search`、`api.chats.searchMessages`）を呼ぶ。検索語は 200 字まで
- 当たりは古い順に 1〜n 番。最初は**いちばん新しい当たり（n件中 n件目）**
- ↑（前へ）・Enter → 古い方、↓（次へ）・Shift+Enter → 新しい方。端で止まり、ボタンは押せなくなる（回らない）
- 当たりは 100 件ずつ読む。最初に先頭の塊と、当たりが 100 件を超えるときは新しい方の塊も読む。読んでいない番号へ移るときは、その番号を含む塊を読む
- 帯の文字：打っている間「探しています…」、0 件「見つかりません」、失敗「探せませんでした」、昔の吹き出しを読み足している間「読み込んでいます…」。読み上げは role=status
- 検索語を変えたら最初から（offset は検索語ごとに戻す：API の決まり）。古い応答は捨てる

## 当たりへ移る
- いま見ている当たりの吹き出しは太い枠（$warning・2px）、ほかの当たりは薄い枠（$warning-soft）。枠は影で描き、吹き出しの大きさを変えない（窓分けの高さが動かない）
- ほかの当たりは、読んだ当たりの ID に加え、読み込み済みの文字の吹き出しをサーバーと同じそろえ方（NFKC＋小文字）で照らして決める。取り消した吹き出しは当たりにしない
- 当たりが読み込み済みなら、その吹き出しを欄の真ん中へ出す（窓分けの外なら覚えた高さで送ってから）
- 読み込んでいない昔の当たりは、いま読んでいる最古の1件から会話詳細の口（`api.chats.get` の beforeAt/beforeId・1回 1,000 件＝口の上限・最大 20 回）で当たりまで読み足してから移る
  - 読み足した分は新しい方から途切れずにつながる。定期の取り直し（5秒）・下に付ける・「前のメッセージ」・窓分けの目印はそのまま動く
  - 位置の口（`api.chats.messagesAt` の around）は使わない。返す形に送った人・引用・シナリオ名が無く、読むと新しい方との間が空いた並びになって、定期の取り直しが間を黙って詰めてしまうため
  - 読み足せなかったら「当たったメッセージまで読み込めませんでした。もう一度お試しください。」

## 読み上げの全件数
- 吹き出しの `aria-setsize` は会話詳細の口の `total`（API-9：テスト送信を除いた全件数）。`aria-posinset` は（全件数 − 読み込んだ数）＋ 何番目 ＋ 1
- すべて読み込んだら読み込んだ数。`total` が無い古い応答で前がまだある間だけ -1

## 受け付ける URL と指定
- 受信箱の今の指定（`?friend=` など）のまま。探す帯の状態は URL にも保存先にも残さない
