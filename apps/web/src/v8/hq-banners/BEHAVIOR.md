# 統括のバナー生成の動き（BEHAVIOR.md）

対象：`list.tsx`（一覧 `B9ZAr`・画像ライブラリ `W5Wxr`）と `project.tsx`（プロジェクトの中 `iMnph`・生成中 `p03ImY`・上限 `zOpMG`）。
写し元：`app/hq/banners/page.tsx`・`app/hq/banners/project/page.tsx`・`components/hq/banners/*`（v7。消さない）。

## 入口
- `app/hq/banners/page.tsx`・`app/hq/banners/project/page.tsx`：`theme === 'v8'` のときだけこの画面を出す。v7 側は今のまま。

## 受け付ける URL と指定（v7 と同じ）
- `/hq/banners`：プロジェクト一覧。`?tab=library` で画像ライブラリ。タブは `router.replace` で切り替え、履歴を積まない。
- `/hq/banners/project?id=<プロジェクト>`：プロジェクトの中。`&from=<画像>` で「同じ設定でもう一度生成」の条件をパネルへ入れる。
- id が無い・見つからない・権限が無い・読めないときは、v7 と同じ案内（TargetMissing・ListState）。

## 読み込み（API は v7 と同じ）
- 一覧：`hqBanners.presets`（用途と利用量）・`hqBanners.stats`（数）・`lineAccounts.list`（渡す先）。形の違う応答は置かず「—」。
- プロジェクト一覧：`projects.list({archived})` と `images.list({limit:100})`（カードの上の3枚）。
- 画像ライブラリ：`images.list({favorite, delivered, shape, q, withCounts, limit:12, before})`。数（すべて・お気に入り・渡し済み・未使用）はサーバの `counts`。
  - **変えた所**：v7 は「さらに N 枚を表示」で足していく形だった。V8 は絵どおり 12 枚ずつのページ（「1–12 件 / 23 件」「次の 12 件」「前の 12 件」）。続きは v7 と同じ `before`（日時のカーソル）で読む。
- プロジェクトの中：`projects.get(id)`・`presets`。生成は `createGeneration` → `generations.run` を1枚ずつ繰り返す（v7 と同じ。戻ったら続きから動く・止めるは `generations.cancel`）。

## 操作（オーナー・管理者だけ。閲覧のみには置かない）
- 一覧：プロジェクトを作る（窓 `W7Z57`。名前は必須・100文字まで。作ったらそのプロジェクトを開く）、カードの星（お気に入り）。
- ライブラリ：画像を取り込む（窓 `AnwtH`。入れるプロジェクトを選ぶ・PNG/JPEG/WebP・10MB まで。取り込めたらそのプロジェクトを開く）、星。
- プロジェクトの中：画像を取り込む（ファイルを直接選ぶ）・アーカイブする（確かめ `I0w2e`。済んだら一覧へ）・復元・「…」（お気に入り・複製する・名前と説明を変える）・生成パネル・画像を生成・条件をクリア・止める。
- 画像の詳細（窓 `rI5uh`。一覧・ライブラリのどちらからも開く）：ダウンロード（閲覧のみも可）・お気に入り・アカウントへ渡す・一覧から外す（確かめ `B24oNg`。詳細の窓は閉じて確かめだけを出し、やめると詳細へ戻る）・参照画像にする（プロジェクトの中だけ）・同じ設定でもう一度生成。
- **変えた所**：渡す先からアーカイブしたアカウントを外した（受け取る口が止まっている）。渡す先の一覧は5人分の高さで、多いときは中で送る。

## 権限
- 役割はサーバ（`useStaffRole`）から読む。オーナー・管理者以外は「閲覧のみ」として、作る・取り込む・星・アーカイブ・生成パネル・渡す・外すを**置かない**（押せない形でも出さない。2026-10-06 オーナー決定）。読み込める間は一覧・画像・詳細・ダウンロードは見られる。
- 403 は「バナー生成は統括の管理者・オーナーだけが使えます。」（v7 と同じ）。

## 失敗時
- 作る・渡す・外すの失敗は、共通の状態別案内（`describeApiFailure`、M022）を窓の中に出し、窓は開いたまま送り直せる。
- お気に入りの失敗は帯で「お気に入りを変更できませんでした。もう一度お試しください。」。
- 上限・一時停止・課金の停止は帯（一覧）と生成パネルの中（プロジェクトの中）に出す。言葉は v7 と同じ判定。

## 見た目の決めごと
- 窓の枠は `frame.tsx`（共通の `useOverlayFocus` でフォーカス・Esc・背景で閉じる・処理中は閉じない）。共通の窓は見出しの行の余白と説明の文字が絵と違い、説明が8上・2行に折れるため使っていない。
- 生成パネルと参照画像を選ぶ窓は、共通の `components/hq/banners/generation-panel`・`reference-picker-dialog` をそのまま使う（2026-10-05〜06 にオーナーが ★BG-B・★BG-C で決めた形。絵 `iMnph`・`UcBQ5` は決定前の古い形）。
- プロジェクトの中の下の帯は、承認済み ★BG-B `qIp42` の `X2oLn`「下部追従バー」どおり **左=残り枚数（`M118zK`）／中=書き出す大きさの札（`WDJak`）／右=条件をクリア（`wCvLN`）＋生成する（`abZle`）**。生成中は `An26R`「帯（生成中）」で、右が「生成をやめる」（`CzXI2`）＋押せない「生成中…」（`q9hrn`）。共通の `components/shared/sticky-bar` を使い、札は `components/hq/banners/export-size-chip`。
  - **変えた所**：生成ボタンをパネルの中の全幅ボタン、大きさと「条件をクリア」をその下の行に置いていたが、絵と配置が違っていた（2026-10-07 の差し戻し2件）。v7（`app/hq/banners/project/page.tsx`）と同じ並びにそろえた。止める操作は帯だけに置き、作っている最中の注記（`k7sbSR`）からボタンを外した（同じ操作が2か所に出ていた）。閲覧のみの人には押せないボタンを置かないので帯ごと出さない。
  - **帯の見た目は板どおり（`outlined` を渡す）**：`X2oLn` は **高さ72／枠線 `#DADDE2` 1px／角丸12／影の指定なし**。V8 の既定は ★A/M10 の板で決めた浮かせ（高さ60・枠なし・ふんわり影）だが、それは**別の板**なので、この画面は共通部品の口（`sticky-bar` の `outlined`）で板どおりに戻す。v7 の土台は元からこの姿なので、渡しても見た目は変わらない。下から浮かせる量は `X2oLn` に指定が無いため、推測で 0 に戻さず ★A のまま 12px を使う。
- **順位の記録（2026-10-07 の止まりの再発防止）**：`docs/v8-design-rules.md` §1 は「2. Pencil の ★V8（**画面ごとに、その板の絵のとおり**。1枚の絵を全部の画面の決まりにしない）」＞「4. 共通部品」。この回は**逆に扱い**、共通部品に入っていた ★A/M10 の浮かせを承認済みの `qIp42`/`X2oLn` より優先し、板どおりに直すことを利用者への選択の質問にしてしまって止まった。**承認済みの板と共通部品が食い違ったら、質問ではなく板に合わせる**（既存承認の中の直しなので、新しい承認は要らない）。直し方は「★A の規定を弱める」ではない（40画面以上がその板のまま）。**板が違う画面だけが渡す札**を足し、より強い指定で戻す。ひと組の見張りは `components/shared/sticky-bar-contract.test.ts`。
- **足した札の書き方（同じ止まりを防ぐための決めごと）**：
  - 板と共通部品の既定が食い違ったら、部品の既定を書き換えて他の画面の合格を壊すのではなく、**その見た目を選ぶ名前を部品に1つ足す**（帯 `sticky-bar` の `outlined`、行内ラジオ `radio` の `size="small"`、切替器 `segmented` の `size="panel"`）。足した見た目は `[data-theme='v8'] .root[data-size='…']` のように v8 の中だけで効かせ、既にある板の合格は変えない。画面側の `className` で部品の中身を上書きして済ませない。
  - 足した見た目は、**板のどの番号の絵から来たかをコメントと試験に書く**（`radio-size.test.tsx`・`segmented-size.test.tsx`・`sticky-bar-contract.test.ts`）。数字（文字の大きさ・余白）を後から「そろえる」と ±4px の照合が外れるので、根拠の無い数字を置かない。
  - **余白の段（4px きざみ）の見張りと板の寸法が食い違ったら、その画面だけの CSS Module に理由つきで書く**。見張り（`size-scale-contract`）は Tailwind の余白を段に保つためのもので、板の寸法そのものを否定しない（★BG-B `R6MBHf` の名前と説明の間 2px は `generation-panel.module.css` に書いた）。
  - この3つは `docs/v8-design-rules.md` §2 にも入れたいが、あの文書は司令塔の所有パスで lane の PR から変更できない（`required-pr-gate` の「Protect command-center owned documents」）。正本への反映は司令塔の枝で行う。それまではこのファイルが作業記録。
- 値は `globals.css` の `[data-theme="v8"]` の `--tpl-hb-*`。
