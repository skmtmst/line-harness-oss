## 撮れない板・正本の食い違い

- NGh7b：撮影指定は `PUT /api/webhooks/outgoing` の409と「保存する」のクリック。しかし作成は POST で、操作は「下書きを保存」「つくって動かす」。作成・更新の口に版の競合の契約が無い。画面に偽の競合を入れたり、撮影指定を勝手に変えたりしていない。
- wWrpY：対応表にも `manual: 状態の見本帳（横並び）` がある。未登録・絞り込み0件・読み込み・失敗・閲覧権限の状態は既存の共通 ListState／Skeleton／Notice と動きの試験で守る。通常の一覧を撮った0%を合格率へ混ぜない。
- AsfFB：板名とURLは送信一覧だが、PNGとTSVに「いつ・どちら向き」「送った・届いた中身」「返事」「かかった時間」の記録の列がある。送信一覧を別機能の表へ置き換えない。正本の修正か対応先の指定が必要。
- 複数のPNGが更新済みのTSV／HTMLと異なる。PNGの古い寸法へ戻して新しい座標を崩さない。上表に代表の違いを記載。司令塔に新しいPNGでの再照合を引き継ぐ。
- 共通 Dialog の題・解除警告・操作帯、共通の数の帯の単位と印は司令塔の判断待ち。追加指定を使う範囲だけ共通化し、既定の見た目そのものは変更していない。
