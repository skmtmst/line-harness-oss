# 健康日記（専用機能）の動き（BEHAVIOR.md）

対象：今までの V8 の健康日記（`app/nen/health/health-v8.tsx`）と v7（`page.tsx` の HealthInner・`health-tab.tsx`・`items-tab.tsx`・`summary-drawer.tsx`）。動きを写して、`health.tsx`（外枠と一覧）・`summary.tsx`（30日のまとめと印刷面）・`items.tsx`（記録の項目）を一から書いた。見た目は型（ListPage）と部品で組み直した。板は 一覧 `mIwA4`・30日のまとめ（引き出し）`BVuYh`・記録の項目 `z2tvtX`。

## 入口
- `app/nen/health/page.tsx`：V8 のときだけ `@/v8/nen-health/health` を出す。v7 の画面と `health-v8.tsx` は切り替えの日まで残す。

## 受け付ける URL と指定（今までと同じ名前・同じ意味）
- `?tab=concern`：気になる変化（同じ一覧を「変化：気になる」で絞る）。`?tab=items`：記録の項目。無い・ほかの値は記録のあるペット。
- タブを替えると `router.replace`（`/nen/health` か `/nen/health?tab=…`）。
- 探す・札・よく使う絞り込み・並び・件数・ページは URL に残さない（今までどおり画面の中だけ）。

## 読み込み（API・今までと同じ口）
- `GET /api/nen/health?accountId&q&change&last&sort&page&pageSize`：一覧と数の帯（`kpis`）。古い返事は番号で捨てる。件数（10・20・50）は `pageSize` で送る（`nenPetsApi.health` に `pageSize` を足した。Worker は前から受け取れる）。記録の項目のタブでは `pageSize=1` で1件だけ取って数を読む。
- 一覧の取得は、絞り込み・ページ・件数が変わったときだけ。探す欄は打ち終わってから 0.3 秒で取り直す。
- `GET /api/nen/health/:petId/summary?accountId`：30日のまとめ。対象スナップショット（アカウント＋ペット）と要求世代で照合し、閉じた後・別のペットを開いた後・アカウントを替えた後に届いた返事は捨てる（DEEP-23）。失敗はそのまま共通の失敗面へ渡し、403 と 429 を言い分ける（M034）。

## 一覧（mIwA4）
- 上から 案内の帯 → 道具の段（ペットを探す・よく使う札3つ〈気になる変化・今週 記録あり・30日 記録なし〉・よく使う絞り込み・件数）→ 表 → 件数 → ヒント。気になる変化のタブでは札を出さない（もう絞っている）。
- よく使う絞り込み（「…」のメニュー）：変化なしのペット・30日以内に記録あり・最後の記録が30日より前、並び（気になる順・最終記録が新しい順・30日の記録が多い順）、絞り込みを外す。
- 列：ペット（名前・種類・品種）・飼い主・最終記録（「9/30」。相対の言い方は title）・30日の記録（「28 日」）・体重の推移（8週の小さな棒。体重の変化がある行は琥珀）・便・食いつき・気になる変化（札）・行の「…」。
- 気になる変化の札：体重が減った／体重が増えた／便の異常が続く／食いつき不良が続く（琥珀）、記録なし（灰）。くわしい数（「体重 −6%（8週）」）は札の title。変化が無ければ、30日の記録があれば「いつもどおり」（緑）、無ければ「記録なし」。
- 行の「…」：30日のまとめ・獣医師向け PDF（まとめを開き、読めたら一度だけ印刷の窓を出す）・飼い主を開く（`/friends/detail?id=…`）・飼い主にトークで声をかける（`/chats?friend=…`）。
- 数の帯の「…」：その数で一覧を絞る（すべて・気になる変化だけ・今週 記録あり・30日 記録なし）。ほかのタブからは記録のあるペットへ戻して当てる。

## 30日のまとめ（BVuYh）
- 右から出る引き出し（共通の Drawer を幅 600・頭の線なしに合わせた）。題「健康日記 30日のまとめ」、下に「こむぎ（犬・柴・4歳）・田中 明子さん・9/1〜9/30」。
- 注意書き（診断や治療の判断は含みません）→ 記録・体重・呼吸数（平均）・心拍数（平均）→ 体重の30日の棒と「30日で −0.6kg（−6%）」→ 記録の表（日付・体重・便・食いつき・皮膚・涙やけ・メモ）→ 印刷・PDF に保存する。
- 板の頭の「獣医師向け PDF を書き出す」は、まとめが読めている間だけ押せる（押せない間は title で開き方を案内）。どちらもブラウザの印刷（PDF に保存）。
- 印刷面（`data-print-sheet`）は画面に出ず、印刷のときだけ紙になる。中身は今までと同じ（記録・体重の幅・心拍数・呼吸数・回数・表・メモ・注意書き）。

## 記録の項目（z2tvtX）
- 数の帯の直下に、変えられない決まりの表（項目・記録の形・選べる値・「気になる変化」に出る条件・30日のまとめ）。条件の数（8週・±10%・3回・30日）は Worker と同じ。

## 権限
- 健康日記はお客さまがマイページで付けるもので、ここに変える操作は無い。閲覧のみの人も同じ画面（帯は出さない。押せないボタンが無いため）。

## 今までと変えたところ
- 道具の段の「並び」の選ぶ欄を、よく使う絞り込みの中へ（絵の道具の段は 探す・札・よく使う絞り込み・件数）。
- 件数（10・20・50）を選べるようにした（今までは 20 件固定）。
- 最終記録は日付（「9/30」）で見せ、「昨日」などの言い方は title。30日の記録は「28 日」。
- 気になる変化の札は短い言葉にし、くわしい数は title。
- 30日のまとめは自前の引き出しではなく共通の Drawer。記録の表の涙やけは短い言葉（なし・少し・気になる）。
