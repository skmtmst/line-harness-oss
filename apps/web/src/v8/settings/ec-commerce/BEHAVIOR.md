# EC連携の動き（BEHAVIOR.md）

対象：`screen.tsx`（★V8 `GmVR5`、定期便 `wqC8x`・つなぎ先 `iLJmw` は今の部品を差し込む）。
写し元：`app/ec-commerce/page.tsx` の EventsPanel・`ec-tabs-view.tsx`。

## 入口・URL
- `app/ec-commerce/page.tsx`：見た目が v8 のときだけこの画面。v7 は今の画面のまま。
- `?tab=events|subscriptions|connector`（`useMergedTab`）。会員のつき合わせは `/ec-commerce/identity-candidates`。

## 読み込み（API）
- 集計 `GET /api/ec-commerce/overview`、一覧 `GET /api/ec-commerce/events?view=actions`（20件ずつ・`status`/`statusGroup`・`query`・`sort`）。
- 値は取ったアカウントと一体で持ち、切り替えたら同期的に捨てる（#685）。古い応答は世代で捨てる。
- 一覧が取れていない間は状態別の数を出さない（R599）。集計だけの失敗は小さな1行と「集計をもう一度読む」。

## 操作
- 札：すべて／処理完了／処理中／失敗／送信なし（サーバで絞ってからページを切る）。探す言葉は 300ms 遅らせて 1 ページ目へ。並び（新しい順／古い順）。
- 行の「…」：中身を見る（友だち）またはつき合わせる・注文の状況を見る（引き出し）・もう一度やる（409 は読み直し）。
- 数の帯：処理完了・処理中・送信なし・失敗（一覧の集計）。最後に届いた日時・今日取り込んだ数は表の下に小さく。
- 見るだけの人には定期便の「対象を選んで送る」を出さない。つなぎ先の保存口は今の部品が隠す。

## 注文の状況の引き出し（`order-drawer.tsx`・★V8-B `nAesv`）
- 行の「…」→「注文の状況を見る」で右から開く（幅 560）。口は今と同じ `GET /api/ec-commerce/orders/:id?lineAccountId=`。読み直しは世代で古い応答を捨てる。
- 見出し：注文番号、お客さまの名前（友だちと結びついていれば友だちへ行ける）・結びつきの有無・返金／取り消し。結びついていなければ「会員のつき合わせへ」。
- 4つの段（絵の順）：注文の内容（中身・金額・EC側の注文＝注文した時刻と ECの管理画面で開く）／この注文に届いた出来事／成果・マイル・スコア／発送後に届く案内。各段は「時刻＋1行」。
- 済んだ出来事は1行だけ。止まった・失敗・見送りの出来事は、その下に状態・止まった段階・失敗の理由（分類と次にすること）・回数・「もう一度やる」（押すと戻して読み直す）・通知と配送の失敗を足す。
- 成果は承認待ち・却下・紹介者・報酬・支払いの段階・確定後の取消・同じ注文の重複を、あるときだけ下に足す。発送後の案内は送った時刻・見送り／失敗の理由を、あるときだけ足す。
- 権限なし（403）は「見る権限がありません」、それ以外の失敗は「読み込めませんでした」＋もう一度。閉じ方は右上の×・幕を押す・Esc。
- 今までの引き出し（app/ec-commerce/order-detail-drawer.tsx）は v7 の画面だけが使う（v8 の入口から外した）。

## 会員のつき合わせ（`identity.tsx`・★V8-B `w1W8h`）
- 入口：`app/ec-commerce/identity-candidates/page.tsx`（見た目が v8 のときだけ）。外側と中の切り替えは取り込みの記録と同じ（右上は「つなぎ先の設定」）。
- 口は今と同じ：候補は本人照合の口（`useIdentityReview('ec_member')`）、数と金額は `GET /api/ec-commerce/identity-candidates`（EC運用の集計）。アカウントを切り替えたら古い集計の応答は捨てる。集計だけの失敗は数の帯に出し、候補の表は残す（数は 0 と書かず —）。
- 数の帯：自動で結びついた・候補が見つかった（つき合わせ N のうち）・結びついていない・結びついていない注文の金額。
- 自動で結びつく条件は1行の帯（入りきらないときは「…」と title）。
- 並び（確からしさが高い順・注文が新しい順）と、絵に無い絞り込み（すべて・候補あり・候補なし・同じ人が2人いる疑い）は並びの横の選ぶ部品に残した。
- 表：ECの注文・会員（下の行に会員番号と「注文 N件 ¥…」）・LINEの候補・似ているところ・確からしさ・操作。候補があれば「候補を見る」（表の下に両方の中身・根拠・影響・これまでの判断。開いている行の「候補を見る」は緑）と「決める」（判定の窓）。候補なしの行は「友だちを探す」（`/friends?q=名前`）。
- 続きがあれば「続きを読み込む」。表の下に件数（読めていなければ —）。
