# SNS 連携（V8）の動き

入口：`app/settings/sns/page.tsx`（新しい画面なので V8 だけ）。絵：提案 E-6 `y3GGTs`。Google ビジネスと Instagram の2つだけ（X は入れない）。
- 設定の中のメニュー：ほかの設定の画面のメニューの末尾に「SNS 連携」を出す。この画面は絵にメニューが無いので出さない（`useHideSettingsNav`）。

## Google ビジネス
- 口：`GET /api/restaurant-test/google/connection`（今ある接続の口）。
- 札：つながっている／店舗を選んでいません／認可切れ／権限なし／つないでいません。
- つながっている（と認可切れ・権限なし）：店舗（接続した店舗の名前）・最終同期・口コミ（★平均（件数）・未返信 N件）・投稿（確かめる投稿の数）。下に「口コミへ・投稿へ・プロフィールへ」（Google ビジネスの画面の各タブ）。
- つないでいない：説明と［Google とつなぐ］（管理できる人だけ・Google ビジネスの設定へ。つなぐ手順はそちら）。
- 「…」：接続の設定を開く（管理できる人だけ）。

## Instagram
- 札「まだつないでいません」。つなぐとできること4つ（DM を受信箱で読む・返す／投稿へのコメントに返す／投稿を予約する／プロフィールのリンクを LINE の友だち追加へ向ける）。
- ［Instagram とつなぐ］：押せる形のまま、押すと「Instagram とつなぐ機能は、まだ使えません」の案内（管理画面の決まりで「準備中」とは書かない）を出す（つなぐ口が無い）。横に「プロアカウント（ビジネス）が必要です」。
- 閲覧のみ（owner・admin 以外）には［つなぐ］を置かない。

## 受信箱での見え方（見本）
- 絵の見本の表をそのまま出す（相手・対応・担当・最新のメッセージ・経路・最終接触。実際のメッセージではないと「？」に書く）。

## 今の口で出せないもの
- 投稿の「今月 N件・次の予約」（投稿の数を返す口が接続の口に無い。いまは確かめる投稿の数）。
- Instagram の接続・DM・コメント（口が無い）。
