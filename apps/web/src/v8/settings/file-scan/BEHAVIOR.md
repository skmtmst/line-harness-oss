# ファイルの検査の動き（BEHAVIOR.md）

対象：`screen.tsx`（★V8 `PfA4o`、空の状態は `bR6a1`）。写し元：`app/settings/file-scan/file-scan-v8.tsx`・`use-file-scan.ts`。

## 入口・URL
- `app/settings/file-scan/page.tsx`。`/settings/file-scan`（指定なし）。

## 読み込み（API）
- アカウントごとの `GET /api/file-scans`（札の状態・探す言葉・ページ 50件）と外の検査の設定。403 は「管理者だけが開けます」。

## 操作
- ファイル名で探す、札「しまったファイル N」「確かめ中 N」「戻した」。
- 行の右端：「使えるように戻す」（理由必須の窓）＋「…」（削除する＝確認の窓）。
- 外の検査サービス：設定を編集（提供元・送り先 https・鍵の名前）・外の検査を止める。編集中の離脱は番兵の窓。
- 空：しまったファイルが無いときは「しまったファイルはありません」、絞り込みで 0 件は「条件に合うものはありません」＋「条件を外す」。
