# LINEアカウント一覧の動き（BEHAVIOR.md）

対象：`app/accounts/page.tsx`（今の画面）から写して `accounts.tsx` を一から書いた。板 `V7vn3`。

## 入口
- `app/accounts/page.tsx`：`data-theme="v8"` で、`?tab=migration` でないときだけこの画面を出す（`useSettingsTheme`）。
  `?tab=migration`（UID の移行）は今までどおり今の画面が受ける。v7 側は触らない。

## 受け付ける URL と指定
- `?tab=migration`：今の画面へ渡す（上）。ほかの指定は無い（今の画面と同じ）。

## 読み込み（API）
- `api.lineAccounts.list()`。「接続をもう一度確かめる」は `list(true)`（live）で一覧ごと取り直す。
- 判定・言葉は `view.ts`（`app/accounts/account-list-view.ts` の写し＋数の4枚・並び）。直すときは両方。

## 見せ方
- 数の4枚：つないでいる（全部）・稼働中・接続に問題・友だちの合計（アーカイブは数えない）。未取得は「—」（0 と出さない）。
- 探す欄（名前・チャネル ID。打つたびに取り直さない）＋絞り込みの札（すべて・稼働中・停止中・接続に問題・アーカイブ。数つき）。
- 表：アカウント／接続状態／Webhook／友だち／既定（★）／親アカウント／「…」。並びは displayOrder（「並び順と親子を変える」で決めた順。サーバと同じ）。

## 操作
- 頭：「並び順と親子を変える」→ 窓で今ある並び替えの部品（`components/accounts/account-ordering`）。閉じたら読み直す。「LINEアカウントを登録」→ `/accounts/new`。
- 行の「…」：詳細（`/accounts/detail?id=`）・接続をもう一度確かめる・引き継ぎ（`/accounts/handover?id=`）・アーカイブ（理由・本人確認）／アーカイブから戻す。
- 見るだけの人には、頭の2つ・引き継ぎ・アーカイブ（戻す）を出さない。詳細と確かめ直しは出す。

## 失敗
- 一覧の失敗は `ListState` の error（再読み込み）。アーカイブできない理由（blockers）は運用者の言葉で窓の中に。428 は本人確認の窓を立ててやり直す。

## 今の画面から変わったところ
- 数は 稼働中・停止中・アーカイブ の3枚から、絵の4枚へ。頭に「並び順と親子を変える」（今まで画面から開けなかった部品）を足した。スマホ幅のカード表示は持たない（PC 幅の表だけ）。
