# 会員（専用機能）の動き（BEHAVIOR.md）

対象：`app/nen/members/members-v8.tsx`（今までの V8 の会員）。このファイルの動きを写して、`members.tsx`（外枠）・`list.tsx`（会員一覧）・`ranks.tsx`（ランク設定）・`lifetime.tsx`（ライフタイム）を一から書いた。見た目は型（ListPage）と部品で組み直した。板は 会員一覧 `AOWoJ`・ランク設定 `fb9NJ`・ランクを消す（確認）`dEv6G`・ランク設定の競合 `e5yBLx`・ライフタイム `zQ5vY`。

## 入口
- `app/nen/members/page.tsx`：V8 のときだけ `@/v8/nen-members/members` を出す。設定の読み込み（アカウントごとの世代・切り替えの瞬間に読み込み中へ戻す）と保存結果の受け取りは今までどおり page.tsx が持つ。v7 の画面（members-tab・rank-settings-tab・lifetime-tab）と `members-v8.tsx` は切り替えの日まで残す。

## 受け付ける URL と指定（今までと同じ名前・同じ意味）
- `?tab=ranks`：ランク設定。`?tab=lifetime`：ライフタイム。無い・ほかの値は会員一覧。
- タブを替えると `router.replace`（`/nen/members` か `/nen/members?tab=…`）。「ECとの照合」は `/ec-commerce/identity-candidates` へのリンク。
- 会員一覧の検索・札・並び・件数・ページは URL に残さない（今までどおり画面の中だけ）。

## 読み込み（API・今までと同じ口）
- `GET /api/nen/rank-settings?accountId`（`nenRanksApi.settings`）：ランク・決まり・節目・数の帯。page.tsx が読む。形が違えば失敗として扱う。
- `GET /api/nen/members?accountId&q&rank&ranks&link&pet&sort&page&pageSize`：会員一覧。古い返事は番号で捨てる。
- CSV：会員を 100 件ずつ全部取り、BOM 付きの CSV（会員名・EC会員ID・LINE連携・ランク・通年・ライフタイム・マイル残高・ペット・最終購入・マイル還元）。先頭が `=+-@` のセルには `'` を付ける。板の頭の「CSV で書き出す」と、数の帯の「…」の「CSV で書き出す」は同じ動き。

## 権限
- 役割はサーバ（`/api/staff/me`、`useStaffRole`）。管理できない人は「閲覧のみで見ています。ランクや節目を変える操作は管理者に頼んでください。」の帯（タブの下）。
- 閲覧のみには、ランクを足す・行の削除・もう一度同期・キャンセル・保存・節目を足す・節目の「…」を出さない（押せない飾りを置かない。2026-10-06 オーナー決定）。入力欄は読めるが変えられない。ランクの行の「…」は「タグを開く」だけ残る。CSV は使える。

## ランク設定（fb9NJ）
- 左に「ランクの決まり」（通年の区切り・集計に含める注文・上がったとき・維持する期間。灰の地の箱で、変えられない）と「ランク」、右に「ECとの同期」。下の中央に キャンセル・保存して EC へ同期。
- ランクの行：ランク名・通年のしきい値（「¥200,000〜」の形で見せる。保存の前に ¥・,・〜 を外して数へ）・マイル還元（「3%」の形）・行の「…」。いちばん下（¥0）は「¥0〜（固定）」の箱で変えられない。
- 行の「…」：タグを開く（`/tags/edit?id=…`、タグがあるときだけ）・ランクを削除する（いちばん下は押せない・理由つき）。
- ランクを足す：いちばん下の固定の行のすぐ上に空の行（8 つまで）。保存前の行は「…」の削除でその場で外れる。
- 保存：空の名前・読めない金額・読めない還元は送らずに知らせる。送る前に最新の設定を取り直し、版（`rules.version`）が進んでいたら競合の帯へ。`PUT /api/nen/rank-settings` が 409 を返したときも競合の帯へ。保存できたら、ECへ送れたかを知らせる。
- もう一度同期：`POST /api/nen/rank-settings/resync`。保存していない変更がある間は押せない。
- 保存していない変更があるまま画面を離れると、確かめの窓（`useUnsavedGuard`）。

## ランクを消す（dEv6G）
- 「…」→「ランクを削除する」で窓（幅 520・上から 300）。会員がいるランクは「移す先のランク（必須）」を選ぶ。最初からひとつ下のランクを選んでおく（無ければひとつ上）。選ばないと消すボタンは出ない。
- 「N 人を移して消す」：`DELETE /api/nen/rank-settings/:id`（`replacementRankId`・`expectedVersion`）。消せたら設定を読み直す。409 は窓を閉じて競合の帯へ。
- 会員がいないランクは「消す」だけ。

## 競合（e5yBLx）
- タブの下・数の帯の上に琥珀の帯：「ほかの人が HH:MM にランク設定を保存しました」「このまま保存すると、ほかの人の変更が消えます」。保存した人の名前は API に無いので「ほかの人」と書く。
- 違いを比べる：最新の保存といまの下書きを並べた窓。「この内容で保存する」で版の確かめを飛ばして保存。
- 最新を読み込んで続ける：最新の設定へ乗り換え、下書きは捨てる。
- 帯が出ている間、保存ボタンは「比べてから保存」（押すと比べる窓）。

## ライフタイム（zQ5vY）
- 1枚のカードに説明と右に「ライフタイム 合計」、下に節目の表（節目（累計）・称号・特典・到達した人・到達時の LINE 通知・行の「…」）。いちばん高い節目の称号は太字で下に「最上位」。
- 行の「…」：編集する（窓で 金額・称号・通知を直す）・削除する。「＋ 節目を足す」は同じ窓で新しい行（12 まで）。窓で決めた内容は下書きに入り、下の中央の「保存して EC へ同期する」でまとめて `PUT /api/nen/lifetime-milestones`。特典は API で変えられないので表に出すだけ（無ければ「未設定」）。

## 今までと変えたところ
- ランクの行の削除は、赤いごみ箱ではなく行の「…」の中（行の右端は「…」の決まり）。保存前の行を外す「行を外す」の文字ボタンも「…」の削除にまとめた。
- ランク設定の表から「タグ」「会員数」の列を外した（絵 fb9NJ に無い）。行に重ねたときの吹き出し（title）でタグ名と会員数を読める。
- ライフタイムの表は、行の中の入力欄・スイッチをやめ、「…」の「編集する」の窓で直す（絵 zQ5vY は値を文字で見せる）。
- 保存・キャンセルは画面の下に張り付く帯（StickyBar）ではなく、カードの下の中央（絵どおり）。
- `PUT /api/nen/rank-settings` の 409 も競合の帯へ（今までは保存の前の版の確かめだけ）。
