## 一覧（list.tsx）
- 外側は4つのタブで同じ：見出し・説明・右上（コラムは「コラムを書く」、ほかは「CSV で書き出す」）・タブ（自動配信 N・コラム N・停止中 N・送った履歴）・数の帯（自動配信／今月送った／開封／コラム）。
- 数の帯の開封：自動配信は「自動配信は開封を取れません（コラムだけ）」、コラムは「コラムを開いた割合」、送った履歴は題を「取得不可」にして「配信ごとの開封の集計から」。
- 表は「見出し 36・行 56」の同じ物差し。行の右端は「…」ボタン（右クリックだけにしない）。表の下に件数（1ページでも出す）とページ送り、操作のヒント。
- 自動配信：コラム以外の配信を全部（止めているものも）今月多く送った順。札「注文のあと N」「誕生日 N」「止めている N」、よく使う絞り込み（注文・発送／注文のあと／ペットの誕生日）、10・20・50件表示、名前で探す。
  - 「…」：編集・中身を見る・テスト送信・（誕生日）クーポンの決めごと・止める／動かす・送った履歴を見る。
  - CSV：一覧に出ている決めごと（配信名・きっかけ・対象・状態・今月送信）。
- 停止中：止めている配信だけ。
- コラム：札「公開中 N」「下書き N」「（いちばん多い分類）N」、よく使う絞り込み＝分類、10・20・50件表示。公開日は「9/26」、予約中の下書きは「10/10 予定」。LINE 配信は 予約中／配信待ち／送信済み N／送っていない。
  - 題名を押すか「…」→「この内容で予約する」で、表の下に「選んだコラム」：紹介文の保存（版つき・競合は page.tsx）、同じ形で書く（複製）、自分にテスト、今すぐ／日時を予約、配信を予約する（確認の窓）。
  - 200本を超えて読み切れないときは注意の帯。
- 送った履歴：札（送りました・これから・届きませんでした・送りませんでした）と探す（手が止まってから1回）。開封は「取得不可」。「…」→ 中身を見る・再送待ちへ戻す（理由が要る。直せる理由で止まったものと上限まで失敗したものだけ）。ページ送りは口のカーソル。
- 誕生日クーポンの決めごと（引き出し・幅520）：クーポンを付ける・特典の名前・割引額（円）・使える日数・コードの頭の文字・2月29日生まれの子・届く見本。保存の決めごと（1〜100,000円・1〜365日・大文字と数字3〜10文字）は page.tsx。

## 配信を直す（edit.tsx）
- 読み込み：`settings`（その key）・`forms.list`・`overview`（配信待ちの数）・`getTestRecipientLoginUsers`。
- 節：配信フロー（きっかけ→日数と時刻→この配信→フォームに答えた→N マイル）・いつ送りますか（きっかけからの日数・送る時刻・届かない日＝なし）・送るもの（届く形は画像の有無で決まる・本文・差し込み）・押されたあとにすること（回答フォーム・回答後のマイル）。
- 日数・時刻・フォーム・マイルは選ぶ欄（いまの値が候補に無くても入れて出す）。マイルの「ほかの数を入れる」から1〜1,000,000の任意の整数を共通の窓で指定できる。非公開のフォームは理由つきで選べない。誕生日は「3日前 10:00」固定で、選べない箱で見せる。
- 差し込みの道具は本文の右上「差し込む」で開く。残りの字数は 300字を切ったときだけ、超えたら赤字。
- 保存：`updateSetting`（版 `expectedUpdatedAt` つき）。409 は入力を残し、比較で最新を取り、明示的に読み直すときだけ入力を置き換える。フォームが使えない・マイルが範囲外・本文が長すぎるときは保存しない。
- 自分にテストを送る：名前で探す（Enter）→ 送る相手（2人以上なら下で選ぶ）→「テストを送る」。下書きの中身で送る。
- 下の帯：キャンセル・配信内容を保存する（中央）。左は短い状態（動いています／配信待ち N通は前の中身のまま／停止中）。

## コラムを書く（column-new.tsx）
- 決めごとは `column-form.ts`（今の画面の写し）：題名1〜120字・記事の URL は HTTPS・画像は任意で HTTPS・分類40字・概要200字・配信日時は先の日時・タグで絞るならタグ必須。
- 配信対象は1つの欄：「友だち全員」か「タグで絞る：〇〇」（このアカウントのタグだけ）。届く人数を欄の右上に出す。アカウントを替えてタグが無くなったら外して知らせる。
- 公開日時（任意）は「公開日時も記録する」で開く。題名が20字を超えたら題名の右に知らせ。
- 届く形：画像の URL があれば写真つき、無ければ文字だけ。「文字だけ」を選ぶと画像の URL を外す。
- 画像か分類を指定した見本は右欄で一覧と同じ共通の記事カードを出す。未指定の見本は現在の文字の吹き出し。見本は保存や配信を行わない。
- 保存：`createColumn` → `/nen-campaigns?tab=columns`。足りないまま押すと保存せず欄の下に理由。失敗は 403／400・413／409／その他で言い分ける。

## 閲覧のみ（変える権限が無い人）
- 一覧：帯「閲覧のみで見ています」を数の帯の上に出す。「コラムを書く」・編集・テスト送信・止める・予約・複製・再送は置かない（押せない形でも置かない）。CSV・中身を見る・送った履歴を見る・クーポンの決めごと（見るだけ）は出す。
- 配信を直す：帯を出し、選ぶ欄は値の箱、保存とテスト送信は置かない（「一覧へ戻る」だけ）。
- コラムを書く：帯と「一覧へ戻る」だけ。
