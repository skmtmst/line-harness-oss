# 来店スタンプ（V8）の動き

入口：`app/visit-stamps/page.tsx`（V8 だけで出す）。絵：`w4SBbv`（提案 E-7）。左メニューは「予約」の組（予約管理・予約設定・イベント予約の次）。飲食店もサロンも使うので `/restaurant-test` の外に置く。マイル（オンライン・特定の動き）とは別のカード・台帳。

## 受け付ける URL と指定
- `/visit-stamps`：指定なし。
- `/visit-stamps?friend=<友だちID>`：「店で手入力」でその友だちを選んだ状態で開く（④ の記録もその人）。

## 呼ぶ口（`lib/visit-stamps-api.ts`・Codex の API-7）
- 読む：`GET /api/visit-stamps/cards`（選んでいる店が押せるカード→無ければ先頭）、`GET /api/visit-stamps/paper-requests?accountId`、`GET /api/visit-stamps/cards/:id/wallet?accountId&friendId`（④）。名前は `api.friends.list`（店の友だち 200 人）と `api.friends.get`（一覧に無い人だけ）、担当者は `api.staff.list`。
- 書く：
  - ①② の下書き → 下の帯［保存する］で `POST /cards`（まだ無いとき）／`PUT /cards/:id`（`expectedVersion` 付き）。ほかの人が先に保存していたら（409）知らせて読み直す。［キャンセル］は保存した値に戻す。
  - ③［承認］→ `POST /paper-requests/:id/review`（approve・理由は「紙のカードの写真を確認しました」）。［却下］は理由を書く窓から reject。
  - 店で手入力［押印を足す］→ `POST /cards/:id/grants`（理由＝選んだ理由＋メモ。「紙のカードから移す」は `source: paper`、ほかは `manual`）。`requestId` は押すたびではなく成功するまで同じ（二重押しで2回足さない）。
  - ④「…」→［この記録を取り消す］→ 理由を書く窓 → `POST /entries/:id/reverse`。取り消しも台帳に残り、元の行に「→ 取り消し」と出す。
  - 頭［店員の暗証番号］→ 店員と4桁 → `PUT /pins/:staffId`。保存後は番号を出さない（口も返さない）。
  - 頭［押せる店：…］→ 店を選ぶ窓（下書き。保存は［保存する］）。

## 表示の決まり（`display.ts`・試験は `display.test.ts`）
- マスの数＝いちばん大きい特典の個数（設定に別の欄は無い）。変えるといちばん大きい特典の個数が変わる。
- 特典の下の1行：サーバは使うと特典の個数だけ減らす。いちばん大きい特典は「使ったら新しいカードへ」、途中の特典は「使うとスタンプが N個へる」（絵の「使ったらマスはそのまま」はサーバの動きと違うので書かない）。
- 倍率の名前と中身：曜日か時間がある倍率は「N倍デー」、中身は「毎週 火曜 17:00〜19:00 ・ 1/1〜3/31」（期間の終わりはその日を含めて見せる）。スイッチを切る＝その倍率を消す（止めておく欄がサーバに無い）。
- 初回来店ボーナスのスイッチ：入れると +1個（「…」で個数を変える）、切ると 0。会員ランクの倍率のスイッチ：入れるとランクの窓、切ると消す。
- 「重ねたときの順番」はサーバが決めている（時間の倍率はかけ合わせ・ランクはいちばん高い倍率だけ）ので選べない1つだけを出す。「1回の上限」と「重ねたときの上限」は同じ値（サーバの上限は1つで、倍率を重ねたあとにかかる）。
- ④ の記録は「店で手入力」で選んだ友だちの台帳（店全体の記録の口は無い）。5件まで出し、6件以上は「すべて見る」で全部。
- 日時は日本時間「1/13 18:40」。誰が：自動押印は「自動」、特典は「店員：名前（暗証番号）」、紙の承認は「名前（承認）」。

## 権限
- 閲覧のみ（viewer）：変える操作を置かない（頭の2つ・下の帯・特典と倍率の「…」・特典を足す・倍率を足す・承認／却下・店で手入力の欄）。入力は読み取りだけ。
- 担当者（staff）：③ の承認・却下と店で手入力はできる（サーバも owner/admin/staff）。カードの設定・暗証番号・取り消しは出さない（サーバは owner/admin）。
- 役割が読めるまでは操作を出す（最後の守りはサーバの 403）。
