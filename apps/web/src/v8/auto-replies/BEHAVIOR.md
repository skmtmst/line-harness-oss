# 自動応答一覧の動き（BEHAVIOR.md）

対象：`app/auto-replies/list-v8.tsx`（V8一覧、`uE9gf`）。このファイルから写して `list.tsx` を一から書く。

## 入口
- `app/auto-replies/page.tsx`：`theme === 'v8'` のときだけ V8一覧を出す。v7側は触らない。

## 読み込み（APIs）
- 見るだけの人（`canEdit=false`、`roles` に `manage` 無し、またはオーナー代理で `tenantOwner=false`）は一覧だけ読み、数は読まない。
- 管理できる人は `listAutoReplies`・`listFolders`・`listTemplates`・`getAutoReplyStats` をまとめて読む。
- ルール数が多いアカウント（しきい値 `fetchAllThreshold=50`）は件数→ID一覧→100件ずつ読み、300件で止める（「300件までしか見ていません」）。
- 失敗：読み直しを出す帯／行内の読み直し。「つまみから作り直し…」が3回→`次は読み込めませんでした`。
- 状態ワード：`読み込み中…`／`新しく追加された…を読み込んでいます`／`押した並び替え・絞り込みを反映しています`／`並び替え中…`。

## 並び・絞り込み（URLで覚える）
- URL（`?folder=&q=&sort=&page=&size=&view=&closed=`）に残る。`view=closed`→停止中のみ。
- 並び：評価順（優先度）／新しい順／名前順／今月多い順／重なり多い順。並び替えは手元でやる。
- 絞り込み：フォルダ／言葉（25文字まで、長いと注意）／停止中のみ／時間帯あり／今月0回／重なりあり。
- よく使う：すべて・動いている・停止中・時間帯・今月0回・重なり。
- つまみ（評価順のみ、ドラッグ＋キーボード）→ `reorderAutoReply` → 失敗で元に戻す＋理由。`order`が無い古いデータは並べない。
- 優先度：1から振り直す。曜日・時間・キーワード・部分一致・AIが同じ＝同じ条件とみなし、下に警告。

## 一覧の行
- 名前（編集へのリンク。行を押すと詳細パネル、前後移動つき）／条件の行（受信＋曜日時間、以外の札）／返すもの（テンプレ＋種類＋後の処理）／今月・累計（nullは「—」、0は書かない）／状態（有効・停止中＋理由）／「…」（詳細・編集・停止/再開・複製・フォルダへ移す・実行結果・削除・選択）。
- 見るだけの人・運用担当は「…」が「詳細」だけ。権限が要る操作は `管理の権限がありません`。
- narrow幅では選ぶ箱・つまみ・回数・操作列を隠す（`boardId='WPrd5'`）。

## 帯（KPIs）

- 重なりは失敗しても一覧を止めない（理由＋読み直し）。

# 実行結果の動き（runs.tsx・板 nWmLg）

写し元：`app/auto-replies/runs/runs-v8.tsx`（import はしない）。入口 `app/auto-replies/runs/page.tsx` の V8 の import だけ差し替えた。v7（同じ page.tsx の AutoReplyRunsInner）は触らない。

## 受け付ける URL と指定
- `/auto-replies/runs?id=<ルールID>`：そのルールの実行結果。`id` が無ければ全ルール。返ってきたルールの ID が違うときは捨てる（古い返事で上書きしない）。

## 読み込み（APIs）
- `GET /api/auto-reply-runs?ruleId=&from=&to=&limit=&offset=`（`api.autoReplies.runs`）。返事の形が違えば「読み込めませんでした」＋再読み込み。古い呼び出しの返事は捨てる（連番）。
- 期間：既定は「今月」（月の初日から）。この7日・この30日・すべての期間・日付で決める（2つの日付欄を出す）。**v7 と旧 V8 は既定が「すべて」だった**（絵 nWmLg の「今月」に合わせて変えた）。
- 1ページの件数：10・20・50件（既定20）。ページ送りは共通の Pagination（「214件中 1〜20件」）。

## 帯・札・表
- 数の帯（KpiBand）：今月当たった（累計）／担当者へ引き継ぎ（確認待ち）／失敗した処理／平均で返すまで（最後に動いた）。
- 失敗が1件以上なら赤い帯：「失敗だけ見る」（札を失敗へ）と「失敗した処理をもう一度」（いまのページでやり直せる失敗を順に再実行。403 は権限の文、409 は飛ばす）。
- 札（このページの中で絞る）：すべて（全件数）・失敗（帯の数）・確認待ち（引き継ぎの確認待ちの数）・見送り（口に数が無いので数は出さない）。探す：友だち・届いた言葉・きっかけ。
- 表：日時（時刻。全文は title）・友だち（頭文字の丸＋友だち詳細へのリンク）・届いた言葉（「」で囲む）・結果の札・行ったこと・時間・行の「…」（トークを開く／もう一度実行＝再実行できる行だけ）。

## 操作と権限
- 一時停止する：止める窓（理由は任意・記録に残る）→ `api.autoReplies.stop`。有効なルールのときだけ押せる。
- ルールの編集へ・一時停止する・もう一度実行は owner/admin だけ。**閲覧のみには置かない（隠す）**。閲覧のみの帯を出す。CSV の書き出しは全員。
- CSV：100件ずつ読み、5000件で止める。途中で止められる。

## 失敗の扱い
- 読み込み失敗：帯ではなく表の場所に「読み込めませんでした」＋再読み込み。再実行 409：最新を読み直す。403：権限の文。

## かんたんに作る（`quick-create.tsx`・絵 `G4GejG`・小窓 560）
- 入口：作るボタン（▾）の「かんたんに作る」・0件のときの「かんたんに作る」。
- 呼ぶ口（今と同じ）：`autoReplies.createDraft`（確認キー付き）→ `conflicts` → 重なりがあれば帯で知らせ、もう一度押すと `publishDraft`（確かめた分だけ承認）。
- 言葉は札。Enter のほか、欄を離れたときも入れかけの言葉を札にする。空の欄で Backspace を押すと最後の札を外す。札の×は指を乗せたとき・キーボードで選んだときだけ見せる（札の幅を絵どおりに保つ）。
- 見た目：× は題の行に重ねる（絵に無いが閉じ方は右上の×の決まり）。キャンセル・有効にして保存は窓の真ん中、左に「詳しく作るへ」。
