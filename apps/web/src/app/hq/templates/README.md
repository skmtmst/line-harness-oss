# 統括のひな形

`NEXT_PUBLIC_HQ_TEMPLATE_DISTRIBUTION_ENABLED=1` のとき、`/hq/templates?type=...` から4種類の一覧、作成・編集、店舗選択、重複確認、配布結果を開く。この設定はWorkerの同一APIと結合テストが配備済みの場合だけ有効にする。既定値では画面を公開せず、既存の店舗別タグ管理へ案内する。`/accounts/new` の動作は変更しない。

- Pencil: `nen-order-inventory-fulfillment.pen` の rsyjI / ZsLly / E0CmCp / Uhd35 / FxHyL。
- 保存・削除は期待revision付き。共通fetchApiによるセッション・CSRF保護を利用する。
- 新規保存は8〜128文字のrequestId（UUID推奨）をbodyと`Idempotency-Key`へ同じ値で渡す。応答不明時は同じrequestIdと同じpayloadを再送し、サーバーの201再現を受ける。HTTP応答があっても408・5xxなど結果不明は同じrequestId・payloadを保持し、入力を固定して「前回の保存を再確認」を表示する。後続の拒否応答だけでは以前の結果不明を解除せず、成功結果を復元するまで同じ依頼を保持する。最初の試行が明確な入力・権限エラーで拒否された場合だけ、新しい依頼として修正できる。同じrequestIdで異なるpayloadを送った409 `IDEMPOTENCY_CONFLICT` は最新版を再読込して解消する。
- 配布前確認は選択店舗との一致と有効期限を検査する。重複は未選択から開始し、allowedModes内だけ選べる。一括設定後も個別変更できる。
- preflightIdがrunIdになるAPI契約。POST応答不達はGETで復元し、自動再POSTしない。URLのhashにひな形IDと配布番号だけを残し、再読込でもGETで復元する。
- 完了が確定した失敗店舗だけ、新しい事前確認へ戻す。成功件数はsucceeded店舗の内訳から計算し、通信失敗や処理中を成功・失敗として数えない。
- 認証・店舗境界・競合・冪等性の最終判断はWorker側。画面の選択制御は認可の代用ではない。
- 作成依頼はPOST前に同じタブのsessionStorageへ保存する。保存するのは依頼ID・固定入力・保存後の遷移先だけで、認証トークン・Cookie・スタッフ応答全体は保存しない。保存キーは認証済み`/api/staff/me`のtenantId・利用者ID・種類で分離する。tenantId未提供、保存不可、記録破損の場合は新規POSTを開始しない。
- 再読込や認証画面から戻った後は、同じ所属先・利用者の未確定依頼を編集画面へ復元する。自動POSTは行わず「前回の保存を再確認」から同じキーで再送する。成功時、または先行する結果不明がない最初の確定拒否時だけ記録を消去する。タブを閉じた後や別タブへの復元は対象外。所属先IDを返すWorker更新と合わせて接続する。

## 表示と受け渡し

一覧の参照先・配布先件数は初期APIが未提供のため「—」。未提供の値を0や未配布に置き換えない。APIが任意のreference_summary/distributed_account_countを提供すれば表示できる。
タグは色とタググループ、テンプレートは形式・分類・本文、リッチメニューはサイズ・画像・画像全体のタップ動作、回答フォームは質問・回答後のタグ／シナリオを専用入力欄で編集する。保存済み定義の未表示情報は保持する。
結果のreasonはAPIが返す公開用の日本語理由を表示する。API通信失敗の内部メッセージは専用clientで安全な案内へ変換する。

## 検証範囲

React契約テストは4種類の作成、編集、版競合、店舗集合、期限切れ、未選択、上書き不可、一括＋個別選択、二重クリック、結果不達、再読込、失敗店舗だけの再確認、権限不足を扱う。
Worker結合テストは4種類の保存・版管理・配布、元データと配布先の版固定、同名参照の再利用、参照グラフの複製、循環・不明参照の安全停止、DB一括確定、R2補償を実SQLiteで扱う。画面確認はローカルの静的ビルドに固定データを与え、1440/1920/390pxで行う。検証DBへの反映と、検証用LINEアカウントでの公開確認は配備工程で行う。
CSS Modulesは静的className解析では解決できないため、その利用数のみdesign-debt-baselineへ登録。表見出し・操作ボタン・削除確認は既存共通部品を使う。
既存の共通アプリ枠（サイドバー・トップバー・更新案内）は維持。PencilのEC側の共通枠との差を、この画面固有の変更で埋めない。
