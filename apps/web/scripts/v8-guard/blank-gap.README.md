# 空白量の診断

`node apps/web/scripts/v8-guard/blank-gap.mjs <baseUrl> [out.json]` は実画面の空白を測定し、全結果を診断用に報告します。空白のpx量や数の帯の高さだけで合否を決めません。測定できない画面は終了1になります。

はみ出し・重なり・右端越え・入力エラー・操作の遮断の合否は `layout-defects.mjs` と `layout-overflow.mjs` が担当します。空白の例外表と旧 `--self-test` の合否検査は廃止しました。測定器の閾値を引き上げて通す変更はしていません。
