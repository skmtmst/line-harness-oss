# 飲食店の席の予約（E-11・お客さまの LIFF）

入口：`/restaurant/reserve/:token`（管理画面の「LINE 予約の URL」）。`?view=mine` で「予約を変える・取り消す」から開く。
絵：★V8 `glL3g`（① 人数と日時）→ `km8EG`（② 確認）→ `sAnyy`（③ 受け付けました）。変更・取り消しの一覧は絵なし（共通部品だけで組んだ）。
口：API-9・API-11 の `restaurantBookingApi`（link・availability・hold・confirm・mine・cancel・reschedule）。

## 動き
- 開くと token から店を決め、今日から5日＋その次の日の空きを、選んだ人数で読む。人数を替えると読み直す。
- 人数は 1〜4名の札と「5名以上」。5名以上を選ぶと 5〜20名の選択が出る。
- 日の札は今日・明日・以降3日。空きが1つも無い日（休み・貸切・満席）は灰色にし、下に「〇/〇（曜）は臨時休業のため選べません」など理由つきの注を出す（今日は外す）。「ほかの日を選ぶ ›」で日付の選択を開く。
- 時刻は3列。空きあり／残りわずか（残り2席以下）／満席。満席は押せない。最初の日に空きが無ければ空きのある最初の日を選んでおく。
- 「この時刻で進む」で仮押さえ（店・時刻・人数・受付番号）。届いたか分からない失敗（通信・500）の再試行は同じ受付番号、断られた（409 など）ら新しい番号。埋まっていたらその日の空きを読み直す。
- ② は仮押さえの残り時間を毎秒出す。切れたら確定のボタンを押せなくし、選び直しを案内する。「← 時刻を選び直す」は仮押さえを返して ① へ。
- 「予約を確定する」は返った版を指定して確定。確認の LINE は API が確定のあとに送る（画面からは送らない）。
- ③ の「予約を変える・取り消す」で本人のこれからの予約を出す。締め切り前だけ「日時・人数を変える」「取り消す」を出す。締め切り後はお店への連絡を案内する。
- 変更は ① で選び直し、② で「この内容に変える」（仮押さえなし・版を指定）。取り消しは確認窓（取り消せない操作）を通す。
- 当日など締め切りを過ぎた予約は「取り消し・変更は〇〇まで」の代わりに「お店へ直接ご連絡ください」と書く。

## API-11 でつないだ所
- ご要望（任意・200字）と電話（任意・数字とハイフン・50字まで）：② で入れ、確定の口（`confirm(id, 版, { note, customerPhone })`）へ送る。空は送らない（null）。全角のハイフン・長音・＋は半角にそろえる。変更（reschedule）では前の予約の値を見せるだけ。
- お席：仮押さえで割り当てた卓の種類（`seatType`）、無ければ空いている候補（`slots[].seatTypes`）。「テーブル席（お店で決めます）」。③ の人数の行にも「2名・テーブル席」。
- 休みの日の注：空きの口の `unavailableReason`（日全体、無ければ時刻の理由がそろっていればそれ）。「10/12（月）は臨時休業のため選べません」。理由ごとにまとめ（臨時休業・貸切・定休日・満席）、分からない日だけなら今までの「空きがないため」。時刻の札も、空いていない理由が貸切・臨時休業ならその言葉。
- 遅れたときの決まり：空きの口の `lateArrivalPolicy.message`（無ければ分数から作る。決まりが無い店は今までの「遅れるときや人数が変わるときは…」）。

## 絵と変えた所
- 手順「2 お客さま」：お名前は LINE の名前を使い、入力の段は無い（印は ② で済みにする）。電話とご要望は ② の中で入れる。
