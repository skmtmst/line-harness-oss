# 飲食店の席の予約（E-11・お客さまの LIFF）

入口：`/restaurant/reserve/:token`（管理画面の「LINE 予約の URL」）。`?view=mine` で「予約を変える・取り消す」から開く。
絵：★V8 `glL3g`（① 人数と日時）→ `km8EG`（② 確認）→ `sAnyy`（③ 受け付けました）。変更・取り消しの一覧は絵なし（共通部品だけで組んだ）。
口：API-9 の `restaurantBookingApi`（link・availability・hold・confirm・mine・cancel・reschedule）。

## 動き
- 開くと token から店を決め、今日から5日＋その次の日の空きを、選んだ人数で読む。人数を替えると読み直す。
- 人数は 1〜4名の札と「5名以上」。5名以上を選ぶと 5〜20名の選択が出る。
- 日の札は今日・明日・以降3日。空きが1つも無い日（休み・貸切・満席）は灰色にし、下に「〇/〇（曜）は空きがないため選べません」を出す（今日は外す）。「ほかの日を選ぶ ›」で日付の選択を開く。
- 時刻は3列。空きあり／残りわずか（残り2席以下）／満席。満席は押せない。最初の日に空きが無ければ空きのある最初の日を選んでおく。
- 「この時刻で進む」で仮押さえ（店・時刻・人数・受付番号）。届いたか分からない失敗（通信・500）の再試行は同じ受付番号、断られた（409 など）ら新しい番号。埋まっていたらその日の空きを読み直す。
- ② は仮押さえの残り時間を毎秒出す。切れたら確定のボタンを押せなくし、選び直しを案内する。「← 時刻を選び直す」は仮押さえを返して ① へ。
- 「予約を確定する」は返った版を指定して確定。確認の LINE は API が確定のあとに送る（画面からは送らない）。
- ③ の「予約を変える・取り消す」で本人のこれからの予約を出す。締め切り前だけ「日時・人数を変える」「取り消す」を出す。締め切り後はお店への連絡を案内する。
- 変更は ① で選び直し、② で「この内容に変える」（仮押さえなし・版を指定）。取り消しは確認窓（取り消せない操作）を通す。
- 当日など締め切りを過ぎた予約は「取り消し・変更は〇〇まで」の代わりに「お店へ直接ご連絡ください」と書く。

## 口が無いので絵と変えた所（報告済み）
- ご要望・電話：席予約の口に送り先が無い。ご要望は入力できない形で「このあと LINE でお送りください」、電話は「LINE でご連絡します」。
- お席：口が席の種類を返さないので「お店で決めます」。
- 臨時休業の注：空きの口が休みの理由を返さないので「空きがないため選べません」。
- 「15分を過ぎてご連絡がない場合は…」：店の決まりの口が無いので「遅れるときは、この LINE でお店へお知らせください」。
- 手順「2 お客さま」：お名前は LINE の名前を使い、入力の段は無い（印は ② で済みにする）。
